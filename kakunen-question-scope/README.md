# 核燃料取扱主任者試験 作問範囲

核燃料取扱主任者試験の暗記・演習アプリ向け作問仕様。

## 原則
- 原子力規制委員会・e-Gov等の一次資料を最優先する。
- 法令・線量限度・規制値は作問時点の現行資料で再確認する。
- 過去問そのものを転載せず、論点を抽出して新規問題を作る。
- 1問1論点を基本とする。
- 数値問題は対象・期間・単位を必ずセットにする。
- 記述問題は採点要素を明示できるものだけ作る。
- 出典確認できない内容を verified にしない。
