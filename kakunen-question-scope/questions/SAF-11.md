## 出題根拠

対象論点は、安全機能維持、閉じ込め、臨界形状維持、地震荷重の重畳、支持・固定、耐震重要度概念。現行の加工施設規則・技術基準で、安全機能を有する施設、耐震重要施設、地盤、基準地震動、斜面崩壊の要求を確認した。NRAの新規制基準説明で安全機能の重要性と耐震重要度の関係を確認した。MOX燃料加工施設の公開耐震資料で、水平2方向＋鉛直方向の地震力、荷重組合せ、波及的影響、グローブボックスの閉じ込め機能、排風機の動的・電気的機能、核的制限値（寸法）の維持、支持機能を確認した。NRAの過去問公開ページで第58回～第56回の公開状況を確認し、同論点が明示的に扱われた第55回の耐震安全設計問題も論点抽出の参考とした。過去問本文は転載せず、独立した4択問題に再構成した。

## 問題

### SAF-11-Q001
- 問題文: 加工施設の安全機能を有する施設について、現行の耐震要求の基本として正しいものはどれか。
- 選択肢: ["地震力に十分に耐えることができるようにする", "地震時の損傷は許容し、事故後の復旧だけで安全を確保する", "耐震要求は建物だけに適用し、機器には適用しない", "地震力は耐震重要施設にだけ考慮し、その他の安全機能施設には考慮しない"]
- 正答選択肢: A
- 正答: 地震力に十分に耐えることができるようにする
- 解説: 加工施設の事業許可基準規則は、安全機能を有する施設に地震力へ十分耐えることを要求している。耐震要求は建物だけに限定されず、安全機能を有する施設全体に適用される。
- 出典: https://laws.e-gov.go.jp/law/425M60080000017

### SAF-11-Q002
- 問題文: 安全機能を有する施設に作用させる地震力の大きさを定める際の基本的な考え方として正しいものはどれか。
- 選択肢: ["設備価格の高低だけで決める", "地震による安全機能喪失に起因する放射線の公衆影響の程度に応じて算定する", "建物の床面積だけで決める", "事業所の従業員数だけで決める"]
- 正答選択肢: B
- 正答: 地震による安全機能喪失に起因する放射線の公衆影響の程度に応じて算定する
- 解説: 現行規則では、地震力は、安全機能の喪失に起因する放射線による公衆への影響の程度に応じて算定する。設備価格、床面積、従業員数はこの基準ではない。
- 出典: https://laws.e-gov.go.jp/law/425M60080000017
- verified: true

### SAF-11-Q003
- 問題文: 加工施設の「耐震重要施設」の考え方として最も適切なのはどれか。
- 選択肢: ["地震後の復旧費が高い施設を一律に指す", "建屋の高さが一定値を超える施設を指す", "地震による安全機能喪失に起因する放射線の公衆影響が特に大きい安全機能施設を指す", "核燃料物質を全く扱わない一般管理施設だけを指す"]
- 正答選択肢: C
- 正答: 地震による安全機能喪失に起因する放射線の公衆影響が特に大きい安全機能施設を指す
- 解説: 耐震重要施設は、安全機能を有する施設のうち、地震で安全機能を失った場合の放射線による公衆影響が特に大きいものとして扱われる。復旧費、高さ、一般管理施設で分類する概念ではない。
- 出典: https://laws.e-gov.go.jp/law/425M60080000017
- verified: true

### SAF-11-Q004
- 問題文: 耐震重要施設に対する基準地震動による地震力の要求として正しいものはどれか。
- 選択肢: ["基準地震動では機器の永久変形を必ず許容する", "基準地震動は一般管理施設だけの設計に用いる", "基準地震動に対して建屋外観だけを維持すればよい", "基準地震動による地震力に対して安全機能が損なわれるおそれがないようにする"]
- 正答選択肢: D
- 正答: 基準地震動による地震力に対して安全機能が損なわれるおそれがないようにする
- 解説: 加工施設の技術基準は、耐震重要施設について、基準地震動による地震力に対して安全機能が損なわれるおそれがないよう施設することを要求する。外観維持だけを要求するものではない。
- 出典: https://laws.e-gov.go.jp/law/362M50000002010
- verified: true

### SAF-11-Q005
- 問題文: 耐震重要施設を設置する地盤について、現行規則の要求に最も合うものはどれか。
- 選択肢: ["基準地震動による地震力を含む所定の地震力が作用しても施設を十分支持できる地盤とする", "地盤の支持力は耐震設計とは無関係なので評価しない", "上部構造が強ければ地盤は軟弱でも無条件に認められる", "通常運転時の自重だけを支持できればよい"]
- 正答選択肢: A
- 正答: 基準地震動による地震力を含む所定の地震力が作用しても施設を十分支持できる地盤とする
- 解説: 耐震重要施設を含む安全機能施設の地盤には、規則で定める地震力が作用した場合でも施設を十分支持できることが求められる。耐震重要施設では基準地震動による地震力も含めて考える。
- 出典: https://laws.e-gov.go.jp/law/425M60080000017
- verified: true

### SAF-11-Q006
- 問題文: 耐震重要施設の地盤の「変形」に関する要求として正しいものはどれか。
- 選択肢: ["地盤は一切変形してはならないという絶対条件だけが規定されている", "地盤が変形した場合でも安全機能が損なわれるおそれがないことが求められる", "変形は耐震重要施設では評価対象外である", "変形が生じたら安全機能喪失を前提としてよい"]

- 出典: https://laws.e-gov.go.jp/law/425M60080000017

### SAF-11-Q007
- 問題文: 耐震重要施設の地盤の「変位」に関する要求として正しいものはどれか。
- 選択肢: ["地盤変位は建屋の高さだけで評価する", "変位が生じても必ず許容する", "変位が生ずるおそれがない地盤に設ける", "変位は津波評価でのみ扱い、地震評価では扱わない"]

### SAF-11-Q008
- 問題文: 耐震重要施設の近傍斜面について、地震時の要求として正しいものはどれか。
- 選択肢: ["斜面崩壊は施設敷地外なら常に無視できる", "斜面崩壊は津波時だけ考慮する", "斜面崩壊で安全機能を失っても基準地震動に耐えればよい", "基準地震動に対応する地震で生じ得る斜面崩壊により安全機能が損なわれないようにする"]

- 出典: https://laws.e-gov.go.jp/law/362M50000002010

### SAF-11-Q009
- 問題文: 核燃料施設の新規制基準で、加工施設の耐震設計について明確化された考え方はどれか。
- 選択肢: ["安全機能の重要性と耐震重要度の関係を明確にする", "耐震重要度は建屋の築年数だけで決める", "全設備に同一の地震力を無条件で適用する", "安全機能と耐震重要度を切り離して扱う"]
- 正答選択肢: A
- 正答: 安全機能の重要性と耐震重要度の関係を明確にする
- 解説: NRAは核燃料施設等の新規制基準の特徴として、加工施設について安全機能の重要性と耐震重要度の関係の明確化を掲げている。耐震重要度は築年数だけで決めるものでも、全設備を同一扱いするものでもない。
- 出典: https://www.nra.go.jp/activity/regulation/reactor/kisei/sekkei/sekkei2.html
- verified: true

### SAF-11-Q010
- 問題文: 耐震設計で施設ごとに要求レベルを変える理由として最も適切なのはどれか。
- 選択肢: ["設備の塗装色を統一するため", "安全機能喪失時の影響に応じて必要な耐震性を確保するため", "機器メーカーの数を減らすため", "配管長を一律にするため"]
- 正答選択肢: B
- 正答: 安全機能喪失時の影響に応じて必要な耐震性を確保するため
- 解説: 耐震重要度は安全機能と、その喪失が公衆へ及ぼす放射線影響を踏まえて設定される。目的は必要な安全機能を地震時にも維持することであり、塗装、メーカー数、配管長の統一ではない。
- 出典: https://laws.e-gov.go.jp/law/425M60080000017
- verified: true

### SAF-11-Q011
- 問題文: 下位の耐震クラスの設備が耐震重要施設へ及ぼす「波及的影響」として評価対象になるものはどれか。
- 選択肢: ["下位クラス設備の購入価格だけ", "下位クラス設備の保守担当部署だけ", "下位クラス設備の損傷・転倒・落下により耐震重要施設を損傷させる可能性", "下位クラス設備の塗装の退色"]
- 正答選択肢: C
- 正答: 下位クラス設備の損傷・転倒・落下により耐震重要施設を損傷させる可能性

- 出典: https://www2.nra.go.jp/data/000462619.pdf

### SAF-11-Q012
- 問題文: 地震時の波及的影響評価で、隣接する施設間について考慮すべき事項として正しいものはどれか。
- 選択肢: ["設備名称が同じかどうかだけを確認する", "運転員の所属部署だけを確認する", "建設会社が同じかどうかだけを確認する", "施設間の相対変位や接続部での相互影響を確認する"]
- 正答選択肢: D
- 正答: 施設間の相対変位や接続部での相互影響を確認する
- 解説: NRA公開の耐震審査資料では、波及的影響の観点として、地盤・応答の違いによる相対変位や、接続部における相互影響などを確認する。名称や組織、施工会社は地震時の波及的影響そのものではない。
- 出典: https://www2.nra.go.jp/data/000456709.pdf
- verified: true

### SAF-11-Q013
- 問題文: 耐震重要施設を支持する建物・構築物の支持機能を確認する際の考え方として正しいものはどれか。
- 選択肢: ["支持される施設の耐震重要度に応じた地震力と、必要な常時・運転時荷重等を組み合わせる", "支持部には自重だけを作用させ、地震力を考えない", "支持される設備より低い耐震要求だけを適用する", "支持機能は地震後に目視できれば事前評価しない"]

- 出典: https://www2.nra.go.jp/data/000359733.pdf

### SAF-11-Q014
- 問題文: 動的地震力の方向成分の組合せについて、MOX燃料加工施設の耐震資料に示される考え方はどれか。
- 選択肢: ["水平1方向だけを評価し、鉛直方向は常に無視する", "水平2方向と鉛直方向の地震力を適切に組み合わせる", "鉛直方向だけを評価し、水平成分は無視する", "3方向のうち最小の成分だけを採用する"]
- 正答選択肢: B
- 正答: 水平2方向と鉛直方向の地震力を適切に組み合わせる

- 出典: https://www2.nra.go.jp/data/000359733.pdf
- verified: true

### SAF-11-Q015
- 問題文: 複数の荷重組合せを評価する場合の扱いとして、NRA公開のMOX燃料加工施設耐震資料に合うものはどれか。

### SAF-11-Q016

- 出典: https://www2.nra.go.jp/data/000359733.pdf

### SAF-11-Q017

### SAF-11-Q018
- 問題文: グローブボックス排気設備の排風機について、地震時・地震後に維持すべき機能として最も適切なのはどれか。
- 選択肢: ["外装の塗装状態だけ", "回転動作に関する動的機能と、制御盤を含む電気的機能", "停止状態の外観だけ", "排風機の銘板表示だけ"]
