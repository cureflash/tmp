# RADL-05 管理区域

- status: complete
- verified_at: 2026-09-13
- question_count: 24
- authority: 2026-09-13時点のe-Gov現行「核燃料物質の加工の事業に関する規則」、原子力規制委員会の現行線量限度等告示及びNRA公表資料を正解authorityとする

## 出題根拠

対象は `07_放射線防護・法定数値.md` の RADL-05（外部放射線、空気中濃度、表面密度、設定基準、立入、標識）。

2026-09-13時点で、e-Gov現行「核燃料物質の加工の事業に関する規則」と、NRAが現行告示として掲載する「核原料物質又は核燃料物質の製錬の事業に関する規則等の規定に基づく線量限度等を定める告示」を再確認した。管理区域に係る設定値は、外部放射線による実効線量が3月間につき1.3 mSv、空気中濃度が告示第6条第1号から第4号までの濃度の10分の1（3月間平均）、表面密度が告示第4条の表面密度限度の10分の1である。同一場所に外部放射線と空気中放射性物質がある場合は、それぞれの設定値に対する割合の和で判定する。告示第4条の表面密度限度は、アルファ線を放出する放射性物質4 Bq/cm²、アルファ線を放出しない放射性物質40 Bq/cm²であるため、管理区域設定に係る表面密度はそれぞれ0.4 Bq/cm²、4 Bq/cm²となる。

NRAの2024年公表「核燃料物質の使用（変更）許可申請に係る事例集（第5条（立入りの防止））」でも、管理区域の基準として3月間1.3 mSv、3月間平均空気中濃度の10分の1、表面密度限度の10分の1が引用されている。NRA公表の加工施設資料では、通常の管理区域外で一時的に法令上の管理区域値を超える又は超えるおそれがある場合の一時的管理区域の設定、壁・柵等による区画、標識、解除時の環境測定と告示第1条の値を超えていないことの確認が具体化されている。

直近過去問はNRA公開の第58回（2026年）、第57回（2025年）、第56回（2024年）を確認した。第56回法令では管理区域の区画・標識・飲食喫煙・表面汚染・退出時管理が直接問われ、第58回法令でも保安規定事項として管理区域等の設定・立入制限、線量・濃度・表面密度の監視が扱われている。既存 `LAW-07` はこれらの定義・法定値の直接暗記問題を既に含むため、本ファイルでは同じ文章を繰り返さず、基準値に対する割合計算、複合条件、表面密度の使い分け、一時的管理区域の実務判断を中心に新規4択化した。過去問本文は転載していない。

## 問題

### RADL-05-Q001
- 問題文: ある場所の外部放射線による実効線量を3月間で1.56 mSvと見積もった。空気中放射性物質と表面汚染は無視できるものとする。管理区域設定基準との関係として正しいものはどれか。
- 選択肢: ["1.3 mSv/3月の120 %に相当し、外部放射線の設定基準を超える", "1.3 mSv/3月の83 %に相当し、設定基準を超えない", "1.3 mSv/3月の12 %に相当し、設定基準を超えない", "年間値に換算しなければ管理区域設定の判定はできない"]
- 正答選択肢: A
- 正答: 1.3 mSv/3月の120 %に相当し、外部放射線の設定基準を超える
- 解説: 管理区域設定に用いる外部放射線の基準は3月間につき1.3 mSvである。1.56÷1.3=1.20なので120 %であり、基準を超える。83 %は逆数に近い誤り、12 %は小数点の誤りである。判定期間は3月間なので年間換算は不要である。
- 出典: https://www.nra.go.jp/data/000306810.pdf ; https://www.nra.go.jp/data/000475580.pdf
- verified: true

### RADL-05-Q005

### RADL-05-Q007
- 問題文: 告示第6条の該当濃度限度が2.0×10^-4 Bq/cm³であると仮定する。この核種について管理区域設定に用いる3月間平均空気中濃度の基準値はどれか。

- 正答: 2.0×10^-5 Bq/cm³
- 解説: 管理区域設定に用いる濃度は告示第6条の該当濃度の10分の1である。2.0×10^-4×0.1=2.0×10^-5 Bq/cm³。Aは10倍、Bは元の濃度、Dは100分の1である。ここで用いた2.0×10^-4 Bq/cm³は計算条件として与えた値であり、特定核種の実在値を問うものではない。

### RADL-05-Q008

### RADL-05-Q010
- 問題文: 同一場所で、外部放射線による3月間実効線量が0.39 mSv、空気中放射性物質の3月間平均濃度が告示第6条の該当濃度Cの0.05倍である。表面汚染は無視できる。複合基準に対する割合の和はどれか。

### RADL-05-Q012
- 問題文: 同一場所に外部放射線と空気中放射性物質が存在する場合の管理区域設定判定について、正しい計算方法はどれか。

- 出典: https://www.nra.go.jp/data/000306810.pdf ; https://www.jaea.go.jp/04/maisetsu/reference/pdf/JAEA-Review-2023-011.pdf

### RADL-05-Q015
