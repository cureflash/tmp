## 問題

### SAF-09-Q001
- 問題文: 純粋なα線源に対する外部被ばく防護として最も適切なのはどれか。
- 選択肢: ["紙やごく薄い物質でもα線自体は十分に遮蔽できる", "必ず数cmの鉛が必要である", "水素を多く含む厚い遮蔽体だけが有効である", "α線源は随伴放射線の有無にかかわらず一切の遮蔽を考えなくてよい"]
- 正答選択肢: A
- 正答: 紙やごく薄い物質でもα線自体は十分に遮蔽できる
- 解説: α線は物質中での飛程が極めて短く、JAEAは紙程度でも遮蔽できるとしている。ただし同じ核種からγ線などが放出される場合は、その放射線について別途遮蔽が必要である。鉛や水素含有材をα線自体の遮蔽に必須とする説明、随伴放射線まで無視する説明は誤り。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-10-03.html

### SAF-09-Q002
- 問題文: α線を放出する核種が同時に透過力の高いγ線も放出する場合の遮蔽として最も適切なのはどれか。
- 選択肢: ["α線だけを紙で止めれば十分で、γ線は考慮しない", "α線自体の遮蔽に加え、γ線に対する遮蔽も設ける", "γ線は水素による減速だけで処理する", "β線用の低原子番号材だけを用いればよい"]
- 正答選択肢: B
- 正答: α線自体の遮蔽に加え、γ線に対する遮蔽も設ける
- 解説: JAEAは、α線そのものは透過力が小さい一方、同じ核種からγ線が放出される場合にはγ線の遮蔽が必要としている。γ線はα線やβ線とは遮蔽原理が異なり、単に紙や低Z材だけで十分とはいえない。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-10-03.html
- verified: true

### SAF-09-Q003
- 問題文: 高放射能のβ線源を近距離で取り扱う場合の遮蔽方針として最も適切なのはどれか。
- 選択肢: ["β線は透過力が弱いので、どのような条件でも遮蔽は不要である", "中性子と同様に、まず水素で熱化しなければならない", "β線の飛程を上回る厚さで遮蔽し、必要に応じて制動X線も考慮する", "高原子番号材だけを線源直近に置き、制動放射は考慮しない"]
- 正答選択肢: C
- 正答: β線の飛程を上回る厚さで遮蔽し、必要に応じて制動X線も考慮する
- 解説: β線はα線より透過力が大きく、放射能の大きい線源や近接作業では遮蔽が必要となる。さらにβ線が物質中で減速される際には制動X線が生じ得るため、その二次放射線も考慮する必要がある。中性子の熱化はβ線の遮蔽原理ではない。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-10-03.html
- verified: true

### SAF-09-Q004
- 問題文: β線源の一次遮蔽材として、制動放射の発生を抑える観点から一般に適するものはどれか。
- 選択肢: ["タングステンのような非常に高原子番号の材料だけを用いる", "鉛だけを線源に密着させる", "カドミウムのような熱中性子吸収材だけを用いる", "プラスチックなどの低原子番号材料を用いる"]
- 正答選択肢: D
- 正答: プラスチックなどの低原子番号材料を用いる
- 解説: β線を高Z材で急激に減速させると制動X線が増えやすいため、JAEAはβ線の一次遮蔽に低原子番号材、例えばプラスチックを用いることを示している。鉛やタングステンはγ・X線遮蔽には有効だが、β線源直近の一次材としては制動放射の観点で不利になり得る。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-10-03.html

### SAF-09-Q005
- 問題文: β線と、その制動X線の双方を遮蔽する二層構造として最も適切なのはどれか。
- 選択肢: ["線源側に低原子番号材、その外側に高原子番号材を配置する", "線源側に高原子番号材、その外側に紙だけを配置する", "線源側にカドミウム、その外側に水だけを配置する", "線源側に鉛、その外側に同じ厚さの鉛を置けば材料順序は常に無関係である"]
- 正答選択肢: A
- 正答: 線源側に低原子番号材、その外側に高原子番号材を配置する
- 解説: JAEAは、β線に対しては線源側に低Z材を置いて制動X線の発生を抑え、その外側に高Z材を置いて発生したX線を遮蔽する考え方を示している。逆順にすると線源近傍の高Z材で制動放射が増えやすい。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-10-03.html
- verified: true

### SAF-09-Q006
- 問題文: 約1 MeVのβ線をアルミニウムで遮蔽する場合について、JAEAの概説に示される目安として最も近いものはどれか。

- 正答選択肢: B
- 正答: 約2 mm以上
- 解説: JAEAの「放射線の遮へい」では、1 MeVのβ線の飛程を約0.4 g/cm2とし、アルミニウムの密度を約2.7 g/cm3として、厚さ2 mm以上で遮蔽できる目安を示している。したがってµm級では薄すぎ、cm〜m級はこの例の目安から大きく外れる。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_08-01-02-06.html

### SAF-09-Q007
- 問題文: 陽電子を放出する核種の遮蔽で、陽電子の停止後に特に考慮すべき二次放射線はどれか。

- 正答選択肢: C
- 正答: 電子との対消滅で生じる0.51 MeVのγ線2本

- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_08-01-02-06.html

### SAF-09-Q013
- 問題文: 単一エネルギーの狭いγ線束が一様な遮蔽体を透過するときの基本的な減衰式として適切なのはどれか。
- 選択肢: ["I = I0 exp(-μx)", "I = I0(1+μx)", "I = I0/x だけで材料係数には依存しない", "I = I0 で厚さに依存しない"]
- 正答選択肢: A
- 正答: I = I0 exp(-μx)
- 解説: γ線の基本的な減衰は、線減弱係数μと遮蔽厚さxを用いて I=I0 exp(-μx) と表される。線形増加、材料係数を無視した単純な1/x、厚さ非依存はいずれも遮蔽体中の基本減衰則を表さない。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_08-01-02-06.html
- verified: true

### SAF-09-Q014
- 問題文: γ線遮蔽計算でいうビルドアップ係数を考慮する主な理由はどれか。
- 選択肢: ["α線が遮蔽体中で中性子へ変換されるため", "散乱されたγ線も測定点へ到達し、単純な未衝突成分だけの指数減衰より寄与が増えるため", "遮蔽体を厚くすると必ず放射線が増えるため", "ビルドアップ係数は熱中性子だけに定義されるため"]
- 正答選択肢: B
- 正答: 散乱されたγ線も測定点へ到達し、単純な未衝突成分だけの指数減衰より寄与が増えるため
- 解説: 広い体系では、遮蔽体中で散乱された光子が評価点に到達するため、未衝突光子だけを表す単純な指数減衰では線量等を過小評価し得る。この寄与を補正するためビルドアップ係数Bを用い、I=B I0 exp(-μx)の形で扱う。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_08-01-02-06.html
- verified: true

### SAF-09-Q015
- 問題文: 高速中性子を減速する材料として、水素を多く含む物質が有効な主な理由はどれか。

- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_08-01-02-06.html

### SAF-09-Q018
- 問題文: 高速中性子に対する遮蔽の基本的な二段階の考え方として最も適切なのはどれか。
- 選択肢: ["まず高Z材でγ線化し、その後β線として止める", "まず散乱で減速し、その後、熱中性子等を吸収材で捕獲する", "まず紙で全て停止し、その後鉛を取り除く", "まず熱中性子を高速化し、その後水素で増倍する"]

- 正答: まず散乱で減速し、その後、熱中性子等を吸収材で捕獲する

- 出典: https://atomica.jaea.go.jp/dic/detail/dic_detail_1050.html

### SAF-09-Q019
- 問題文: 減速された熱中性子を吸収する材料・元素の例として適切なのはどれか。
- 選択肢: ["鉛とタングステンだけ", "紙とアクリルだけ", "ホウ素、カドミウム、ガドリニウムなど", "アルミニウムと銅だけ"]

### SAF-09-Q020
- 問題文: 中性子吸収材を用いるときに二次γ線まで考慮すべき理由として最も適切なのはどれか。
- 選択肢: ["中性子は物質中で必ず陽電子に変わるから", "中性子の減速だけで全てのγ線が消えるから", "吸収材を置くと必ずβ線だけが生じるから", "中性子捕獲反応に伴ってγ線が放出される場合があり、そのγ線の遮蔽も必要になるから"]
- 正答選択肢: D
- 正答: 中性子捕獲反応に伴ってγ線が放出される場合があり、そのγ線の遮蔽も必要になるから
- 解説: 中性子を吸収すると捕獲γ線などの二次γ線が生じる場合がある。このため中性子遮蔽では、減速材・吸収材だけでなく、必要に応じてγ線遮蔽材を組み合わせる。陽電子化やβ線だけの発生を一般則とする説明は誤り。

### SAF-09-Q021
- 問題文: 中性子とγ線が同時に存在する放射線場の遮蔽設計として最も適切なのはどれか。
- 選択肢: ["それぞれの放射線の透過・相互作用特性を考え、必要に応じて複数種類の遮蔽材を組み合わせる", "最も透過力の弱い放射線だけを基準にすれば他は自動的に遮蔽される", "中性子用の水素含有材だけでγ線遮蔽も常に十分である", "γ線用の鉛だけで高速中性子の減速・吸収も常に十分である"]

- 正答: それぞれの放射線の透過・相互作用特性を考え、必要に応じて複数種類の遮蔽材を組み合わせる
- 解説: 複数種類の放射線が共存する場合は、それぞれに適した機構を組み合わせて遮蔽する必要がある。例えば高速中性子には減速・吸収、γ線には高密度材が有効であり、単一材だけで常に全成分を十分に遮蔽できるとは限らない。

### SAF-09-Q022

### SAF-09-Q023
- 問題文: 必要な配管貫通部などからのγ線ストリーミングを低減する設計として有効なのはどれか。
- 選択肢: ["できるだけ直線状で短い貫通孔にする", "貫通部周辺の遮蔽を取り除く", "迷路状・屈曲した経路とし、直接見通せないようにする", "貫通孔の断面を無条件に大きくする"]
- 正答選択肢: C
- 正答: 迷路状・屈曲した経路とし、直接見通せないようにする
- 解説: JAEAは遮蔽体の貫通部等からの漏えい低減策として迷路（ラビリンス）構造を挙げている。直線的な見通し経路や大きな開口はストリーミングを増やしやすく、遮蔽の除去は逆効果である。

### SAF-09-Q024
- 問題文: 遮蔽ブロックや遮蔽体を施工・配置するとき、ストリーミング低減の観点から重要な事項はどれか。
- 選択肢: ["意図的に連続したすき間を設ける", "遮蔽体の接合部を一直線に貫通する開口としてそろえる", "線源に近い側ほど遮蔽を減らす", "遮蔽体の接合部や周囲に放射線が通り抜けるすき間を作らない"]
- 正答選択肢: D
- 正答: 遮蔽体の接合部や周囲に放射線が通り抜けるすき間を作らない
- 解説: 遮蔽は平均厚さだけでなく局所的な弱点が重要であり、JAEAも遮蔽体にすき間を作らないことを基本上の注意としている。連続したすき間や一直線の開口はストリーミング経路となり得る。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-10-03.html
- verified: true
