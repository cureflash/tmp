- authority: JAEA/ATOMICA「放射線測定の統計的誤差」を計数統計・BG差引き・検出限界の基礎authorityとし、JAEA原子力科学研究所のGM計数管解説とJAEA-Technology-2013-049を不感時間・数え落とし補正、JAEA-Research 2026-001を判定しきい値・検出限界の現行的整理に用いた。直近過去問はNRA第58回（令和8年）、第57回（令和7年）、第56回（令和6年）の公開状況を確認し、第58回「放射線の測定及び放射線障害の防止に関する技術」で、測定計数率からバックグラウンド計数率を差し引いて表面密度を評価する論点が出題されていることを確認して作問へ反映した。過去問本文は転載していない。

対象論点は、ポアソン統計、標準偏差・相対標準偏差、計数率、計数時間依存、バックグラウンド差引きと誤差伝搬、検出限界・判定しきい値、不感時間と数え落とし補正である。既存のDET-03等で扱うGM計数管そのものの原理説明を中心にせず、計数データの統計処理と補正へ寄せた。数値問題では全選択肢を数値・単位付きとし、途中式・単位・検算を解説に残した。

### DET-10-Q001
- 問題文: 放射性崩壊に由来する計数について、半減期による変化を無視でき、一定条件で繰り返し測定するときの統計的性質として正しいものはどれか。

- 正答選択肢: A
- 正答: 計数は偶発事象であり、ポアソン分布に従う
- 解説: JAEA/ATOMICAは、放射性崩壊と放射線の検出は偶発的であり、一定計数時間で得られる計数はポアソン分布に従うとしている。Bは統計的揺らぎを否定し、Cは統計誤差と系統誤差を混同し、Dは分布形が誤りである。

### DET-10-Q002
- 問題文: ポアソン分布で平均計数が100 countのとき、分散と標準偏差の組合せとして正しいものはどれか。
- 選択肢: ["分散10 count^2、標準偏差100 count", "分散100 count^2、標準偏差10 count", "分散10000 count^2、標準偏差100 count", "分散1 count^2、標準偏差1 count"]
- 正答選択肢: B
- 正答: 分散100 count^2、標準偏差10 count
- 解説: ポアソン分布では分散は平均値に等しく、標準偏差は平均値の平方根である。平均100 countなら分散は100 count^2、標準偏差は√100=10 count。A・C・Dはこの関係を満たさない。検算として10^2=100で平均値に一致する。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-03-18.html

### DET-10-Q013

### DET-10-Q020
- 問題文: 平均信号計数率とバックグラウンド計数率が時間的に安定しているとき、計数時間を延ばす主な統計的効果として正しいものはどれか。
- 選択肢: ["総計数が減るため相対標準偏差が増える", "総計数は同じままで標準偏差だけ増える", "計数時間を延ばすほど必ず系統誤差もゼロになる", "総計数が増え、相対標準偏差が小さくなり、低レベル信号の識別に有利になる"]
- 正答選択肢: D
- 正答: 総計数が増え、相対標準偏差が小さくなり、低レベル信号の識別に有利になる
- 解説: 一定計数率ならN∝t、相対標準偏差は1/√N∝1/√tで減少する。したがって長時間計数は統計的には低レベル信号の識別に有利である。A・BはNとtの関係が逆、Cは系統誤差までゼロになるとしており誤り。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-03-18.html
- verified: true

### DET-10-Q021
- 問題文: GM計数管の不感時間の説明として正しいものはどれか。
- 選択肢: ["一つの放電後、次の放射線が入射しても新たな計数として検出できない時間が存在する", "放射線が入射する前に必ず計数される時間をいう", "測定終了後に線源が壊変しなくなる時間をいう", "検出器の校正証明書の有効期間をいう"]
- 正答選択肢: A
- 正答: 一つの放電後、次の放射線が入射しても新たな計数として検出できない時間が存在する
- 解説: JAEA/ATOMICAは、GM計数管で一度放電した後、電場が回復するまで次の入射を計数できない時間を不感時間と説明している。B～Dは不感時間の物理的意味と無関係である。
- 出典: https://atomica.jaea.go.jp/dic/detail/dic_detail_2615.html
- verified: true

### DET-10-Q022
- 問題文: JAEA原子力科学研究所が示すGM計数管の代表的な不感時間の大きさとして最も適切なものはどれか。
- 選択肢: ["約1 ns", "約100 μs", "約1 s", "約100 s"]
- 正答選択肢: B
- 正答: 約100 μs
- 解説: JAEAのサーベイメータ解説では、GM計数管は放電後に次の放電が可能になるまで約100 μsの不感時間があり、その後さらに回復時間を要するとしている。100 μs=1×10^-4 s。Aは短すぎ、C・Dは長すぎる。
- 出典: https://www.jaea.go.jp/04/ntokai/houkan/monitor/b_2.html
- verified: true

### DET-10-Q023
- 問題文: 非拡張型（非麻痺型）の不感時間モデルで、測定計数率をm、真の計数率をn、不感時間をτとし、JAEA資料に示される補正式 n=m/(1-mτ) を用いる。m=1000 s^-1、τ=100 μsのときnはいくらか。
- 選択肢: ["900 s^-1", "1000 s^-1", "約1111 s^-1", "10000 s^-1"]
- 正答選択肢: C
- 正答: 約1111 s^-1
- 解説: τ=100 μs=1.0×10^-4 s。mτ=(1000 s^-1)(1.0×10^-4 s)=0.10。したがってn=1000/(1-0.10)=1000/0.90=1111.1 s^-1≈1111 s^-1。検算として不感時間による数え落としがあるので補正後nは測定値1000 s^-1より大きい。A・Bは補正方向が誤り、Dは過大。
- 出典: https://jopss.jaea.go.jp/pdfdata/JAEA-Technology-2013-049.pdf
- verified: true

### DET-10-Q024
- 問題文: 不感時間による数え落としを補正せず、高計数率の場でパルス計数型検出器を用いた場合の傾向として正しいものはどれか。
- 選択肢: ["入射率が高いほど必ず測定計数率が真値を上回る", "不感時間は低計数率でだけ生じ、高計数率では消える", "数え落としはエネルギー校正だけで自動的に消える", "入射率が高くなるほど数え落としが無視できなくなり、未補正の測定計数率は真の入射率を過小評価しやすい"]
- 正答選択肢: D
- 正答: 入射率が高くなるほど数え落としが無視できなくなり、未補正の測定計数率は真の入射率を過小評価しやすい
- 解説: JAEAはGM計数管について、高線量率になると不感時間による計数落としが生じ、さらに高い場合は窒息により低い線量率と誤認する危険まであると説明している。Aは補正方向が逆、B・Cは不感時間の性質と一致しない。
- 出典: https://www.jaea.go.jp/04/ntokai/houkan/monitor/b_2.html
- verified: true
