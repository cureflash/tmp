# RADL-08 内部被ばく管理

- status: complete
- verified_at: 2026-09-13
- question_count: 24
- authority: 作問時点で現行のe-Gov「電離放射線障害防止規則」と厚生労働省掲載の現行条文・告示を法令数値のauthorityとし、JAEA・QST・環境省の公的資料を内部被ばくモニタリング実務の根拠とする

## 出題根拠

対象は `07_放射線防護・法定数値.md` の RADL-08（吸入/経口/創傷、体外計測、バイオアッセイ、空気濃度、摂取量、線量係数、預託実効線量、呼吸保護）。現行の電離放射線障害防止規則第6条・第8条・第9条、昭和63年労働省告示第93号の内部被ばく線量計算と空気中濃度限度、JAEAの内部被ばくモニタリング・バイオアッセイ資料を中心に新規作問した。

2026-09-13時点で、厚生労働省掲載の現行電離則について、第8条第4項の内部被ばく測定周期（原則3月以内ごと、一定の者は1月以内ごと、誤摂取時は速やかに）、第6条の妊娠中の内部被ばく実効線量1 mSv、第8条第5項の告示による算定を確認した。告示第93号について、内部被ばく実効線量 `Ei = eI`、吸入摂取と経口摂取で別の実効線量係数を用いること、複数核種では各実効線量を加算すること、複数核種の空気中濃度限度の扱いを確認した。

NRAの過去の資格試験問題公開ページで第58回（2026年）、第57回（2025年）、第56回（2024年）を確認した。第56回では内部被ばくの摂取量推定・体内動態・吸入/経口経路が論点となっているため、文章は転載せず、現行法令と公的資料に基づく別設問へ展開した。

正答位置は A/B/C/D 各6問。

## 問題

### RADL-08-Q001
- 問題文: 内部被ばくに該当するものはどれか。
- 選択肢: ["密封線源から出るガンマ線を体外から受ける", "放射性物質を含む空気を吸入し、体内に取り込んだ核種から放射線を受ける", "放射線発生装置の近くでエックス線を体外から受ける", "床にある密封線源を離れた位置から見つける"]
- 正答選択肢: B
- 正答: 放射性物質を含む空気を吸入し、体内に取り込んだ核種から放射線を受ける
- 解説: JAEAは、呼吸や飲食、汚染した傷口などから放射性物質が体内に入り、その体内線源から放射線を受けることを内部被ばくとしている。AとCは線源が体外にある外部被ばくであり、Dは被ばくの成立自体を示さない。
- 出典: https://www.jaea.go.jp/glossary/%E5%86%85%E9%83%A8%E8%A2%AB%E3%81%B0%E3%81%8F
- verified: true

### RADL-08-Q002
- 問題文: 空気中の放射性物質による吸入摂取を低減する設備的対策として、現行の電離放射線障害防止規則に例示されているものはどれか。
- 選択肢: ["鉛板だけを追加して外部放射線を遮蔽する", "作業者の滞在時間だけを短くする", "個人線量計の読取回数だけを増やす", "局所排気装置を設ける、又はガス・蒸気・粉じんの発散源を密閉する"]
- 正答選択肢: D
- 正答: 局所排気装置を設ける、又はガス・蒸気・粉じんの発散源を密閉する
- 解説: 電離則第3条の2は、常時立入場所の線量低減措置として局所排気装置や放射性物質のガス・蒸気・粉じんの発散源を密閉する設備を例示している。Aは外部放射線遮蔽、Bは滞在時間管理、Cは線量測定であり、いずれも空気中放射性物質の発生・拡散を直接低減する設備対策ではない。

### RADL-08-Q009
- 問題文: 厚生労働省告示第93号に基づき、ある核種・化学形の内部被ばくによる実効線量 Ei を、実効線量係数 e と摂取量 I から求める式はどれか。

### RADL-08-Q010
- 問題文: 厚生労働省告示第93号の `Ei = eI` における単位の組合せとして正しいものはどれか。
- 選択肢: ["e: mSv/Bq、I: Bq、Ei: mSv", "e: Bq/mSv、I: Bq、Ei: mSv", "e: mSv/Bq、I: mSv、Ei: Bq", "e: Bq、I: mSv/Bq、Ei: Bq"]
- 正答選択肢: A
- 正答: e: mSv/Bq、I: Bq、Ei: mSv
- 解説: 告示はeをmSv/Bq、IをBq、EiをmSvと定義している。次元も `(mSv/Bq)×Bq=mSv` となる。B・C・Dは告示の定義及び次元に合わない。
- 出典: https://www.mhlw.go.jp/web/t_doc?dataId=74102000&dataType=0&pageNo=1
- verified: true

### RADL-08-Q012
- 問題文: 厚生労働省告示第93号の実効線量係数について正しいものはどれか。
- 選択肢: ["吸入摂取と経口摂取では常に同じ係数を使う", "核種・化学形等に応じ、吸入摂取と経口摂取でそれぞれ告示表の対応する係数を使う", "核種に関係なく全て1 mSv/Bqを使う", "摂取経路ではなく作業時間だけで係数を決める"]

### RADL-08-Q013
- 問題文: ある核種を 2.0×10^4 Bq 吸入摂取し、その化学形に対する吸入摂取の実効線量係数が 3.0×10^-5 mSv/Bq であるとする。厚生労働省告示第93号の式で求める内部被ばく実効線量はどれか。
- 選択肢: ["0.60 mSv", "0.060 mSv", "6.0 mSv", "60 mSv"]
- 正答選択肢: A
- 正答: 0.60 mSv
- 解説: `Ei=eI=(3.0×10^-5 mSv/Bq)×(2.0×10^4 Bq)=6.0×10^-1 mSv=0.60 mSv`。単位Bqは相殺されmSvとなる。Bは10分の1、Cは10倍、Dは100倍である。
- 出典: https://www.mhlw.go.jp/web/t_doc?dataId=74102000&dataType=0&pageNo=1
- verified: true

### RADL-08-Q014

### RADL-08-Q015
- 問題文: 成人の内部被ばくでいう預託実効線量について、摂取後の線量を積算する期間として正しいものはどれか。
- 選択肢: ["摂取後1年間", "摂取後50年間", "摂取後5年間", "物理学的半減期の1回分だけ"]
- 正答選択肢: B
- 正答: 摂取後50年間

- 出典: https://www.qst.go.jp/site/nirs/1831.html
- verified: true

### RADL-08-Q016

- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-07-05.html ; https://www.qst.go.jp/site/nirs/radiation-protection-rensai-85.html

### RADL-08-Q017
- 問題文: バイオアッセイの測定値から摂取量や体内量を推定するときに必要な考え方として正しいものはどれか。
- 選択肢: ["試料採取時刻に関係なく、測定値をそのまま摂取量とする", "核種の体内代謝や排泄を無視し、尿中放射能だけを常に全身量とみなす", "体内動態は核種にかかわらず一定なのでモデルは不要とする", "摂取した核種の体内代謝・排泄率と、摂取から試料採取までの時間を考慮して解釈する"]
