# MAT-01 燃料形態

status: complete

## 対象
金属燃料、酸化物燃料（UO2/MOX）、炭化物燃料、窒化物燃料について、融点・密度・熱伝導率・中性子特性・用途を比較できるようにする。

- 過去問本文は転載せず、燃料物性・材料比較を独立問題に再構成した。

## Q001
問題文: 狭い意味での原子燃料とは、どのような物質または化合物を指すか。

正答: 中性子を吸収して核分裂を起こす物質、またはその化合物。

解説: JAEAは狭義の原子燃料として、U、PuおよびThから生成する233Uなどの核分裂性物質またはその化合物を挙げている。

出典URL: https://atomica.jaea.go.jp/data/detail/dat_detail_03-06-01-01.html

verified: true

## Q002
問題文: 固体核燃料に要求される性質として、物理的安定性・化学的安定性・照射下での安定性に加えて重要な中性子特性を1つ答えよ。

正答: 中性子吸収断面積が小さいこと。

解説: 燃料自身による非有効な中性子吸収を抑えることが、連鎖反応を維持する上で重要である。

出典URL: https://atomica.jaea.go.jp/data/detail/dat_detail_03-06-01-01.html

## Q003
問題文: コールダーホール型炉で用いられた代表的な燃料形態は何か。

正答: 金属ウラン燃料。

解説: コールダーホール型は金属U燃料、マグネシウム合金被覆、黒鉛減速、炭酸ガス冷却の組合せで実用化された。

出典URL: https://atomica.jaea.go.jp/data/detail/dat_detail_03-06-01-01.html

verified: true

## Q004
問題文: 現在の軽水炉で代表的な「燃料―被覆管―減速兼冷却材」の組合せを答えよ。

正答: UO2燃料―ジルコニウム基合金被覆―軽水。

解説: BWR・PWRでは濃縮ウラン酸化物燃料とジルコニウム基合金被覆の組合せが主流である。

出典URL: https://atomica.jaea.go.jp/data/detail/dat_detail_03-06-01-01.html

verified: true

## Q005
問題文: UO2が、熱伝導度や単位体積当たりのウラン含有量で不利でも軽水炉燃料として採用された主な理由を2つ答えよ。

正答: 融点が高いこと、被覆材や水冷却材との化学的両立性が良いこと。

解説: JAEAはUO2の熱伝導度などの弱点を挙げた上で、高融点と水との優れた両立性が軽水炉採用の理由としている。

出典URL: https://atomica.jaea.go.jp/data/detail/dat_detail_03-06-01-01.html

verified: true

## Q006
問題文: UO2とUC（炭化ウラン）を比べたとき、熱伝導と単位体積当たりのウラン含有量が優れているのはどちらか。

正答: UC。

解説: UCはUO2よりウラン含有量が大きく、熱伝導も良い。

出典URL: https://atomica.jaea.go.jp/data/detail/dat_detail_03-06-01-01.html

verified: true

## Q007
問題文: UCが水冷却炉の燃料として不向きな主な化学的理由は何か。

正答: 化学的安定性に乏しく、特に水と激しく反応するため。

解説: 熱特性は優れるが、水との両立性が悪いことが水冷却炉への適用を妨げる。

出典URL: https://atomica.jaea.go.jp/data/detail/dat_detail_03-06-01-01.html

verified: true

## Q008
問題文: UCの融点はUO2と比べてどうか。

正答: UO2よりわずかに低い。

解説: JAEAはUCについて、融点はUO2よりわずかに低い一方、ウラン含有量と熱伝導はUO2より優れるとしている。

出典URL: https://atomica.jaea.go.jp/data/detail/dat_detail_03-06-01-01.html

verified: true

## Q009
問題文: 炭化物燃料が軽水炉より高速炉で候補になりやすい理由を、冷却材との関係から答えよ。

正答: 高速炉では水ではなく液体金属冷却材を用いるため、UCの水との激しい反応という欠点を避けられるから。

解説: 炭化物燃料の水との両立性の悪さは、水冷却炉で特に重大になる。

出典URL: https://atomica.jaea.go.jp/data/detail/dat_detail_03-06-01-01.html

verified: true

## Q010
問題文: 金属燃料の代表的な長所を、熱特性と密度の観点から2つ答えよ。

正答: 熱伝導率が高いこと、燃料（重金属）密度が高いこと。

解説: 高熱伝導率により燃料温度を下げやすく、高い重金属密度は炉心のコンパクト化にもつながる。

出典URL: https://atomica.jaea.go.jp/data/detail/dat_detail_04-09-02-08.html

verified: true

## Q011
問題文: JAEA資料では、高速炉用金属燃料の熱伝導度は酸化物燃料のおよそ何倍と説明されているか。

正答: 約10倍。

解説: 高い熱伝導度は金属燃料の主要な利点であり、運転時の燃料温度を低く保つ方向に働く。

出典URL: https://atomica.jaea.go.jp/data/detail/dat_detail_04-09-02-08.html

verified: true

## Q012
問題文: 金属燃料が酸化物燃料へ主流の座を譲った歴史的な主因を2つ答えよ。

正答: スウェリングが大きいこと、融点が低いこと。

解説: 金属燃料は熱伝導率と密度に優れる一方、照射スウェリングと低融点が課題となった。

出典URL: https://atomica.jaea.go.jp/data/detail/dat_detail_04-09-02-08.html

verified: true

## Q013
問題文: 高速炉用金属燃料として提案・開発された代表的な三元合金を答えよ。

正答: U-Pu-Zr合金。

解説: U-Pu二元系の低融点や被覆管との両立性などを改善する観点からZrを加えたU-Pu-Zr系が開発された。

## Q014
問題文: 金属燃料の高い重金属密度は、同出力の酸化物燃料炉心と比べて炉心寸法にどのような利点を与えるか。

正答: 炉心径を小さくできる。

解説: 高い重金属密度により、同じ出力をよりコンパクトな炉心で実現しやすい。

## Q017
問題文: Pu含有量が数％程度の軽水炉用MOX燃料の融点は、UO2燃料と比べてどうか。

正答: UO2より若干低いが、ほぼ同程度。

解説: MOXの融点はUO2とPuO2の間にあり、Pu含有量が少ない軽水炉用MOXではUO2との差は小さい。

## Q018
問題文: Pu含有量が数％程度の軽水炉用MOX燃料の熱伝導度は、UO2燃料と比べてどうか。

正答: わずかに低下するが、概ね同程度。

解説: JAEA資料では、Puが数％の範囲で熱伝導度の低下は2％未満とされ、UO2と同程度としている。

## Q019
問題文: 高速炉でMOX酸化物燃料が採用されてきた理由として、材料特性上の長所を3つ答えよ。

正答: 耐熱性が高い、化学的に安定、照射によるスウェリングが比較的小さい。

解説: 高速炉用燃料では高温・高燃焼度・高速中性子照射への耐性が重要であり、MOXには豊富な使用実績もある。

出典URL: https://atomica.jaea.go.jp/data/detail/dat_detail_03-01-02-06.html

verified: true

## Q020

解説: JAEAはこれらの性質により冷却しやすく、安全裕度を大きくできる点を窒化物燃料の長所としている。

## Q022
問題文: JAEAが研究するADS用窒化物燃料では、主要なアクチノイド成分と希釈材として何が用いられるか。

正答: Puとマイナーアクチノイド（MA）を主要成分とし、ZrN（窒化ジルコニウム）を希釈材として加える。

解説: ADSによる核変換用燃料として、Pu・MA・ZrNからなる窒化物固溶体の物性研究が進められている。

出典URL: https://www.jaea.go.jp/02/press2019/p19101802/

verified: true

## Q023
問題文: 窒化ウラン（UN）は、軽水炉分野でどのような新型燃料の候補として研究されているか。

解説: JAEAは窒化物燃料物性データベースが軽水炉用事故耐性燃料の研究にも応用できるとしている。

## Q024
問題文: 窒化物燃料で放射性14Cの生成を抑えるために検討される窒素同位体上の対策は何か。

解説: 通常の窒素に多い14Nからの14C生成を抑えることが、窒化物燃料サイクルの課題の一つである。

## Q027
問題文: UO2と比べて熱伝導に優れると公的資料で確認できる燃料形態を、金属燃料・UC・窒化物燃料から選べ。

## Q030
