# NUC-01 アクチノイド元素

- topic_id: NUC-01
- status: completed
- verified_questions: 26
- scope: Ac, Th, Pa, U, Np, Pu, Am, Cm の元素名・記号・原子番号・順序・代表的な酸化状態
- 作問方針: 過去問の文章は転載せず、IUPAC・JAEA・米国DOE/NNSA傘下LANLの公開資料から論点を再構成する。

## 問題

### Q001
- 問題文: アクチノイドは、原子番号何番から何番までの何元素を指すか。
- 正答: 原子番号89のアクチニウム（Ac）から103のローレンシウム（Lr）までの15元素。
- 解説: JAEAはアクチノイドをAcからLrまでの15元素と定義している。
- 出典: https://www.jaea.go.jp/02/press2022/p22061301/
- verified: true

### Q019
- 問題文: LANLの周期表でアクチニウム（Ac）について挙げられている酸化状態を2つ答えよ。
- 正答: +3、+2
- 解説: LANLはAcの酸化状態として3と2を掲載している。核燃料化学の基礎では特に三価を押さえる。
- 出典: https://periodic.lanl.gov/89.shtml
- verified: true

### Q020
- 問題文: DOEのWIPP性能評価で、トリウムの溶解度評価に用いられている酸化状態は何価か。
- 正答: +4（Th(IV)）
- 解説: WIPPのアクチノイド化学モデルではトリウムを100% IV価として扱う。トリウムの代表的酸化状態として+4を押さえる。
- 出典: https://wipp.energy.gov/library/CRA/CRA-2014/CRA/Appendix_SOTERM/Appendix_SOTERM.htm
- verified: true

### Q021
- 問題文: プロトアクチニウム（Pa）が固体化合物中で最も安定とされる酸化状態は何価か。
- 正答: +5
- 解説: LANLはPaについて、固体化合物では+5が最も安定で、+4、+3、+2も存在するとしている。
- 出典: https://periodic.lanl.gov/91.shtml
- verified: true

### Q022
- 問題文: ウラン化学で特に重要な2つの酸化状態は何価か。
- 正答: +4と+6
- 解説: LANLはU(IV)とU(VI)を最も重要な酸化状態として挙げ、UO2とUO3を対応する代表的酸化物としている。水溶液では+6が最も安定とされる。
- 出典: https://periodic.lanl.gov/92.shtml
- verified: true

### Q023
- 問題文: 水溶液中のネプツニウム（Np）で最も安定とされる酸化状態は何価か。
- 正答: +5
- 解説: LANLはNpが水溶液中でIII～VII価をとり、そのうちV価が最も安定としている。
- 出典: https://periodic.lanl.gov/93.shtml
- verified: true

### Q024
- 問題文: 二酸化プルトニウムPuO2中のプルトニウムの酸化状態は何価か。
- 正答: +4
- 解説: 酸素を−2価とすると、O2全体で−4となるためPuは+4である。LANLはPuO2を主要なプルトニウム酸化物として掲載し、Pu(IV)化合物も示している。
- 出典: https://periodic.lanl.gov/94.shtml
- verified: true

### Q025
- 問題文: アメリシウム（Am）が水溶液中で最も安定に示す代表的な酸化状態は何価か。
- 正答: +3
- 解説: LANLはアメリシウムがランタノイドに似た化学挙動を示し、水溶液では三価が最も安定であるとしている。
- 出典: https://periodic.lanl.gov/95.shtml
- verified: true

### Q026
- 問題文: キュリウム（Cm）の化合物・溶液で代表的かつ安定な酸化状態は何価か。
- 正答: +3
- 解説: LANLはCm(III)溶液が安定で、多くのキュリウム化合物が三価であるとしている。
- 出典: https://periodic.lanl.gov/96.shtml
- verified: true

## 検証メモ

- 元素名・記号・原子番号・原子番号順はIUPAC周期表で照合した。
- アクチノイドの範囲はJAEAの定義でも照合した。
- 酸化状態はLANL Chemistry DivisionおよびDOE WIPP公開資料で個別に確認した。
- NRAは第56～58回を含む核燃料取扱主任者試験問題を公式に公開している。本topicは過去問の文章をコピーせず、試験範囲上の基礎知識を新規問題化した。
- NRA過去問一覧: https://www.nra.go.jp/procedure/examination/kakomon.html
