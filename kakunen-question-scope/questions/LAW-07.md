## 出題根拠

対象は `01_法令.md` の LAW-07（管理区域、保全区域、周辺監視区域、立入制限、標識、汚染除去、線量・濃度・表面密度の監視、排気・排水監視）。2026-09-13時点の「核燃料物質の加工の事業に関する規則」と、NRAが加工分野の現行告示として掲載する「核原料物質又は核燃料物質の製錬の事業に関する規則等の規定に基づく線量限度等を定める告示」を再確認した。数値問題は同告示の管理区域設定基準、周辺監視区域外の線量限度、表面密度限度に固定した。

NRAの過去問公開ページで第58回～第56回の「核燃料物質に関する法令」が公開されていることを確認した。直近過去問に見られる区域設定・立入制限・放射線監視・表面汚染管理の論点だけを参照し、文章は転載せず独立した新規4択問題にした。既存の LAW-04 にある「3区域の名称」や「排気監視設備・排水監視設備の名称」を答える問題とは重複させず、LAW-07では定義、具体的措置、現行数値、放出管理を問う。

## 問題

### LAW-07-Q001
- 問題文: 加工規則上の「管理区域」の定義として最も適切なものはどれか。
- 選択肢: ["加工施設の場所で、外部放射線の線量、空気中の放射性物質濃度又は汚染物表面の放射性物質密度が原子力規制委員会の定める値を超えるおそれのある場所", "加工施設のうち、核燃料物質を貯蔵する建屋だけを一律に指定した場所", "工場又は事業所の敷地境界から外側に設定する場所", "加工施設の保全上特に管理を要する場所で、管理区域を含むすべての場所"]
- 正答選択肢: A
- 正答: 加工施設の場所で、外部放射線の線量、空気中の放射性物質濃度又は汚染物表面の放射性物質密度が原子力規制委員会の定める値を超えるおそれのある場所
- 解説: 加工規則の定義では、管理区域は放射線・空気中濃度・表面汚染密度の基準を超えるおそれを基準に定める。Bのように貯蔵建屋だけに限定されず、Cは周辺監視区域の概念とも異なる。Dは保全区域の定義を混同しており、保全区域は管理区域以外の場所について定義される。
- 出典: https://laws.e-gov.go.jp/law/341M50000002037
- verified: true

### LAW-07-Q002
- 問題文: 加工規則上の「保全区域」の定義として正しいものはどれか。
- 選択肢: ["管理区域と同義で、放射線量が一定値を超えるおそれのある場所", "加工施設の保全のため特に管理を必要とする場所であって、管理区域以外の場所", "周辺監視区域の外側に設定する避難区域", "核物質防護のための防護区域と同義の場所"]
- 正答選択肢: B
- 正答: 加工施設の保全のため特に管理を必要とする場所であって、管理区域以外の場所
- 解説: 保全区域は、加工施設の保全のため特に管理を必要とする場所のうち管理区域以外の場所である。Aは管理区域、Cは法定義ではなく、Dの核物質防護上の防護区域とも別概念である。
- 出典: https://laws.e-gov.go.jp/law/341M50000002037
- verified: true

### LAW-07-Q003
- 問題文: 加工規則上の「周辺監視区域」の定義として最も適切なものはどれか。
- 選択肢: ["管理区域の内部に設け、従業者以外の立入りだけを制限する区域", "加工施設の保全のためだけに鍵管理を行う区域", "管理区域の周辺の区域で、外側のいかなる場所においてもその場所における線量が原子力規制委員会の定める線量限度を超えるおそれのない区域", "敷地外の全ての自治体を一律に指定する区域"]
- 正答選択肢: C
- 正答: 管理区域の周辺の区域で、外側のいかなる場所においてもその場所における線量が原子力規制委員会の定める線量限度を超えるおそれのない区域
- 解説: 周辺監視区域は管理区域の周辺に設定し、その外側で線量限度を超えるおそれがないようにする区域である。Aは管理区域内ではなく、Bは保全区域の管理目的に近い。Dのような自治体単位の指定ではない。
- 出典: https://laws.e-gov.go.jp/law/341M50000002037
- verified: true

### LAW-07-Q004
- 問題文: 加工規則上の「放射線業務従事者」に該当する者の説明として正しいものはどれか。
- 選択肢: ["工場又は事業所に雇用されている者は、管理区域に入らなくても全員該当する", "加工事業者の役員だけが該当する", "周辺監視区域の外側を通行する一般公衆も該当する", "核燃料物質の加工、加工施設の保全、核燃料物質等の運搬・貯蔵・廃棄等の業務に従事し、管理区域に立ち入る者"]
- 正答選択肢: D
- 正答: 核燃料物質の加工、加工施設の保全、核燃料物質等の運搬・貯蔵・廃棄等の業務に従事し、管理区域に立ち入る者
- 解説: 放射線業務従事者は、規則に列挙された業務に従事し、管理区域に立ち入る者である。雇用関係や役職だけでは決まらず、一般公衆も当然含まれない。
- 出典: https://laws.e-gov.go.jp/law/341M50000002037

### LAW-07-Q005
- 問題文: 加工施設で管理区域を設定する際、外部放射線に係る線量の基準として線量限度等告示が定める値はどれか。
- 選択肢: ["実効線量が3月間につき1.3 mSv", "実効線量が1週間につき1.3 mSv", "実効線量が1年間につき50 mSv", "実効線量が5年間につき100 mSv"]
- 正答選択肢: A
- 正答: 実効線量が3月間につき1.3 mSv
- 解説: 線量限度等告示の管理区域に係る基準は、外部放射線による実効線量について3月間につき1.3 mSvである。Bは期間が違い、C・Dは放射線業務従事者の線量管理で現れる値と混同した選択肢で、管理区域設定基準ではない。
- 出典: https://www.nra.go.jp/data/000306810.pdf
- verified: true

### LAW-07-Q006
- 問題文: 加工施設の管理区域設定基準のうち、空気中の放射性物質濃度について正しいものはどれか。
- 選択肢: ["1日平均が線量限度等告示別表の濃度の10倍", "3月間の平均濃度が、線量限度等告示第6条第1号から第4号までに定める濃度の10分の1", "1年間の平均濃度が、同告示第6条の濃度と同じ", "空気中濃度は管理区域設定基準に用いない"]
- 正答選択肢: B
- 正答: 3月間の平均濃度が、線量限度等告示第6条第1号から第4号までに定める濃度の10分の1
- 解説: 線量限度等告示は、管理区域設定に用いる空気中濃度を3月間の平均濃度で評価し、第6条第1号から第4号までの濃度の10分の1を基準とする。A・Cは期間と倍率が異なり、Dも誤りである。
- 出典: https://www.nra.go.jp/data/000306810.pdf

### LAW-07-Q007
- 問題文: 加工施設の管理区域設定基準のうち、放射性物質によって汚染された物の表面密度について正しいものはどれか。

### LAW-07-Q008
- 問題文: 管理区域設定に際し、外部放射線と空気中放射性物質の双方を考慮する場合の判定方法として線量限度等告示に適合するものはどれか。
- 選択肢: ["外部放射線だけを評価し、空気中濃度は無視する", "空気中濃度だけを評価し、外部放射線は無視する", "二つの基準値のうち数値が大きい方だけを採用する", "外部放射線の基準に対する比と空気中濃度の基準に対する比を加え、その和で判定する"]
- 正答選択肢: D
- 正答: 外部放射線の基準に対する比と空気中濃度の基準に対する比を加え、その和で判定する
- 解説: 外部放射線と空気中放射性物質の双方が存在する場合、告示はそれぞれの基準に対する割合の和で判定する。片方を無視したり、数値を直接比較したりする規定ではない。
- 出典: https://www.nra.go.jp/data/000306810.pdf
- verified: true

### LAW-07-Q009

### LAW-07-Q010

### LAW-07-Q011
- 問題文: 管理区域内の床、壁その他人が触れるおそれのある物の表面が放射性物質で汚染された場合の管理として正しいものはどれか。
- 選択肢: ["表面密度に上限はなく、区域外に持ち出す時だけ測定する", "表面密度は管理区域設定基準の10分の1以下でなければならない", "表面の放射性物質密度が線量限度等告示第4条の表面密度限度を超えないよう、必要な汚染除去等の管理を行う", "汚染を確認しても、外部線量が低ければ除染・管理は不要である"]
- 正答選択肢: C

- 出典: https://laws.e-gov.go.jp/law/341M50000002037 ; https://www.nra.go.jp/data/000306810.pdf

### LAW-07-Q012

### LAW-07-Q013
- 問題文: 線量限度等告示第4条が定める、アルファ線を放出する放射性物質の表面密度限度はどれか。
- 選択肢: ["4 Bq/cm²", "0.4 Bq/cm²", "40 Bq/cm²", "400 Bq/cm²"]
- 正答選択肢: A
- 正答: 4 Bq/cm²
- 解説: 告示第4条の表面密度限度は、アルファ線を放出する放射性物質について4 Bq/cm²である。0.4 Bq/cm²はその10分の1で退出・持出し管理に対応する値。40 Bq/cm²はアルファ線を放出しない放射性物質の表面密度限度で、400 Bq/cm²ではない。
- 出典: https://www.nra.go.jp/data/000306810.pdf
- verified: true

### LAW-07-Q017

### LAW-07-Q018
- 問題文: 加工規則が周辺監視区域について原則として求める措置はどれか。
