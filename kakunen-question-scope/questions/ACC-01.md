## 出題根拠

対象論点は、UF6物性、空気中水分との反応、UO2F2/HF、毒性・放射線リスク、防護、隔離、換気、測定。JAEA資料でUF6の常温・大気圧での状態、空気中水分との加水分解、反応式、生成物の物性、反応熱、低濃縮ウランでの化学的急性影響を確認した。NRAの直近公開過去問を確認し、第56回「核燃料物質の取扱いに関する技術」第1問でUF6漏えい時の反応式と事故対応者の身体防護が問われていることを論点抽出の参考とした。過去問本文は転載せず、独立した4択問題に再構成した。NRC/DOE/NIOSHの公的資料で、HFの腐食・吸入危険、管理換気・スクラバ、未知濃度での呼吸保護、HF測定、化学モニタリングと放射能モニタリングの併用を確認した。

## 問題

### ACC-01-Q001
- 問題文: 常温・大気圧における六フッ化ウラン（UF6）の状態として正しいものはどれか。
- 選択肢: ["白色の固体", "無色の液体", "常に気体", "黒色の粉末"]
- 正答選択肢: A
- 正答: 白色の固体
- 解説: JAEAはUF6を常温・大気圧では白色の固体としている。温度・圧力条件により固体、液体、気体の各状態をとるが、常温・大気圧で液体や気体ではない。
- 出典: https://www.jaea.go.jp/04/zningyo/profile1020.html
- verified: true

### ACC-01-Q002
- 問題文: UF6がウラン濃縮工程で気体原料として用いられる性質として最も適切なものはどれか。
- 選択肢: ["常温で水に全く反応しない", "比較的低い温度で気相として扱うことができる", "核分裂生成物を自発的に除去する", "空気より必ず軽く上昇する"]
- 正答選択肢: B
- 正答: 比較的低い温度で気相として扱うことができる
- 解説: UF6は大気圧で約56.6℃以上では気相が安定し、遠心分離等の気体を用いる濃縮工程に適する。一方、空気中水分とは反応し、UF6蒸気は空気より大幅に重い。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_11-02-03-03.html
- verified: true

### ACC-01-Q003
- 問題文: UF6が空気中の水分と反応したときの反応式として正しいものはどれか。
- 選択肢: ["UF6 + H2O → UF4 + 2HF + O2", "UF6 + 3H2O → UO3 + 6HF", "UF6 + 2H2O → UO2F2 + 4HF", "UF6 + O2 → UO2F2 + 2F2"]
- 正答選択肢: C
- 正答: UF6 + 2H2O → UO2F2 + 4HF
- 解説: UF6は水分と迅速に加水分解し、フッ化ウラニルUO2F2とフッ化水素HFを生じる。原子数を数えるとU=1、F=6、H=4、O=2で両辺が一致する。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_11-02-03-03.html
- verified: true

### ACC-01-Q004
- 問題文: UF6漏えい時の加水分解生成物の組合せとして正しいものはどれか。
- 選択肢: ["UO2とH2", "UF4とO2", "U3O8とF2", "UO2F2とHF"]
- 正答選択肢: D
- 正答: UO2F2とHF
- 解説: 空気中水分との加水分解で生成する主要生成物はフッ化ウラニル（UO2F2）とフッ化水素（HF）である。
- 出典: https://www.jaea.go.jp/04/zningyo/profile1020.html ; https://atomica.jaea.go.jp/data/detail/dat_detail_11-02-03-03.html
- verified: true

### ACC-01-Q005

- 正答選択肢: A
- 正答: 4 mol
- 解説: 反応式は UF6 + 2H2O → UO2F2 + 4HF であるため、UF6 1 molあたりHFは4 mol生成する。

### ACC-01-Q006

### ACC-01-Q007
- 問題文: UF6蒸気の空気に対する重さについて、JAEA資料の説明として正しいものはどれか。

### ACC-01-Q008

### ACC-01-Q010
- 問題文: UF6漏えい後に生成したUO2F2の挙動としてJAEA資料に合うものはどれか。
- 選択肢: ["全量が永久に気体として浮遊する", "固体粒子として沈降し、空気中U濃度を低下させ得る", "直ちに金属ウランへ還元される", "HFを全く伴わず単独で生成する"]

### ACC-01-Q011
- 問題文: 低濃縮度のUF6漏えい事故で急性影響を評価するとき、特に重視すべきものはどれか。
- 選択肢: ["可視光による眼障害だけ", "騒音による聴覚障害だけ", "HFや可溶性ウランによる化学的急性影響", "UF6の発火による熱傷だけ"]
- 正答選択肢: C
- 正答: HFや可溶性ウランによる化学的急性影響
- 解説: JAEAおよびNRC資料では、低濃縮・減損UF6の事故時には化学的危険が主要であり、HFの腐食性と可溶性ウランの化学毒性が重要となる。UF6自体を可燃性物質として扱う考え方ではない。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_11-02-03-03.html ; https://www.nrc.gov/materials/fuel-cycle-fac/ur-deconversion
- verified: true

### ACC-01-Q012
- 問題文: UF6加水分解で生じるHFの人体影響として正しいものはどれか。
- 選択肢: ["皮膚・呼吸器を刺激せず無害である", "主な影響は聴覚だけである", "体内に入っても化学作用を示さない", "腐食性が強く、皮膚や呼吸器を重く損傷し得る"]

- 正答: 腐食性が強く、皮膚や呼吸器を重く損傷し得る

- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_11-02-03-03.html ; https://www.cdc.gov/chemical-emergencies/chemical-fact-sheets/hydrogen-fluoride.html

### ACC-01-Q020

### ACC-01-Q021
- 問題文: UF6漏えいが疑われる区域の空気を評価する際、化学・放射線の両リスクを確認する組合せとして最も適切なものはどれか。
- 選択肢: ["HF濃度の確認と空気中放射能のサンプリング", "照度測定と騒音測定だけ", "温度測定だけ", "酸素濃度だけ測定しHF・放射能は測定しない"]
- 正答選択肢: A
- 正答: HF濃度の確認と空気中放射能のサンプリング
- 解説: UF6事故ではHFの化学危険とウランの放射線・内部被ばくの両方が問題となる。NRCの実事故報告でもHF確認と空気中放射能サンプルが別々に実施されている。

### ACC-01-Q022
- 問題文: UF6漏えい後の化学的危険を定量的に確認するため、NIOSH Pocket Guideが測定方法を示している対象物質はどれか。
- 選択肢: ["窒素だけ", "フッ化水素（HF）", "水蒸気だけ", "二酸化炭素だけ"]
- 正答選択肢: B

- 解説: NIOSH Pocket GuideはHFについてNIOSH 3800、7902、7903、7906およびOSHA ID110等の測定方法を示している。UF6漏えい時の化学ハザード確認ではHF濃度の測定が重要となる。

### ACC-01-Q023
- 問題文: UF6漏えいを確認した後の「隔離」に関する対応として最も適切なものはどれか。
- 選択肢: ["漏えい源を放置して作業員を増員する", "漏えい源の圧力を上げて漏えい箇所を探す", "安全を確保した上で漏えい源を停止・隔離し、補修後に漏えい試験等で健全性を確認する", "換気だけ行えば漏えい源の停止は不要である"]
- 正答選択肢: C
- 正答: 安全を確保した上で漏えい源を停止・隔離し、補修後に漏えい試験等で健全性を確認する
- 解説: UF6漏えい事故では、ばく露防護を確保したうえで漏えい源そのものを停止・隔離することが基本となる。NRCのHoneywell事例でも弁部を再締結して漏えいを隔離し、部品交換後の漏えい試験確認まで緊急状態を継続している。
- 出典: https://www.nrc.gov/reading-rm/doc-collections/event-status/morning/2005/20051116mr

### ACC-01-Q024
- 問題文: UF6漏えいで作業者の皮膚・衣服が汚染された可能性がある場合、除染後にも放射線管理上必要な確認として適切なものはどれか。
- 選択肢: ["体温だけ測る", "聴力だけ検査する", "HFの臭いが消えれば確認不要とする", "放射性粒子による汚染が残っていないか放射能をモニタする"]
- 正答選択肢: D
- 正答: 放射性粒子による汚染が残っていないか放射能をモニタする
- 解説: UF6は化学ハザードであると同時にウランを含む放射性物質である。DOEのUF6 SDSは皮膚・眼の洗浄後に放射能モニタリングを行うことを示しており、化学除染だけで放射線管理を終了してはならない。
- 出典: https://www.energy.gov/nnsa/articles/sds-uranium-hexafluoride-uf6
- verified: true
