# NUC-02 天然ウラン・ウラン同位体

- topic_id: NUC-02
- status: completed
- verified_questions: 27
- scope: 234U/235U/238U、天然存在比、半減期、核分裂性、親物質、238U→239Pu、濃縮ウラン・劣化ウラン
- 作問方針: NRAが公開する第56～58回の直近過去問を出題傾向確認に用い、問題文は転載せず、JAEA/ATOMICA・IAEAの公開資料から独立して再構成した。数値は出典を固定した。

## 問題

### Q001
- 問題文: 天然ウランを構成する主要な3つのウラン同位体を質量数で答えよ。
- 正答: 234U、235U、238U。
- 解説: JAEAは天然に存在するウラン同位体として234U、235U、238Uの3核種を挙げている。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_04-03-02-02.html
- verified: true

### Q002
- 問題文: JAEAが示す天然ウランの平均的な原子数比で、238U、235U、234Uはそれぞれ約何％か。
- 正答: 238U 99.274％、235U 0.720％、234U 0.0058％。
- 解説: 天然ウランでは238Uが圧倒的多数を占め、235Uは約0.72％、234Uはごく微量である。
- 出典: https://atomica.jaea.go.jp/dic/detail/dic_detail_1096.html
- verified: true

### Q003
- 問題文: JAEAが示す天然ウランの平均的な重量比で、238U、235U、234Uはそれぞれ約何％か。
- 正答: 238U 99.278重量％、235U 0.711重量％、234U 0.006重量％。
- 解説: 原子数比と重量比は同位体質量が異なるためわずかに異なる。数値問題ではどちらの比かを区別する。
- 出典: https://atomica.jaea.go.jp/dic/detail/dic_detail_1096.html
- verified: true

### Q005

- 出典: https://atomica.jaea.go.jp/dic/detail/dic_detail_1096.html

### Q006

### Q012
- 問題文: 234U、235U、238Uを半減期の短い順に並べよ。
- 正答: 234U → 235U → 238U。
- 解説: 半減期は234Uが約24.55万年、235Uが約7.04億年、238Uが約44.68億年である。
- 出典: https://infcis.iaea.org/nfcss/_content/Iaea.Infcis.Nfcss.UI/documents/TecDocs/IAEA-TECDOC-1864.pdf ; https://atomica.jaea.go.jp/data/detail/dat_detail_09-02-03-11.html ; https://atomica.jaea.go.jp/data/detail/dat_detail_08-01-01-04.html
- verified: true

### Q013
- 問題文: 天然ウラン中で234Uの存在比が極めて小さいにもかかわらず、放射線影響を無視できない理由としてJAEAが挙げる核データ上の特徴は何か。
- 正答: 238Uや235Uより半減期が短く、比放射能が大きいこと。
- 解説: JAEAは234Uの存在比を約0.0055％としつつ、半減期が約24万年と短いため比放射能が大きいと説明している。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_11-02-03-03.html
- verified: true

### Q014
- 問題文: 238Uが「親物質（潜在的核分裂性物質）」と呼ばれる主な理由は何か。
- 正答: 中性子を捕獲して、最終的に核分裂性の239Puへ変換できるため。
- 解説: 238U自身は熱中性子では核分裂しにくいが、中性子捕獲後に239U、239Npを経て239Puとなるため親物質と呼ばれる。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_03-01-01-04.html
- verified: true

### Q015
- 問題文: JAEAの核燃料増殖解説では、238Uはおよそ何MeV以上の中性子で核分裂反応を起こすと説明されているか。
- 正答: 約1 MeV以上。
- 解説: 235Uが低エネルギーの中性子でも核分裂しやすいのに対し、238UはJAEAの解説では約1 MeV以上の中性子で核分裂するとされる。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_03-01-01-04.html
- verified: true

### Q016

### Q022
- 問題文: 238Uから239Puが生成する核変換系列を、途中核種を含めて順に答えよ。
- 正答: 238U(n,γ)239U → β− → 239Np → β− → 239Pu。
- 解説: 238Uが中性子を捕獲して239Uとなり、2回のβ−壊変を経て239Puが生成する。

### Q025

- 正答: 235U。

### Q026
- 問題文: JAEAの六ヶ所ウラン濃縮工場解説では、濃縮工程から得られる濃縮側と劣化側の235U濃度はそれぞれおよそ何％と例示されているか。
- 正答: 濃縮側3～5％、劣化側約0.2％。
- 解説: 六ヶ所の遠心分離工程の説明では、235U割合が3～5％の濃縮UF6と、約0.2％まで低下した劣化UF6に分離されるとされる。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_04-05-02-03.html
- verified: true

### Q027
- 問題文: ウラン濃縮で235Uと238Uを分離できる基本的な物理的根拠は何か。
- 正答: 同位体間にわずかな質量差があること。
- 解説: 235Uと238Uは化学的性質がほぼ同じだが質量が異なるため、その差を利用して遠心分離などの同位体分離が行われる。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_04-05-01-01.html
- verified: true

## 検証メモ

- 天然ウランの同位体組成はJAEA/ATOMICA「天然ウラン」の原子数比・重量比で固定した。
- 半減期は234UをIAEA TECDOC-1864、235UをJAEA「劣化ウランの健康影響」、238UをJAEA「半減期」で照合した。丸め値を問題文・解答内で明示した。
- 238U→239Pu系列、239U・239Npの半減期、238Uの親物質としての意味、239Puの核分裂性はJAEA「核燃料増殖のしくみ」で照合した。
- 濃縮ウラン・劣化ウランの定義はJAEA「濃縮ウラン」、工程上の代表濃度はJAEA「六ヶ所ウラン濃縮工場」で照合した。
- NRAは第56回（令和6年）～第58回（令和8年）の「核燃料物質の化学的性質及び物理的性質」を公式過去問として公開している。本topicでは過去問本文を転載せず、同位体・核変換・濃縮の基礎論点を独立して作問した。
- NRA過去問一覧: https://www.nra.go.jp/procedure/examination/kakomon.html
