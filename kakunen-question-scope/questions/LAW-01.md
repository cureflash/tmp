# LAW-01 原子炉等規制法の目的・基本用語

- status: complete
- verified_at: 2026-09-12
- question_count: 20
- authority: 現行のe-Gov法令を正解authorityとする

## 出題根拠

LAW-01の対象は、原子炉等規制法第1条・第2条を中心とする「目的・基本用語」。NRAの過去問公開ページで直近の第56～58回を確認し、過去問本文の転載ではなく同じ法令知識を独立した問題にした。原子炉等規制法はe-Gov上、2026-09-12時点の現在施行版が令和7年6月6日施行として表示されている（包括的核実験禁止条約発効日に係る未施行改正あり）。

## 問題

### LAW-01-Q001
- 問題文: 原子炉等規制法の目的として、核原料物質、核燃料物質及び原子炉の利用について確保するとされている基本原則は何か。
- 正答: 利用が平和の目的に限られること。
- 解説: 法第1条は、原子力基本法の精神にのっとり、核原料物質、核燃料物質及び原子炉の利用が平和の目的に限られることを確保することを掲げる。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-01-Q002
- 問題文: 原子炉等規制法第1条が防止対象として明示している「重大な事故」に伴う事象は何か。
- 正答: 原子力施設で重大な事故が生じた場合に、放射性物質が異常な水準で当該原子力施設を設置する工場又は事業所の外へ放出されること。
- 解説: 第1条は、この事象を含む核原料物質、核燃料物質及び原子炉による災害の防止を目的に含めている。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-01-Q003
- 問題文: 原子炉等規制法第1条では、災害防止に加えて何を防護して公共の安全を図るとしているか。
- 正答: 核燃料物質。
- 解説: 法の目的には「核燃料物質を防護して、公共の安全を図る」ことが含まれる。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-01-Q004
- 問題文: 原子炉等規制法第1条が、規制を設計する際に発生を想定すると明記している二つの類型を答えよ。
- 正答: 大規模な自然災害、テロリズムその他の犯罪行為。
- 解説: 製錬、加工、貯蔵、再処理、廃棄の事業や原子炉の設置・運転等について、これらの発生も想定した必要な規制を行うとしている。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-01-Q005
- 問題文: 原子炉等規制法第1条が規制対象の事業として列挙している五つを答えよ。
- 正答: 製錬、加工、貯蔵、再処理、廃棄。
- 解説: これらの事業に加え、原子炉の設置及び運転等について必要な規制を行う。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-01-Q006
- 問題文: 原子炉等規制法第1条は、国際約束を実施するため、何の使用等に関する必要な規制を行うとしているか。
- 正答: 国際規制物資。
- 解説: 原子力の研究、開発及び利用に関する条約その他の国際約束を実施するため、国際規制物資の使用等を規制する。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-01-Q007
- 問題文: 原子炉等規制法第1条が最終的に資するとしている三つの事項を答えよ。
- 正答: 国民の生命、健康及び財産の保護、環境の保全、我が国の安全保障。
- 解説: 公共の安全を図るための各種規制等を通じて、この三事項に資することが法目的として明示されている。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-01-Q008
- 問題文: 原子炉等規制法における「核燃料物質」の定義は、どの法律の何条何号を参照しているか。
- 正答: 原子力基本法第3条第2号。
- 解説: 原子炉等規制法第2条第2項は、核燃料物質を原子力基本法第3条第2号に規定する核燃料物質としている。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166 ; https://laws.e-gov.go.jp/law/330AC1000000186
- verified: true

### LAW-01-Q009
- 問題文: 原子力基本法上の「核燃料物質」とは、どのような物質か。
- 正答: ウラン、トリウム等、原子核分裂の過程において高エネルギーを放出する物質であって、政令で定めるもの。
- 解説: 具体的な物質は「核燃料物質、核原料物質、原子炉及び放射線の定義に関する政令」第1条で定める。
- 出典: https://laws.e-gov.go.jp/law/330AC1000000186 ; https://laws.e-gov.go.jp/law/332CO0000000325
- verified: true

### LAW-01-Q010
- 問題文: 原子力基本法上の「核原料物質」とは、どのような物質か。
- 正答: ウラン鉱、トリウム鉱その他核燃料物質の原料となる物質であって、政令で定めるもの。
- 解説: 原子炉等規制法第2条第3項は、この原子力基本法上の定義を参照している。
- 出典: https://laws.e-gov.go.jp/law/330AC1000000186 ; https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-01-Q011
- 問題文: 定義政令上、「核原料物質」はどのように定義されるか。
- 正答: ウラン若しくはトリウム又はその化合物を含む物質で、核燃料物質以外のもの。
- 解説: 核原料物質か核燃料物質かは単にウラン・トリウムを含むかだけでは決まらず、政令で核燃料物質に該当するものは核原料物質から除かれる。
- 出典: https://laws.e-gov.go.jp/law/332CO0000000325
- verified: true

### LAW-01-Q012
- 問題文: 次のうち、定義政令で核燃料物質に含まれるものを全て選べ。A 天然の混合率のウラン及びその化合物 / B 劣化ウラン及びその化合物 / C トリウム及びその化合物 / D プルトニウム及びその化合物 / E ウラン233及びその化合物
- 正答: A、B、C、D、Eの全て。
- 解説: 定義政令第1条は、天然ウラン、天然比未満のウラン、トリウム、濃縮ウラン、プルトニウム、ウラン233等を核燃料物質として列挙する。
- 出典: https://laws.e-gov.go.jp/law/332CO0000000325
- verified: true

### LAW-01-Q013
- 問題文: 原子炉等規制法における「使用済燃料」とは何か。
- 正答: 原子炉に燃料として使用した核燃料物質その他原子核分裂をさせた核燃料物質。
- 解説: 法第2条第10項の再処理の定義中で、この範囲の核燃料物質を「使用済燃料」という。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-01-Q014
- 問題文: 原子炉等規制法における「製錬」の目的と処理方法を答えよ。
- 正答: 核原料物質又は核燃料物質に含まれるウラン又はトリウムの比率を高めるため、化学的方法により処理すること。
- 解説: 「比率を高めること」と「化学的方法」が定義上の要点である。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-01-Q015
- 問題文: 原子炉等規制法における「加工」の目的と処理方法を答えよ。
- 正答: 核燃料物質を原子炉に燃料として使用できる形状又は組成とするため、物理的又は化学的方法により処理すること。
- 解説: 製錬・再処理と異なり、加工の定義では物理的方法も明記されている。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-01-Q016
- 問題文: 原子炉等規制法における「再処理」の目的と処理方法を答えよ。
- 正答: 使用済燃料から核燃料物質その他の有用物質を分離するため、使用済燃料を化学的方法により処理すること。
- 解説: 「使用済燃料から有用物質を分離」「化学的方法」の二点が中核である。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-01-Q017
- 問題文: 「製錬」「加工」「再処理」のうち、法定義で物理的方法による処理を明示的に含むものはどれか。
- 正答: 加工。
- 解説: 製錬と再処理は「化学的方法」、加工は「物理的又は化学的方法」と定義される。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-01-Q018
- 問題文: 使用済燃料からウランやプルトニウムなどの有用物質を分離するために化学処理する行為は、法上「製錬」「加工」「再処理」のどれに当たるか。
- 正答: 再処理。
- 解説: 使用済燃料から核燃料物質その他の有用物質を分離する化学処理は再処理の定義そのものである。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-01-Q019
- 問題文: 原子炉等規制法第2条第7項の「原子力施設」に含まれる施設区分を答えよ。
- 正答: 製錬施設、加工施設、試験研究用等原子炉施設、発電用原子炉施設、使用済燃料貯蔵施設、再処理施設、廃棄物埋設施設、廃棄物管理施設、使用施設等。
- 解説: 法第2条第7項は、各章の個別条文で定義されるこれらの施設をまとめて「原子力施設」としている。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-01-Q020
- 問題文: 正誤を答えよ。「原子炉等規制法は、核燃料物質に係る製錬・加工・貯蔵・再処理・廃棄だけを規制し、原子炉の設置及び運転は規制対象に含めない。」
- 正答: 誤り。
- 解説: 法第1条は五つの事業だけでなく、原子炉の設置及び運転等に関しても必要な規制を行うことを明記している。NRAの規制概要も、原子炉の設置・運転等を原子炉等規制法に基づく規制対象として示している。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166 ; https://www.nra.go.jp/NuclearRegulation/about_index.html
- verified: true
