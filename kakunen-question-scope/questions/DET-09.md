## 出題根拠

対象論点は、α/β計数、γ線スペクトロメトリ、液体シンチレーションによる核種分析、計数効率、幾何学的効率、自己吸収、バックグラウンドである。既存のDET-04・DET-05等で扱った検出器そのものの原理説明を中心にせず、試料調製、核種に応じた測定法、効率校正、測定幾何、自己吸収補正、正味計数率から放射能を求める実務的な論点に寄せた。数値問題は問題文内で用いる効率の定義・前提を固定し、正答だけでなく3誤答肢も式と単位で排除できるものだけを `verified: true` とした。

### DET-09-Q001
- 問題文: 環境試料について「全ベータ放射能測定」を行った結果から直接いえることとして最も適切なものはどれか。
- 選択肢: ["試料に含まれるβ線放出成分の総量を評価できるが、その測定だけでは個々の放射性核種を判別できない", "β線のエネルギースペクトルだけから必ず全核種を一意に同定できる", "γ線放出核種だけを選択的に定量する方法である", "α線放出核種だけを選択的に定量する方法である"]
- 正答選択肢: A
- 正答: 試料に含まれるβ線放出成分の総量を評価できるが、その測定だけでは個々の放射性核種を判別できない
- 解説: 放射能測定法シリーズNo.1は、全ベータ放射能測定を試料中のβ線の総量を測定する方法とし、この方法だけでは試料中の放射性核種を判別できないとしている。Bは全ベータ測定の能力を超え、C・Dは測定対象の放射線種が異なる。

### DET-09-Q008
- 問題文: Ge γ線スペクトロメトリで、試料による自己吸収について正しい説明はどれか。

### DET-09-Q011
- 問題文: 等方的に放射線を放出する点状線源について、検出器窓を見込む立体角をΩとしたときの幾何学的効率はどれか。

### DET-09-Q012
- 問題文: 同じ等方点線源と同じ検出器を用い、他の条件を変えずに線源と検出器の距離だけを十分大きくした。幾何学的効率の変化として正しいものはどれか。

### DET-09-Q013

- 選択肢: ["液体シンチレーション測定", "高純度Geによる通常のγ線ピーク測定だけ", "中性子レムカウンタ測定", "蛍光ガラス線量計による積算外部線量測定"]
- 正答選択肢: A
- 正答: 液体シンチレーション測定
- 解説: 現行の放射能測定法シリーズNo.9「トリチウム分析法」は、水・大気・生物試料のトリチウムを液体シンチレーションにより測定する。トリチウムは低エネルギーβ線放出核種であり、B～Dはこの標準分析法ではない。
- 出典: https://www.kankyo-hoshano.go.jp/library/series/number/ ; https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-03-25.html

### DET-09-Q018

### DET-09-Q019
- 問題文: γ線スペクトロメトリで得られたスペクトルを用いて核種同定と放射能定量を行う基本的な対応として正しいものはどれか。
- 選択肢: ["ピーク面積だけで核種名を決め、ピーク位置は使わない", "バックグラウンドだけから核種名と放射能を同時に決める", "ピークのエネルギー位置を核種同定に用い、全エネルギー吸収ピークの正味面積を放射能定量に用いる", "測定時間や効率を一切用いずピークの色だけで放射能を決める"]
- 正答選択肢: C
- 正答: ピークのエネルギー位置を核種同定に用い、全エネルギー吸収ピークの正味面積を放射能定量に用いる

### DET-09-Q020

### DET-09-Q021
- 問題文: Ge γ線スペクトロメトリで、標準線源の校正時と実試料の測定時で容器形状や充填高さが異なる場合の扱いとして適切なものはどれか。
- 選択肢: ["測定ジオメトリが変わればピーク効率も変わり得るため、そのジオメトリに対応した効率校正または妥当な効率変換・補正を行う", "形状が違ってもピーク効率は常に同一なので補正しない", "充填高さが変わるほど必ず効率が1になる", "放射能値が未知なら幾何学的条件は一切考慮しない"]

- 正答: 測定ジオメトリが変わればピーク効率も変わり得るため、そのジオメトリに対応した効率校正または妥当な効率変換・補正を行う
- 解説: NRAのGe γ線スペクトロメトリ資料は、校正用線源と異なるジオメトリでの測定は解析結果を大きく変え得るとし、効率変換を使う場合も適用先ジオメトリで妥当性を確認する考え方を示している。JAEAも体積試料の形状・密度・組成を効率評価の主要条件としている。B～Dはこれと矛盾する。

### DET-09-Q022
- 問題文: Ge γ線スペクトロメトリで試料を検出器から遠ざけた場合、効率校正に関して正しいものはどれか。
- 選択肢: ["距離を変えても同じピーク効率を無条件で使える", "距離変更で測定ジオメトリとピーク効率が変わるため、その配置に対応した効率を用いる必要がある", "距離を2倍にするとピーク効率は必ず2倍になる", "距離を変えると放射能そのものが変化する"]
- 正答選択肢: B
- 正答: 距離変更で測定ジオメトリとピーク効率が変わるため、その配置に対応した効率を用いる必要がある
- 解説: 検出器から試料を遠ざけると検出器へ入射するγ線の割合が変わる。NRA資料は、異なるジオメトリで測る場合はそのジオメトリに対応するピーク効率校正が必要であるとしている。Aは校正条件を無視し、Cは一般的に成立せず、Dは測定配置と核種の放射能を混同している。
- 出典: https://www.nra.go.jp/data/000293183.pdf ; https://atomica.jaea.go.jp/dic/detail/dic_detail_809.html
- verified: true

### DET-09-Q023
- 問題文: 試料を120 s測定して総計数7800 countを得た。同じ120 sのバックグラウンドが600 count、計数効率が0.250である。この問題では A=[(Ng/t)-(Nb/t)]/ε とする。試料の放射能はどれか。
- 選択肢: ["60 Bq", "250 Bq", "240 Bq", "1200 Bq"]
- 正答選択肢: C
- 正答: 240 Bq
- 解説: 総計数率は7800/120=65 s^-1、BG計数率は600/120=5 s^-1、正味計数率は60 s^-1。したがって A=60/0.250=240 Bq。検算: (240 Bq×0.250+5 s^-1)×120 s=7800 count。Aは効率補正なし、B・Dは式と一致しない。
- 出典: https://www.nra.go.jp/data/000480854.pdf ; https://www.nra.go.jp/data/000293183.pdf
- verified: true

### DET-09-Q024
- 問題文: 放射能測定でバックグラウンドを扱う基本手順として最も適切なものはどれか。
- 選択肢: ["試料の総計数率にバックグラウンド計数率を加えてから効率補正する", "バックグラウンドは常に0と仮定して測定しない", "試料総計数率をそのまま放射能とみなし、効率を用いない", "同等の測定条件で求めたバックグラウンドを試料の総計数から差し引き、得た正味計数を効率等で補正して放射能を評価する"]
- 正答選択肢: D
- 正答: 同等の測定条件で求めたバックグラウンドを試料の総計数から差し引き、得た正味計数を効率等で補正して放射能を評価する
- 解説: 放射能は試料由来の正味信号から評価するため、総計数からバックグラウンドを差し引き、計数効率、必要に応じて放出率・自己吸収等の補正を適用する。NRA第58回試験でも、測定計数率とBG計数率の差、および機器・線源効率を用いる評価が論点になっている。AはBGを逆に加算し、B・Cは系統的に過大評価または誤った単位の結果を生む。
- 出典: https://www.nra.go.jp/data/000480854.pdf ; https://www.nra.go.jp/data/000293183.pdf
- verified: true
