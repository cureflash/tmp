# DET-06 中性子検出

- status: complete
- verified_at: 2026-09-13
- question_count: 24
- correct_index_distribution: A=6, B=6, C=6, D=6
- authority: JAEA/ATOMICA「中性子モニタ」「BF3計数管」「ヘリウム3中性子計数管」、JEMIMA「放射線計測ガイド 6-3-2-1 エリアモニタ」、JAEA原子力科学研究所の中性子線量計応答・校正場資料、NISTの中性子検出資料を主な技術authorityとした。NRA「過去の資格試験問題」で直近の第58回（令和8年）、第57回（令和7年）、第56回（令和6年）の「放射線の測定及び放射線障害の防止に関する技術」が公開されていることを確認し、過去問本文は転載していない。

## 出題根拠

対象論点は、3He、BF3、6Li、核反応、減速材、レムカウンタ、線量測定。中性子は無電荷のため、3He・10B・6Liなどとの核反応で生じる荷電粒子、または高速中性子による反跳陽子などを利用して間接検出する。熱中性子検出器を高速中性子場で用いる際の減速、中性子線量計のエネルギー応答と校正まで含めた。正答だけでなく各誤答肢も下記公的・標準資料と矛盾することを確認した問題だけを `verified: true` とした。

## 問題

### DET-06-Q001
- 問題文: 中性子検出の基本原理として最も適切なものはどれか。
- 選択肢: ["中性子と原子核との反応や散乱で生じる荷電粒子を利用して間接的に検出する", "中性子自身の電荷を電極で直接収集する", "中性子が必ず可視光を放つ性質を直接利用する", "中性子が物質を電離せずに通過した回数だけを電流として直接測る"]
- 正答選択肢: A
- 正答: 中性子と原子核との反応や散乱で生じる荷電粒子を利用して間接的に検出する
- 解説: 中性子は電荷を持たず、荷電粒子のような直接電離を利用した検出はできない。このため、低エネルギーでは3He、10B、6Liなどとの核反応で生じる陽子、トリチウム、α粒子など、高エネルギーでは水素との散乱で生じる反跳陽子などを検出する。B～Dは中性子の無電荷性と検出原理に反する。
- 出典: https://atomica.jaea.go.jp/dic/detail/dic_detail_1504.html ; https://www.nist.gov/programs-projects/determinations-boron-deposit-quality-neutron-depth-profiling

### DET-06-Q002
- 問題文: 3He中性子計数管で熱中性子検出に利用する核反応はどれか。
- 選択肢: ["3He(n,α)反応", "3He(n,p)3H反応", "3He(γ,n)反応", "3He(n,f)反応"]
- 正答選択肢: B
- 正答: 3He(n,p)3H反応
- 解説: 3He計数管では熱中性子と3Heの `3He(n,p)3H` 反応を利用する。生成した陽子と3H（トリチウム）がガスを電離してパルス信号を生じる。A、C、Dはこの計数管の検出反応ではない。
- 出典: https://atomica.jaea.go.jp/dic/detail/dic_detail_1194.html
- verified: true

### DET-06-Q003
- 問題文: 3He(n,p)3H反応で中性子検出信号の形成に直接寄与する主な荷電生成物の組合せはどれか。
- 選択肢: ["α粒子と7Li", "電子と陽電子", "陽子と3H（トリチウム）", "中性子とγ線"]
- 正答選択肢: C
- 正答: 陽子と3H（トリチウム）
- 解説: 3He(n,p)3H反応では陽子と3Hが生成し、両者が荷電粒子として封入ガスを電離する。Aは10B(n,α)7Li反応の生成物、BとDは3He計数管の当該反応生成物ではない。
- 出典: https://atomica.jaea.go.jp/dic/detail/dic_detail_1194.html ; https://www.nist.gov/publications/improved-determination-neutron-lifetime
- verified: true

### DET-06-Q004
- 問題文: JAEA/ATOMICAの説明による3He(n,p)3H反応の核反応エネルギーとして正しいものはどれか。
- 選択肢: ["約33.8 eV", "約2.79 MeV", "約4.78 MeV", "約765 keV"]
- 正答選択肢: D
- 正答: 約765 keV
- 解説: JAEA/ATOMICAは3He(n,p)3H反応で生成した陽子と3Hが765 keVの核反応エネルギーを受けるとしている。33.8 eVは気体のイオン対生成に関係する桁であり、2.79 MeVや4.78 MeVはこの3He反応の値ではない。
- 出典: https://atomica.jaea.go.jp/dic/detail/dic_detail_1194.html

- 解説: 無電荷の中性子は物質中の原子核との散乱を通じてエネルギーを失い、減速される。水素のような軽い核は減速に有効である。Aは無電荷の中性子に対する電場作用の説明として不適切で、BとCも中性子減速の基本過程ではない。
