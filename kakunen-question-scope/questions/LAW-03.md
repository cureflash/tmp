## 問題

### LAW-03-Q001
- 問題文: 加工施設の設置又は変更の工事で、原子力規制委員会規則による除外対象に該当しないものを行う場合、原則としていつ設計及び工事の計画の認可を受ける必要があるか。
- 選択肢: ["工事に着手する前", "工事完了後30日以内", "施設の使用開始後15日以内", "最初の定期事業者検査の前"]
- 正答選択肢: A
- 正答: 工事に着手する前
- 解説: 原子炉等規制法第16条の2第1項は、加工施設の設置又は変更の対象工事について、工事着手前に設計及び工事の計画の認可を受けることを原則としている。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-03-Q002
- 問題文: 加工施設の一部が滅失・損壊した場合又は災害その他非常の場合に、やむを得ない一時的な工事として事前認可の例外を用いたとき、原子炉等規制法上の事後手続はどれか。
- 選択肢: ["工事完了後30日以内に変更許可を受ける", "工事開始後、遅滞なく原子力規制委員会へ届け出る", "工事開始後15日以内に保安規定を変更する", "次回定期事業者検査時に初めて報告する"]
- 正答選択肢: B
- 正答: 工事開始後、遅滞なく原子力規制委員会へ届け出る
- 解説: 法第16条の2第1項ただし書によるやむを得ない一時的な工事では事前認可が例外となるが、同条第4項により工事開始後、遅滞なく届出が必要である。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-03-Q003
- 問題文: 認可済みの加工施設の設計及び工事の計画について、原子力規制委員会規則で定める軽微な変更を行う場合の手続として正しいものはどれか。

- 正答選択肢: C
- 正答: 変更認可は原則不要だが、変更後遅滞なく変更した計画を届け出る

- 出典: https://laws.e-gov.go.jp/law/332AC0000000166

### LAW-03-Q023
- 問題文: 原子力規制委員会が別の時期を指定する場合等を除く通常の場合、再処理施設の定期事業者検査は直近の定期事業者検査終了後いつまでに行うか。
- 選択肢: ["3月を超えない時期", "6月を超えない時期", "12月を超えない時期", "36月を超えない時期"]
- 正答選択肢: C
- 正答: 12月を超えない時期
- 解説: 再処理規則第7条の9は、通常、定期事業者検査終了日以降12月を超えない時期ごとに検査を行うとしている。判定期間が13月以上として委員会が別に指定する場合等には例外がある。
- 出典: https://laws.e-gov.go.jp/law/346M50000002010
- verified: true

### LAW-03-Q024
- 問題文: 再処理施設の設置工事後、初回の定期事業者検査を行う通常の期限はどれか。
- 選択肢: ["工事着手日以降6月を超えない時期", "工事完了日以降24月を超えない時期", "事業指定日以降36月を超えない時期", "使用開始日以降12月を超えない時期"]
- 正答選択肢: D
- 正答: 使用開始日以降12月を超えない時期
- 解説: 再処理規則第7条の9第1項ただし書は、設置工事後の初回の定期事業者検査を、その使用が開始された日以降12月を超えない時期に行うと定めている。
- 出典: https://laws.e-gov.go.jp/law/346M50000002010
- verified: true
