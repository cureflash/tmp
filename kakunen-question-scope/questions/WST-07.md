## 問題

### WST-07-Q001
- 問題文: ガラス固化の主目的として正しいものはどれか。
- 選択肢: ["高レベル廃液中の高放射能・長寿命核種をガラス状媒体に固定化し、安定な固体形態にする", "高レベル廃液から放射性核種を全て気体として分離する", "高レベル廃液中のウラン濃縮度を上げる", "高レベル廃液を未処理のまま水で希釈して処分する"]
- 正答選択肢: A
- 正答: 高レベル廃液中の高放射能・長寿命核種をガラス状媒体に固定化し、安定な固体形態にする
- 解説: JAEA/ATOMICAは、ガラス固化の目的を高レベル廃液中の高放射能・長寿命核種をガラス状媒体中に固定化することとしている。Bは固定化ではなく気相移行、Cは濃縮工程、Dは安定化処理ではなく、いずれもガラス固化の目的ではない。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_05-01-02-04.html
- verified: true

### WST-07-Q002
- 問題文: 高レベル放射性廃液の固化に現在主として選択されているガラス系はどれか。
- 選択肢: ["鉛ガラス", "ホウケイ酸ガラス", "石英ガラスのみ", "リン酸ガラスのみ"]
- 正答選択肢: B
- 正答: ホウケイ酸ガラス
- 解説: JAEA/ATOMICAは、高レベル廃液固化では現在主としてホウケイ酸ガラスが選択されているとする。リン酸ガラスは初期に検討されたが処理・熱安定性上の問題から主流にならず、A・Cも同資料が示す主流固化材ではない。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_05-01-02-04.html
- verified: true

### WST-07-Q003
- 問題文: ホウケイ酸ガラスが高レベル廃液の固化材として選ばれる理由の組合せとして最も適切なものはどれか。
- 選択肢: ["水に溶けやすく、溶融温度が極めて高い", "放射線に弱く、廃棄物成分の許容含有量が小さい", "耐食性が高く、比較的低い溶融温度で処理でき、熱・放射線への抵抗性も高い", "結晶格子が単一元素だけを選択的に取り込む"]
- 正答選択肢: C
- 正答: 耐食性が高く、比較的低い溶融温度で処理でき、熱・放射線への抵抗性も高い
- 解説: JAEA/ATOMICAは、ホウケイ酸ガラスの利点として酸・アルカリへの耐食性、比較的低い溶融温度、廃棄物成分の許容含有量の大きさ、熱・放射線抵抗性を挙げる。A・Bは逆、Dは非晶質ガラスの特徴と逆である。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_05-01-02-04.html
- verified: true

### WST-07-Q004
- 問題文: ホウケイ酸ガラスが多種類の放射性元素を取り込みやすい構造上の理由として正しいものはどれか。
- 選択肢: ["完全な単結晶で格子位置が一種類に固定されているから", "金属結合だけで構成されているから", "放射性元素を表面にだけ吸着させるから", "主にケイ酸とホウ酸が網目構造を作る非晶質で、異なるイオン半径の元素を安定に保持できるから"]

- 解説: JAEA/ATOMICAは、ホウケイ酸ガラスをケイ酸・ホウ酸の網目構造をもつ非晶質とし、多種類の放射性物質を安定・均一に保持できると説明する。Aは結晶質、Bは金属、Cは表面吸着のみという点で誤る。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_05-01-02-04.html

### WST-07-Q007
- 問題文: JAEAのTVFでいう高放射性廃液のガラス固化処理として正しい工程はどれか。

- 出典: https://www.jaea.go.jp/02/press2016/p17013001/
