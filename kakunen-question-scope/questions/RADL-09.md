# RADL-09 表面・空気汚染管理

## 出題根拠

対象は `07_放射線防護・法定数値.md` の RADL-09（表面汚染、スミヤ、空気サンプリング、除染、持出し）。既存の `LAW-07` と `RADL-05` では管理区域の定義、表面密度限度、管理区域設定基準、退出・持出しに用いる法定値そのものを既に扱っているため、本topicでは同じ数値暗記問題を繰り返さず、汚染の形態、直接法とスミヤ法、空気中濃度測定、汚染拡大防止、除染、退出・持出し時の具体的な管理行為を中心に新規作問した。

2026-09-13時点の現行「電離放射線障害防止規則」を再確認し、放射性物質取扱作業室等の構造、飛沫・粉末飛散防止、専用器具、汚染発生時の措置、定期的な汚染検査、除染・清掃用具の検査、管理区域退出時の汚染検査、物品持出し時の検査、空気中放射性物質濃度の作業環境測定を確認した。表面密度に関する数値は現行別表第三（アルファ線を放出する放射性物質 4 Bq/cm²、その他 40 Bq/cm²）を基礎とし、退出・持出し時等に用いる10分の1の関係は既存topicとの重複を避け、主に行為・手順の識別に用いた。

JAEA/ATOMICAの表面汚染モニタリング資料で、固定性汚染と遊離性（除去性）汚染、直接測定法と間接測定法（スミヤ法）、標準的な拭取り面積100 cm²、拭取り効率の考慮、遊離性汚染の再浮遊・内部被ばく・汚染拡大リスクを確認した。空気汚染については、JAEA資料で粒子状放射性物質のろ紙捕集、放射性ガスの直接捕集・電離箱等による測定、施設内空気モニタリングの役割を確認した。

NRAの過去の資格試験問題公開ページで第58回（2026年）、第57回（2025年）、第56回（2024年）の「放射線の測定及び放射線障害の防止に関する技術」が公開されていることを確認した。第57回には同科目の一部設問について出題ミスの公表があるため、当該設問の文章や正誤判定には依存していない。過去問本文は転載せず、表面・空気汚染管理という論点だけを抽出して独立した4択問題にした。

正答位置は A/B/C/D 各6問。

## 問題

### RADL-09-Q001
- 問題文: 放射性物質による表面汚染の程度を「表面密度」で表す場合の量として正しいものはどれか。
- 選択肢: ["表面全体に存在する放射能の総量だけをBqで表したもの", "単位表面積当たりの放射能をBq/cm²などで表したもの", "空気の単位体積当たりの放射能をBq/cm³で表したもの", "表面付近の実効線量率をSv/hで表したもの"]
- 正答選択肢: B
- 正答: 単位表面積当たりの放射能をBq/cm²などで表したもの
- 解説: 表面汚染密度は、汚染した表面の単位面積当たりに存在する放射能で表す。Aは面積で規格化していない総放射能、Cは空気中濃度、Dは線量率であり、いずれも表面密度ではない。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-06-04.html

### RADL-09-Q002
- 問題文: 固定性表面汚染と遊離性（除去性）表面汚染の区別として正しいものはどれか。
- 選択肢: ["固定性汚染は通常の拭取りでは容易に除去されず、遊離性汚染は拭取り等で表面から移行し得る", "固定性汚染だけが空気中へ再浮遊し、遊離性汚染は絶対に再浮遊しない", "固定性汚染は空気中濃度、遊離性汚染は外部線量率を意味する", "両者は放射線の種類だけで分類し、表面への付着状態とは無関係である"]
- 正答選択肢: A
- 正答: 固定性汚染は通常の拭取りでは容易に除去されず、遊離性汚染は拭取り等で表面から移行し得る
- 解説: JAEAは表面汚染を、表面に固着した固定性汚染と、拭取り等で除去・移行し得る遊離性汚染に区別している。Bは再浮遊しやすい側を逆にしており、C・Dは分類の意味自体が異なる。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-06-04.html
- verified: true

### RADL-09-Q003
- 問題文: サーベイメータを汚染面に近づけて測る表面汚染の直接測定法について、最も適切な説明はどれか。
- 選択肢: ["遊離性汚染だけを選択的に測り、固定性汚染は原理上計数しない", "汚染面を拭き取った試料だけを別室で測定する方法である", "検出器が応答する範囲の固定性汚染と遊離性汚染を合わせた表面汚染を直接評価する", "空気中の放射性物質濃度だけを連続測定する方法である"]
- 正答選択肢: C
- 正答: 検出器が応答する範囲の固定性汚染と遊離性汚染を合わせた表面汚染を直接評価する
- 解説: 直接測定法は汚染表面をサーベイメータ等で直接測り、固定性と遊離性を合わせた汚染を評価する。Aはスミヤ法が主に対象とする遊離性汚染との混同、Bは間接測定法、Dは空気モニタリングである。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-06-04.html
- verified: true

### RADL-09-Q004
- 問題文: 表面汚染の直接測定法の特徴として正しいものはどれか。
- 選択肢: ["拭取り試料を必ず100 cm²採取しなければ測定できない", "測定場所の外部放射線やバックグラウンドの影響を受けない", "局所的な汚染位置や分布を調べる用途には適さない", "汚染面を走査して局所的な汚染や分布を把握できる一方、外部放射線やバックグラウンドの影響を受け得る"]
- 正答選択肢: D
- 正答: 汚染面を走査して局所的な汚染や分布を把握できる一方、外部放射線やバックグラウンドの影響を受け得る
- 解説: 直接法は検出器で表面を走査できるため、点状汚染や分布把握に向く。一方で現場の外部放射線・バックグラウンドの影響を受ける。Aはスミヤ採取との混同、Bは影響を否定しており誤り、Cは直接法の利点と逆である。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-06-04.html
- verified: true

### RADL-09-Q005
- 問題文: スミヤ法（拭取り法）が主として評価する表面汚染はどれか。
- 選択肢: ["表面に強固に固着し、拭取りで全く移行しない固定性汚染だけ", "拭取りによって試料へ移行する遊離性（除去性）汚染", "空気中の放射性ガス濃度", "体内に取り込まれた放射性物質の全量"]
- 正答選択肢: B
- 正答: 拭取りによって試料へ移行する遊離性（除去性）汚染
- 解説: スミヤ法は一定面積をろ紙等で拭き取り、その試料に移行した放射能を測るため、主に遊離性汚染を評価する。Aは拭取りで移行しないため対象になりにくく、Cは空気モニタリング、Dは内部被ばくモニタリングの対象である。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-06-04.html
- verified: true

### RADL-09-Q006
- 問題文: JAEA/ATOMICAが表面汚染のスミヤ法の標準的な方法として示している拭取り面積は通常どれか。
- 選択肢: ["1 cm²", "10 cm²", "100 cm²", "1000 cm²"]
- 正答選択肢: C

- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-06-04.html

### RADL-09-Q007
- 問題文: 高い外部放射線バックグラウンドがある場所の遊離性表面汚染を評価するとき、スミヤ法に期待できる利点はどれか。
- 選択肢: ["汚染面から採取した試料を別の低バックグラウンド場所で測定でき、現場の外部放射線の影響を低減しやすい", "固定性汚染を含む表面全放射能を必ず100 %回収できる", "拭取り効率を考慮せず真の表面密度を必ず得られる", "点状の局所汚染を直接走査して位置まで連続表示できる"]
- 正答選択肢: A
- 正答: 汚染面から採取した試料を別の低バックグラウンド場所で測定でき、現場の外部放射線の影響を低減しやすい
- 解説: スミヤ法では採取と測定を分離できるため、高い現場バックグラウンドから試料を離して測定できる。Bは固定性汚染まで100 %回収する方法ではなく、Cは拭取り効率の補正を無視しており、Dは直接走査法の特徴である。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-06-04.html
- verified: true

### RADL-09-Q008
- 問題文: スミヤ試料の計数値から元の表面の遊離性汚染密度を推定するとき、特に考慮すべき要素はどれか。
- 選択肢: ["測定した場所の年間降水量だけ", "作業者の外部被ばく線量だけ", "施設の床面積だけ", "拭取り面積と、表面からスミヤ試料へ汚染が移る拭取り効率"]
- 正答選択肢: D
- 正答: 拭取り面積と、表面からスミヤ試料へ汚染が移る拭取り効率
- 解説: スミヤ試料に回収される放射能は元の表面汚染の一部なので、表面密度への換算には拭取り面積と拭取り効率を考慮する。A・B・Cはいずれもスミヤ回収放射能から表面密度を換算する主要因ではない。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-06-04.html
- verified: true

### RADL-09-Q009
- 問題文: 固定性汚染と比べた遊離性表面汚染の放射線管理上の特徴として正しいものはどれか。
- 選択肢: ["表面から移動しないため、汚染拡大や吸入摂取を考える必要がない", "放射能を持たないため、放射線管理の対象にならない", "再浮遊して空気汚染となり、吸入による内部被ばくや他の場所への汚染拡大につながり得る", "必ずガンマ線だけを放出し、アルファ線・ベータ線放出核種では生じない"]
- 正答選択肢: C
- 正答: 再浮遊して空気汚染となり、吸入による内部被ばくや他の場所への汚染拡大につながり得る
- 解説: 遊離性汚染は表面から移行しやすく、再浮遊による空気汚染、吸入摂取、皮膚・物品を介した汚染拡大が問題になる。Aはその特徴を逆に述べ、Bは放射能を否定する誤り、Dは核種・放射線種を不当に限定している。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-06-04.html
- verified: true

### RADL-09-Q010
- 問題文: 放射性物質取扱作業室等で放射性物質がこぼれ、又は漏れた場合の初動として、現行の電離放射線障害防止規則に適合するものはどれか。

### RADL-09-Q011

### RADL-09-Q014

### RADL-09-Q015
