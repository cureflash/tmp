## 問題

### MAT-03-Q001
- 問題文: 化学量論組成のUO2とPuO2を混合したときの固溶関係として正しいものはどれか。
- 選択肢: ["何れの混合割合でも固溶し、全率固溶体を形成する", "PuO2が1%を超えると必ず二相分離する", "UO2とPuO2は固相では互いに固溶しない", "室温では金属Uと金属Puに分解する"]
- 正答選択肢: A
- 正答: 何れの混合割合でも固溶し、全率固溶体を形成する
- 解説: JAEAはUO2とPuO2について、共に蛍石型構造をもち、何れの混合割合においても固溶して全率固溶体を形成するとしている。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_04-09-01-04.html
- verified: true

### MAT-03-Q002

### MAT-03-Q003

### MAT-03-Q004

- 選択肢: ["Puをペレット表面だけに集める", "Puスポットを意図的に巨大化する", "UO2とPuO2を二相に完全分離する", "Puを均一に分散させ、焼結後のPuスポットを小さくする"]
- 正答選択肢: D
- 正答: Puを均一に分散させ、焼結後のPuスポットを小さくする
- 解説: JAEAは各混合法で均一分散と、焼結後のPuスポットを小さくすることに努力が払われるとしている。

### MAT-03-Q025
- 問題文: Pu同位体の放射線特性について、JAEA資料のMOX取扱い説明に沿うものはどれか。
- 選択肢: ["241Puを除くPu同位体は主としてα線放射体である", "全Pu同位体は安定核種で放射線を出さない", "Pu同位体はすべて純粋なγ線放射体である", "Pu同位体はすべて純粋な陽電子放出核種である"]
- 正答選択肢: A
- 正答: 241Puを除くPu同位体は主としてα線放射体である
- 解説: ATOMICAは241Puを除くPu同位体をα線放射体として扱い、α粒子摂取による内部被ばく防止をMOX取扱い上の重要事項としている。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_04-09-01-04.html
- verified: true

### MAT-03-Q026
- 問題文: MOX燃料製造でPuを含む物質をグローブボックス内で扱う主な放射線防護上の理由はどれか。
- 選択肢: ["α線の外部被ばくが数km先まで届くため", "PuO2粒子などの摂取・吸入による内部被ばくを防ぐため閉じ込める", "Puが空気中で必ず核爆発するため", "UO2より熱伝導率が高すぎるため"]
- 正答選択肢: B
- 正答: PuO2粒子などの摂取・吸入による内部被ばくを防ぐため閉じ込める
- 解説: α線は外部からの透過力は小さいが、Puを吸入・摂取すると内部被ばくとなる。このためPu含有物は閉じ込め、グローブボックス内で取り扱う。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_04-09-01-04.html ; https://www.jaea.go.jp/02/press2021/p21080302/
- verified: true

### MAT-03-Q027
- 問題文: 高燃焼度使用済燃料から回収したPuを用いるMOX製造で、遮蔽・遠隔操作・自動化がより重視される理由としてJAEAが挙げるものはどれか。
- 選択肢: ["Puを含むと全放射線が消えるため", "燃料が常に常温超伝導体になるため", "娘核種等に由来するγ線・中性子線による外部被ばく低減が必要なため", "グローブボックス内では臨界管理が不要になるため"]
- 正答選択肢: C
- 正答: 娘核種等に由来するγ線・中性子線による外部被ばく低減が必要なため
- 解説: JAEAは高燃焼度燃料から抽出されるPuでは娘核種等からγ線・中性子線が放出されるため、遮蔽、遠隔操作化、自動化の要求が強くなるとしている。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_04-09-01-04.html

### MAT-03-Q028
- 問題文: JAEAが2021年にPuO2粒子のα線イメージング研究で説明した内部被ばく評価について正しいものはどれか。
- 選択肢: ["PuO2粒子は必ず直径1 m以上で、吸入されない", "PuO2粒子を吸入しても内部被ばくは生じない", "内部被ばく線量は粒径分布と無関係である", "PuO2は数µm規模の粒子を形成し、吸入時の内部被ばく線量評価にはAMADなど粒径情報が重要である"]
- 正答選択肢: D
- 正答: PuO2は数µm規模の粒子を形成し、吸入時の内部被ばく線量評価にはAMADなど粒径情報が重要である
- 解説: JAEAはPuO2が直径数µmの粒子を形成し、吸入による内部被ばく線量が空気力学的放射能中央径（AMAD）として表される粒径分布に依存すると説明している。
- 出典: https://www.jaea.go.jp/02/press2021/p21080302/
- verified: true
