## 出題根拠

対象論点は、TBP/希釈剤＋硝酸系、高温・高硝酸条件、発熱・ガス発生・爆発、蒸発濃縮時の危険、温度・組成・TBP量・ベント管理である。JAEA/ATOMICAでは、PUREX法で30 vol.% TBP-希釈溶剤と硝酸水溶液を接触させること、レッドオイルが熱的に不安定で135～137℃以上で急激な分解反応を起こし得ること、蒸発缶で有機溶媒混入と過濃縮が重なると急激な熱分解・圧力上昇につながること、Tomsk-7事故で濃硝酸と有機相の反応が発熱的に進展したことを確認した。

DOE-HDBK-1224-2018では、TBPと濃硝酸を高温条件で接触させると、過圧・容器破損・可燃性ガスの火災又はデフラグレーションに至り得ること、酸濃度が高いほど反応が激しくなること、予防管理を温度、ベント/圧力、TBP量、酸濃度の観点で行うことを確認した。適切なベントはガス・中間生成物の除去と蒸発冷却を助ける一方、ベントされた可燃性ガスの外部着火リスクは別途残る。

NRA「過去の資格試験問題」で直近公開の第58回・第57回・第56回の「核燃料物質の取扱いに関する技術」を確認対象とし、レッドオイル、TBP、硝酸、蒸発・事故防止に関する出題傾向を検索した。過去問本文は転載せず、事故条件と安全管理の論点を独立した4択問題に再構成した。

## 問題

### ACC-03-Q001
- 問題文: PUREX法の抽出工程で用いられる有機溶媒系として、JAEA資料に示される代表的な組成はどれか。
- 選択肢: ["約30 vol.% TBPを希釈溶剤に混合した有機溶媒", "濃硝酸のみ", "水のみ", "フッ化水素のみ"]
- 正答選択肢: A
- 正答: 約30 vol.% TBPを希釈溶剤に混合した有機溶媒
- 解説: JAEA/ATOMICAはPUREX抽出工程の有機溶媒として30 vol.% TBP-希釈溶剤を示している。濃硝酸は水相側の成分であり、水やHF単独を抽出有機溶媒として用いるものではない。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_06-01-05-06.html
- verified: true

### ACC-03-Q002
- 問題文: レッドオイルの組成について最も適切な説明はどれか。
- 選択肢: ["純粋なUO2だけからなる", "TBP、その劣化生成物、硝酸やその反応生成物、重金属成分などを含み得る複雑な混合物である", "純粋な硝酸だけからなる", "フッ化水素と水だけからなる"]
- 正答選択肢: B
- 正答: TBP、その劣化生成物、硝酸やその反応生成物、重金属成分などを含み得る複雑な混合物である
- 解説: JAEA資料では、レッドオイルはウラン等の重金属、TBP及びTBP劣化生成物、硝酸、希釈剤と硝酸の反応生成物等を含み得る複雑な混合物として扱われる。単一純物質ではない。
- 出典: https://jopss.jaea.go.jp/pdfdata/JAEA-Review-2008-037.pdf
- verified: true

### ACC-03-Q003
- 問題文: 「レッドオイル」という名称の由来として正しいものはどれか。
- 選択肢: ["赤色のウラン金属が析出するため", "赤色の炎だけが発生するため", "TBP相中に赤みを帯びた油状の中間生成物が生じるため", "赤色の警報灯が作動するため"]
- 正答選択肢: C
- 正答: TBP相中に赤みを帯びた油状の中間生成物が生じるため
- 解説: DOE及びJAEA資料では、TBPと硝酸系の反応過程で赤みを帯びた油状の中間生成物が形成されることからレッドオイルと呼ばれる。金属析出や警報灯の色に由来する名称ではない。
- 出典: https://www.energy.gov/documents/doe-hdbk-1224-2018pdf ; https://atomica.jaea.go.jp/data/detail/dat_detail_06-01-05-06.html
- verified: true

### ACC-03-Q004
- 問題文: TBP-硝酸系のレッドオイル反応が暴走した場合に想定される主要な危険として最も適切なものはどれか。
- 選択肢: ["液の色が変わるだけで圧力変化はない", "腐食だけで発熱やガス発生は起こらない", "反応は必ず穏やかに停止し容器健全性には影響しない", "急激な発熱・ガス発生により過圧、容器破損、火災又はデフラグレーションに至り得る"]
- 正答選択肢: D
- 正答: 急激な発熱・ガス発生により過圧、容器破損、火災又はデフラグレーションに至り得る
- 解説: DOE-HDBK-1224-2018は、TBPと濃硝酸の高温反応が過圧・容器破損を生じ、生成する可燃性ガスが火災又はデフラグレーションにつながり得るとしている。単なる色変化や腐食だけの事象ではない。
- 出典: https://www.energy.gov/documents/doe-hdbk-1224-2018pdf
- verified: true

### ACC-03-Q005
- 問題文: JAEA/ATOMICAがレッドオイルの急激な分解反応開始温度として示す範囲はどれか。
- 選択肢: ["約135～137℃以上", "約20～25℃以上", "約50～55℃以上", "約300～350℃以上"]
- 正答選択肢: A
- 正答: 約135～137℃以上
- 解説: JAEA/ATOMICAは、レッドオイルは熱的に不安定であり、温度が135～137℃以上に達すると急激な分解反応が始まるとしている。ここで問うのは生成開始温度ではなく、同資料が示す急激な分解反応の温度域である。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_06-01-05-06.html
- verified: true

### ACC-03-Q006
- 問題文: DOE-HDBK-1224-2018による、硝酸濃度とTBP-硝酸反応の激しさの関係として正しいものはどれか。
- 選択肢: ["硝酸濃度が高いほど必ず反応は弱くなる", "硝酸濃度が高いほど反応は激しくなる", "硝酸濃度は反応に全く影響しない", "硝酸を加えると必ず吸熱反応だけになる"]
- 正答選択肢: B
- 正答: 硝酸濃度が高いほど反応は激しくなる
- 解説: DOE-HDBK-1224-2018は、硝酸濃度が強いほど反応がより激しくなるとし、予防策として酸濃度の制限を挙げている。濃度が高いほど安全になるわけではない。
- 出典: https://www.energy.gov/documents/doe-hdbk-1224-2018pdf
- verified: true

### ACC-03-Q007
- 問題文: DOE-HDBK-1224-2018が特に危険なTBP-硝酸系の条件として示す組合せはどれか。
- 選択肢: ["低温かつTBPを含まない水系", "室温の水のみ", "高温（概ね135℃超）かつ濃硝酸が存在するTBP系", "希釈溶剤を含まず硝酸も存在しない系"]
- 正答選択肢: C
- 正答: 高温（概ね135℃超）かつ濃硝酸が存在するTBP系
- 解説: DOEは、TBPと濃硝酸が高温、特に135℃を超えるような条件で制御不能反応に至り得るとする。TBP又は硝酸が存在しない選択肢はレッドオイル反応条件を満たさない。
- 出典: https://www.energy.gov/documents/doe-hdbk-1224-2018pdf
- verified: true

### ACC-03-Q008
- 問題文: DOE-HDBK-1224-2018が示すレッドオイル事故防止の管理項目の組合せとして正しいものはどれか。
- 選択肢: ["照度・騒音・気圧・湿度だけ", "遮蔽厚・中性子束・燃焼度・崩壊熱だけ", "作業者人数・室温・照明・通路幅だけ", "温度、ベント/圧力、TBP量、酸濃度"]
- 正答選択肢: D
- 正答: 温度、ベント/圧力、TBP量、酸濃度
- 解説: DOEはレッドオイル事故の予防・緩和を、温度、圧力（ベント）、反応し得るTBP量、酸濃度の管理に整理している。他の選択肢は本反応の主要管理項目の組合せではない。
- 出典: https://www.energy.gov/documents/doe-hdbk-1224-2018pdf
- verified: true

### ACC-03-Q009
- 問題文: レッドオイル事故防止のためTBPの存在量を制限する理由として正しいものはどれか。
- 選択肢: ["反応するTBP量が少なければ、発生する総熱量と総ガス量も小さくできるため", "TBP量を減らすと硝酸濃度が自動的にゼロになるため", "TBP量を減らすと容器が完全に無圧になるため", "TBP量と発熱・ガス発生量は無関係であるため"]
- 正答選択肢: A
- 正答: 反応するTBP量が少なければ、発生する総熱量と総ガス量も小さくできるため
- 解説: DOEは、総発熱量と総ガス発生量は反応するTBP量に比例するとし、TBP量制限を予防策に挙げる。TBP量を減らしても硝酸が消失したり、圧力が必ずゼロになったりするわけではない。
- 出典: https://www.energy.gov/documents/doe-hdbk-1224-2018pdf
- verified: true

### ACC-03-Q010
- 問題文: レッドオイル事故防止で硝酸濃度を制限する直接の理由として、DOE資料に沿うものはどれか。
- 選択肢: ["酸濃度を上げるほど反応速度が低下するため", "反応速度が酸濃度に依存し、酸濃度上昇で反応が速くなり得るため", "酸濃度は色だけに影響し反応速度には影響しないため", "濃硝酸はTBPを完全に不活性化するため"]
- 正答選択肢: B
- 正答: 反応速度が酸濃度に依存し、酸濃度上昇で反応が速くなり得るため
- 解説: DOE-HDBK-1224-2018は酸濃度の制限を予防策とし、反応速度は酸濃度に比例すると説明している。高濃度硝酸を安全化因子とみなすことはできない。
- 出典: https://www.energy.gov/documents/doe-hdbk-1224-2018pdf
- verified: true

### ACC-03-Q011
- 問題文: TBP-硝酸系の反応容器で十分なベントを確保する安全上の効果として最も適切なものはどれか。
- 選択肢: ["反応ガスを容器内に蓄積させる", "沸点を上昇させて蒸発冷却を抑える", "ガスや反応中間体を逃がし、過圧を抑えるとともに蒸発冷却を助ける", "硝酸濃度を必ず100 wt.%にする"]
- 正答選択肢: C
- 正答: ガスや反応中間体を逃がし、過圧を抑えるとともに蒸発冷却を助ける
- 解説: DOEは、十分なベントがガス・反応中間体の排出、圧力上昇の抑制、蒸発による熱除去に寄与するとしている。ベントを閉じる方向は逆に危険を増やす。
- 出典: https://www.energy.gov/documents/doe-hdbk-1224-2018pdf
- verified: true

### ACC-03-Q012
- 問題文: TBP-硝酸系を密閉又は不十分なベント状態にした場合の危険増大メカニズムとして正しいものはどれか。
- 選択肢: ["圧力が低下し続け、沸点も下がる", "生成ガスが直ちに全量消失する", "蒸発冷却が必ず強化される", "生成ガスが蓄積して圧力・沸点が上がり、蒸発冷却が抑えられ、反応性中間体も保持されやすくなる"]
- 正答選択肢: D
- 正答: 生成ガスが蓄積して圧力・沸点が上がり、蒸発冷却が抑えられ、反応性中間体も保持されやすくなる
- 解説: DOEは閉鎖系ではガス蓄積で圧力が上がり、沸点上昇により蒸発冷却が抑制され、反応中間体も系内に保持されるため反応がより厳しくなり得るとする。
- 出典: https://www.energy.gov/documents/doe-hdbk-1224-2018pdf
- verified: true

### ACC-03-Q013
- 問題文: 二相系の容器でレッドオイル反応を抑制するため、DOE資料が示す撹拌の安全上の役割として適切なものはどれか。

### ACC-03-Q015
- 問題文: 1975年のSavannah River Site A-Line事故の教訓として正しいものはどれか。
- 選択肢: ["ベントがあれば可燃性ガスの外部着火は起こり得ない", "高温脱硝器にはTBPを積極的に添加すべきである", "TBPが加熱された脱硝器へ誤混入し、ベントから出た可燃性ガスが室内で着火・デフラグレーションし得る", "TBP混入は高温工程では安全性を高める"]
- 正答選択肢: C

- 解説: DOEとJAEA資料では、1975年事故はTBPが高温の脱硝器に入り、一次容器からベントされた可燃性ガスが室内で着火してデフラグレーションした事例とされる。ベントは容器破損防止に有効でも、外部着火リスクを消すわけではない。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_04-10-03-03.html ; https://www.energy.gov/documents/doe-hdbk-1224-2018pdf

### ACC-03-Q016
- 問題文: Tomsk-7事故の危険条件の組合せとして、DOE資料に最も整合するものはどれか。
- 選択肢: ["希硝酸、水だけ、十分な冷却、常時開放ベント", "TBPを含まない低温水溶液、十分な撹拌", "有機物なし、低温、低圧、十分な換気", "濃硝酸、大量のPUREX由来有機物、熱い蒸発残液、当初不十分なベント"]

- 正答: 濃硝酸、大量のPUREX由来有機物、熱い蒸発残液、当初不十分なベント
- 解説: DOEはTomsk-7事故について、強硝酸、大量のPUREX由来有機残渣、熱い蒸発残液、初期に十分なベントがない条件を挙げている。これらが反応加速と圧力上昇を招いた。
- 出典: https://www.energy.gov/documents/doe-hdbk-1224-2018pdf
- verified: true

### ACC-03-Q017
- 問題文: JAEA/ATOMICAがTomsk-7事故の反応進展として示す説明に最も近いものはどれか。
- 選択肢: ["TBPの加水分解で生じたブタノールが硝酸ブチルを経てさらに反応し、発熱により温度上昇と急激な分解へ進んだ", "TBPが中性子を吸収して核分裂連鎖反応を起こした", "硝酸が完全に蒸発してから吸熱反応だけが続いた", "水が凍結して容器を機械的に破壊した"]
- 正答選択肢: A
- 正答: TBPの加水分解で生じたブタノールが硝酸ブチルを経てさらに反応し、発熱により温度上昇と急激な分解へ進んだ
- 解説: JAEA/ATOMICAは、TBP加水分解由来のブタノールが硝酸ブチルとなり、さらに濃硝酸との反応でカルボン酸等を生じる発熱反応が進み、高温で急激な分解に至ったと説明している。核分裂連鎖反応や凍結破壊ではない。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_06-01-05-06.html
- verified: true

### ACC-03-Q018
- 問題文: DOE-HDBK-1224-2018が、高温でのTBP熱分解により生じる主要な可燃性ガス源として挙げる物質はどれか。
- 選択肢: ["二酸化炭素", "1-ブテン", "窒素", "水蒸気"]
- 正答選択肢: B
- 正答: 1-ブテン
- 解説: DOEは、130℃を超える高温でTBPが熱分解して1-ブテンとリン酸を生じ、1-ブテンが可燃性ガスの主要な源になるとしている。CO2、N2、水蒸気は可燃性ガスではない。
- 出典: https://www.energy.gov/documents/doe-hdbk-1224-2018pdf
- verified: true

### ACC-03-Q019
- 問題文: レッドオイル反応で発生し得る窒素酸化物について正しいものはどれか。
- 選択肢: ["酸素だけが発生しNOxは生じない", "ヘリウムだけが発生する", "NOやNO2等のNOxが生成・放出され得る", "アルゴンだけが発生する"]
- 正答選択肢: C
- 正答: NOやNO2等のNOxが生成・放出され得る
- 解説: DOEは、レッドオイルの赤色油状中間体が硝化化合物でありNOxを多量に生じ得ること、反応生成物としてNO、N2O等も挙げている。希ガスだけが生成する反応ではない。
- 出典: https://www.energy.gov/documents/doe-hdbk-1224-2018pdf
- verified: true

### ACC-03-Q020
- 問題文: 蒸発缶でレッドオイル事故を防止する運転管理として最も適切なものはどれか。
- 選択肢: ["有機溶媒の混入量を増やし、できるだけ過濃縮する", "温度制限を外し、乾固直前まで加熱する", "硝酸濃度だけを高め、TBP混入は無視する", "TBP等の有機溶媒の混入・蓄積を防ぎ、過濃縮と過度の温度上昇を避ける"]
- 正答選択肢: D
- 正答: TBP等の有機溶媒の混入・蓄積を防ぎ、過濃縮と過度の温度上昇を避ける
- 解説: 1953年Savannah River Site事故では有機溶媒混入と過濃縮・高温が重なった。JAEA資料は事故後の対策としてTBP等の混入回避、温度制限、蓄積防止等を挙げている。過濃縮や高酸濃度化は安全策ではない。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_04-10-03-03.html
- verified: true

### ACC-03-Q021
- 問題文: 高温が工程上不可避な脱硝器・か焼器でのレッドオイル事故防止として、DOE資料が示す考え方に最も適切なものはどれか。
- 選択肢: ["高温工程へTBPを持ち込まないことを重要な防止策とする", "TBPを多量添加して反応熱を利用する", "ベントを閉鎖してガスを保持する", "硝酸濃度を最大化して反応を安定化する"]
- 正答選択肢: A
- 正答: 高温工程へTBPを持ち込まないことを重要な防止策とする
- 解説: DOEは1975年A-Line事故について、か焼工程では高温自体が必要であったため、安全はTBPを装置へ入れないことに依存したと整理している。高温工程へのTBP持込みは危険側である。
- 出典: https://www.energy.gov/documents/doe-hdbk-1224-2018pdf
- verified: true

### ACC-03-Q022
- 問題文: DOEのレッドオイル事故防止方針に明確に反する操作の組合せはどれか。
- 選択肢: ["TBP量を制限し、十分なベントを確保する", "硝酸濃度を上げ、同時にベント能力を低下させる", "冷却能力を確保し、温度を監視する", "酸濃度を制限し、必要に応じて撹拌と蒸発冷却を維持する"]
- 正答選択肢: B
- 正答: 硝酸濃度を上げ、同時にベント能力を低下させる
- 解説: DOEは酸濃度制限、十分なベント、冷却・温度管理、TBP量制限を予防策としている。酸濃度上昇とベント能力低下を同時に行うのは両方とも危険側への変更である。
- 出典: https://www.energy.gov/documents/doe-hdbk-1224-2018pdf
- verified: true

### ACC-03-Q023
- 問題文: レッドオイル反応容器に十分なベントを設けても残る可能性がある危険として、1975年事故の教訓に合うものはどれか。
- 選択肢: ["ベントがあれば全ての化学反応が停止する", "ベントがあれば放射性・化学的放出は物理的に不可能になる", "放出された可燃性ガスが室内等で着火し、火災又はデフラグレーションを起こす", "ベントにより硝酸が必ず無害な水へ変化する"]
- 正答選択肢: C
- 正答: 放出された可燃性ガスが室内等で着火し、火災又はデフラグレーションを起こす
- 解説: DOEは、適切なベントが一次容器の過圧破損防止に有効でも、ベントされた可燃性ガスのフラッシュ火災・デフラグレーションを評価する必要があるとしている。1975年事故はその具体例である。
- 出典: https://www.energy.gov/documents/doe-hdbk-1224-2018pdf
- verified: true

### ACC-03-Q024
- 問題文: レッドオイル事故を未然に防ぐための温度・組成管理として最も適切なものはどれか。
- 選択肢: ["圧力上昇後だけ確認し、温度と酸濃度は管理しない", "TBP量だけを増やし、酸濃度は高いほどよいとする", "高温化してからベントを閉じ、反応中間体を保持する", "温度上昇、酸濃度、TBP混入・蓄積を継続的に管理し、危険条件へ近づく前に加熱・供給等を是正する"]
- 正答選択肢: D
- 正答: 温度上昇、酸濃度、TBP混入・蓄積を継続的に管理し、危険条件へ近づく前に加熱・供給等を是正する
- 解説: レッドオイル反応は温度と硝酸濃度の上昇、TBP存在量、密閉性に強く依存する。したがって事故防止は暴走後の対応だけでなく、温度・組成・TBP量・ベント状態を危険域に入る前から管理することが基本である。
- 出典: https://www.energy.gov/documents/doe-hdbk-1224-2018pdf ; https://atomica.jaea.go.jp/data/detail/dat_detail_06-01-05-06.html
- verified: true
