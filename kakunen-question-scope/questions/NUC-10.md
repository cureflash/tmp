## 問題

### NUC-10-Q001
- 問題文: JAEA ATOMICAの定義に照らした「核分裂生成物（FP）」の説明として正しいものはどれか。
- 選択肢: ["核分裂で直接できた核種、およびそれらの放射性壊変で生じた核種", "中性子捕獲で生成した超ウラン元素だけ", "原子炉構造材の放射化で生じた核種だけ", "天然に存在する安定同位体だけ"]
- 正答選択肢: A
- 正答: 核分裂で直接できた核種、およびそれらの放射性壊変で生じた核種
- 解説: ATOMICAはFPを、核分裂によってできた核種またはその核分裂片から放射性壊変によって生じた核種と定義している。中性子捕獲で生成する超ウラン元素、構造材の放射化生成物、天然安定同位体だけを指す語ではない。
- 出典: https://atomica.jaea.go.jp/dic/detail/dic_detail_763.html
- verified: true

### NUC-10-Q002

- 選択肢: ["20～40 と 50～70", "90～110 と 130～150 前後", "170～190 と 210～230", "240～250 の単一領域"]

- 正答: 90～110 と 130～150 前後

### NUC-10-Q003
- 問題文: 核分裂直後の多くの核分裂生成物が安定核種へ近づく際の代表的な壊変として正しいものはどれか。
- 選択肢: ["α壊変だけを繰り返す", "陽電子放出だけを繰り返す", "中性子過剰のためβ−壊変を重ねる", "壊変せず全て直ちに安定核種となる"]
- 正答選択肢: C
- 正答: 中性子過剰のためβ−壊変を重ねる
- 解説: JAEAは核分裂生成物について、その質量数の核として中性子過剰であるため、多くが数回のβ壊変を経て安定核種へ移行すると説明している。A、B、Dはこの一般的挙動と一致しない。

### NUC-10-Q020
- 問題文: 使用済燃料の硝酸溶解・再処理におけるMo-Tc-Ru-Rh-Pd金属析出物の影響として、JAEA資料に合う説明はどれか。
- 選択肢: ["硝酸溶解ですべて瞬時に気化するため残渣を作らない", "全量がUO2結晶へ再固溶して溶解液に現れない", "必ず全量が回収Pu製品へ移る", "硝酸に溶け残り、不溶解残渣の金属相成分となり得る"]
- 正答選択肢: D
- 正答: 硝酸に溶け残り、不溶解残渣の金属相成分となり得る
- 解説: JAEA-Research 2007-002は不溶解残渣中Ruの形態の一つとして、使用済燃料中に生成したMo-Tc-Ru-Rh-Pd合金粒子の解け残りを挙げる。JAERI-Review 2001-038もこれら金属成分の硝酸溶解性を扱っており、再処理では不溶解残渣管理に関係する。A～Cはこの挙動と矛盾する。
