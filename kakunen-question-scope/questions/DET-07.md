## 出題根拠

対象論点は、TLD、OSL、蛍光ガラス線量計、電子式線量計、フィルムバッジ、および再読出し・リアルタイム性。TLDは熱ルミネッセンス読出しで積算情報が消失する一方、OSLは光刺激で一部の捕獲電子を解放するため繰り返し読出しができ、蛍光ガラス線量計はRPLを利用して読取りによるデータ消失がない。フィルムバッジは写真フィルムの黒化と現像を利用し、電子式線量計は直読・警報・通信を作業管理に利用できる。正答だけでなく各誤答肢も、これらの公的資料と矛盾することを確認した問題だけを `verified: true` とした。

## 問題

### DET-07-Q001
- 問題文: 熱刺激による発光を利用して積算線量を評価する個人線量計はどれか。
- 選択肢: ["熱ルミネッセンス線量計（TLD）", "OSL線量計", "蛍光ガラス線量計", "電子式線量計"]
- 正答選択肢: A
- 正答: 熱ルミネッセンス線量計（TLD）
- 解説: TLDは固体の熱ルミネッセンス現象を利用し、放射線照射で蓄えられた情報を加熱による発光として読み出す。OSLは光刺激、蛍光ガラス線量計はラジオフォトルミネッセンス（RPL）、電子式線量計は半導体検出器等を用いた電子的な直読方式であり、熱刺激発光を原理としない。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-03-03.html ; https://www.nra.go.jp/data/000472261.pdf

### DET-07-Q003
- 問題文: 光刺激によって蓄積情報の一部を発光として読み出し、繰り返し測定が可能な個人線量計はどれか。
- 選択肢: ["フィルムバッジ", "熱ルミネッセンス線量計（TLD）", "OSL線量計", "電子式線量計"]
- 正答選択肢: C
- 正答: OSL線量計
- 解説: OSL線量計では光刺激で解放される捕獲電子が全体の一部であるため、繰り返し測定が可能である。TLDは1回の測定で積算線量情報が消失し、フィルムは現像を要する。電子式線量計は直読可能だが、OSLの発光機構による再読出しではない。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-03-03.html ; https://atomica.jaea.go.jp/dic/detail/dic_detail_2203.html
- verified: true

### DET-07-Q004

### DET-07-Q005

- 選択肢: ["被ばく後から現像までの時間が長いほど黒化に寄与する潜像が減少しやすく、高温高湿ほどその影響が大きい", "現像後のフィルムを低温保存すると黒化度が必ず増加し続ける現象である", "OSL材料に光を当てると捕獲電子が増加し続ける現象である", "TLDを加熱すると積算線量情報が保存され続ける現象である"]
- 正答選択肢: A
- 正答: 被ばく後から現像までの時間が長いほど黒化に寄与する潜像が減少しやすく、高温高湿ほどその影響が大きい
- 解説: JAEA/ATOMICAはフィルムの潜像退行を、照射で生じた潜像が時間経過や温湿度の影響で消失して黒化濃度が低下する現象とし、一般に高温高湿ほど著しいと説明している。B～Dは潜像退行の説明ではない。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-03-03.html

### DET-07-Q019
- 問題文: JAEA/ATOMICAの『基本線量計』と『補助線量計』の説明に合うものはどれか。
- 選択肢: ["基本線量計はその場で警報を鳴らす用途だけに限定され、積算記録には用いない", "補助線量計は必ず1～3か月間返却せず装着し、作業中には読み取れない", "基本線量計には一定期間の公式な積算線量記録に用いる受動形があり、補助線量計には作業ごとにその場で読める線量計やアラームメータがある", "基本線量計と補助線量計は測定目的が完全に同一で、使い分ける理由はない"]
- 正答選択肢: C
- 正答: 基本線量計には一定期間の公式な積算線量記録に用いる受動形があり、補助線量計には作業ごとにその場で読める線量計やアラームメータがある
- 解説: JAEA/ATOMICAは、一定期間連続して使用し公式な被ばく線量の記録に用いるものを基本線量計、作業ごとの管理で使用者が現場で値を読める線量計や警報を利用するものを補助線量計の例としている。A、B、Dは役割を逆転または同一視している。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-03-03.html
- verified: true

### DET-07-Q020
- 問題文: 個人線量計を選択する際の検討事項としてJAEA/ATOMICAの説明に最も合うものはどれか。
- 選択肢: ["測定器の外観だけを基準にし、放射線の種類やエネルギーは考慮しない", "どの作業でも1種類の線量計だけを必ず使用し、組合せ使用は避ける", "作業場所の線量率の時間変動や温湿度は線量計選択に影響しない", "測定目的、放射線の種類・エネルギー、線量率の時間変動、環境条件などを検討して選ぶ"]
- 正答選択肢: D

- 解説: JAEA/ATOMICAは個人線量計の選択基準として、測定目的、放射線の種類とエネルギー、線量率の時間的変動、温湿度や化学物質などの環境条件を挙げ、必要に応じて異なる線量計を組み合わせるとしている。A～Cはこの選択基準に反する。

### DET-07-Q024
- 問題文: 個人線量計の再読出し・リアルタイム性に関する組合せとして正しいものはどれか。
- 選択肢: ["TLDは読出し後も同じ積算情報を保持し、フィルムは現像前でもリアルタイムに警報できる", "OSLは1回の読出しで情報が必ず全消失し、電子式は装着中に値を表示できない", "蛍光ガラスは読出しで情報が消失し、TLDは無処理で何度でも同じ値を再読出しできる", "蛍光ガラスは読出しでデータが消失せず、OSLは繰り返し読出しが可能で、電子式は直読・警報に利用できる"]
- 正答選択肢: D
- 正答: 蛍光ガラスは読出しでデータが消失せず、OSLは繰り返し読出しが可能で、電子式は直読・警報に利用できる
- 解説: 蛍光ガラス線量計は読取りによるデータ消失がなく、OSLは光刺激で一部の捕獲電子のみを解放するため繰り返し測定が可能である。電子式はデジタル直読と警報に利用できる。一方、TLDは読出しで積算線量情報が消失するためA～Cはいずれかの対応が逆である。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-03-03.html ; https://www.nra.go.jp/data/000186633.pdf
- verified: true
