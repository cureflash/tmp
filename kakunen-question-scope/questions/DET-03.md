# DET-03 GM計数管

- status: complete
- verified_at: 2026-09-12
- question_count: 24
- correct_index_distribution: A=6, B=6, C=6, D=6
- authority: JAEA原子力科学研究所、日本分析センター、JEMIMAの公開技術資料を主な技術authorityとし、NRA第56～58回核燃料取扱主任者試験の放射線科目を確認した。第56回ではGM管式サーベイメータのγ線検出割合、第57回ではGM計数管の不感時間・数え落とし・窒息・プラトー、第58回では分解時間100 μsのGM計数管の数え落とし補正が出題されている。過去問本文は転載していない。

## 出題根拠

対象論点は、ガイガー放電、エネルギー情報を持たないこと、高感度、不感時間、数え落とし、窒息現象、サーベイメータとしての用途。JAEAのサーベイメータ解説、日本分析センターのGM計数管解説、JEMIMA放射線計測ガイドを用いて正答と全誤答肢を照合した。

## 問題

### DET-03-Q001
- 問題文: GM計数管の基本的な検出原理として正しいものはどれか。
- 選択肢: ["放射線による電離をきっかけに管内で放電を起こし、そのパルスを計数する", "放射線による温度上昇だけを熱電対で測定する", "放射線による結晶発光だけを光電子増倍管なしで測定する", "放射線による写真乳剤の黒化度だけを連続測定する"]
- 正答選択肢: A
- 正答: 放射線による電離をきっかけに管内で放電を起こし、そのパルスを計数する
- 解説: GM計数管では、放射線により生じた電離を起点に放電が起こり、その放電パルスを計数する。熱量測定、シンチレーション発光、写真黒化とは原理が異なる。
- 出典: https://www.jaea.go.jp/04/ntokai/houkan/monitor/b_2.html ; https://www.jcac.or.jp/site/faq/method-fish-description-4.html
- verified: true

### DET-03-Q003
- 問題文: ガイガー放電が自己連鎖的に広がる機構として最も適切なものはどれか。

- 正答選択肢: C
- 正答: 励起分子が放つ紫外線が光電子を生じ、それが次の電子なだれを起こす
