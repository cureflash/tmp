## 出題根拠

対象論点は、放射性物質漏えい時の内部被ばく、放射性エアロゾル、表面汚染、汚染拡大防止、呼吸保護、身体・表面汚染検査、除染である。

JAEAの燃料研究棟汚染事例では、核燃料物質を収納した容器の点検中に封入袋が破損し、作業員の手足の汚染、鼻腔内汚染、空気中放射性物質濃度の上昇が確認された。事象後には身体サーベイ、肺モニタ測定、排泄物分析、区域の立入制限、排気ダストモニタやモニタリングポストによる監視が行われており、漏えい時の「汚染確認→拡大防止→内部被ばく評価→除染・監視」の考え方を確認できる。

JAEAのαエアロゾル監視技術の資料では、燃料デブリ切断等で放射性微粒子が空気中に飛散し、吸入による内部被ばくを防ぐには発生源近傍で空気中濃度を監視することが重要とされている。また、排気系のみでの監視では検出に時間差が生じ得ること、従来のα線用ダストモニタはろ紙に粒子を捕集して測定することが説明されている。

JAEAのグリーンハウス（GH）資料では、身体汚染者の汚染検査・除染時に周囲への汚染拡大を防止するため仮設の密閉区画を用いること、局所排気によりGH外より低い圧力を保ち、出口側から入口側へ空気流を形成すること、ダストモニタで空気中放射性物質濃度を監視することが説明されている。

JAEAの放射線管理資料では、エリアモニタは線量当量率、空気モニタは管理区域内の空気中放射能濃度、排気モニタは排気筒から放出される放射性物質濃度を監視する役割を持つ。表面汚染については、JAEAのスミヤ測定資料で、スミヤろ紙を対象物表面に擦りつけて表面汚染を採取する方法が示されている。

呼吸保護については、JAEAの全面マスク資料で、面体と顔面との気密性が防護性能に重要であり、通常の眼鏡のテンプル等で隙間が生じると防護係数が低下し、汚染吸入の危険が高まることが示されている。ATOMICAの放射線防護機材資料も、表面汚染には手袋・防護衣、空気汚染には呼吸保護具を用いるという基本的な役割分担を示している。

## 問題

### ACC-09-Q001
- 問題文: プルトニウム等を含む放射性エアロゾルが漏えいした作業環境で、内部被ばくにつながる主要な経路として最も直接的なものはどれか。
- 選択肢: ["放射性エアロゾルを吸入する", "床面からのγ線だけを外部から受ける", "遮へい体の外側に立つ", "密封された容器を遠隔監視する"]
- 正答選択肢: A
- 正答: 放射性エアロゾルを吸入する
- 解説: JAEAは、空気中のα線放出放射性微粒子を吸入した場合に内部被ばくの影響が大きくなるため、その濃度監視が重要としている。外部γ線被ばくは内部摂取ではなく、遮へい体外側での待機や密封容器の遠隔監視は摂取経路ではない。
- 出典: https://www.jaea.go.jp/02/press2022/p22051902/

### ACC-09-Q002
- 問題文: 核燃料物質の飛散事故後、作業員の鼻腔内から放射性物質が検出された場合の解釈として最も適切なものはどれか。
- 選択肢: ["外部被ばくしか起きていないことを示す", "吸入による内部取り込みの可能性を考え、内部被ばく評価を行う根拠になる", "床面汚染が存在しないことを示す", "排気系から施設外へ必ず放出されたことを示す"]
- 正答選択肢: B
- 正答: 吸入による内部取り込みの可能性を考え、内部被ばく評価を行う根拠になる
- 解説: 燃料研究棟事象では鼻腔内汚染が確認され、その後、肺モニタや便・尿中のPu、Am分析による内部被ばく評価が行われた。鼻腔内汚染は外部被ばくだけを示すものではなく、床面汚染の有無や施設外放出を直接証明するものでもない。
- 出典: https://www.jaea.go.jp/02/press2017/p17060601/ ; https://www.jaea.go.jp/02/press2017/p17060701/
- verified: true

### ACC-09-Q003
- 問題文: プルトニウムを含む粉じんを吸入した可能性がある作業員について、肺に存在する放射性物質を直接的に評価する目的で用いられるものはどれか。
- 選択肢: ["エリアモニタ", "排気モニタ", "肺モニタ", "表面汚染用スミヤろ紙"]

- 正答: 肺モニタ
- 解説: 燃料研究棟事象では、作業員の内部被ばく評価の一環として肺モニタによるPu-239、Am-241の測定が実施された。エリアモニタは空間の放射線レベル、排気モニタは排気中放射性物質、スミヤは表面汚染の採取に用いる。
- 出典: https://www.jaea.go.jp/02/press2017/p17060701/ ; https://www.jaea.go.jp/04/ntokai/houkan/houkan_01.html ; https://www.jaea.go.jp/02/press2018/p19022202/

### ACC-09-Q004
- 問題文: 放射線防護上「放射性エアロゾル」として扱う対象の説明として最も適切なものはどれか。
- 選択肢: ["遮へい体を透過するγ線そのもの", "床面に固定され空気中へ移動しない固体表面そのもの", "放射性物質を含まない水蒸気だけ", "空気中に浮遊する放射性物質を含む微粒子"]
- 正答選択肢: D
- 正答: 空気中に浮遊する放射性物質を含む微粒子
- 解説: JAEAは、燃料デブリ切断等で発生し空気中に飛散する放射性微粒子をエアロゾルとして扱い、吸入内部被ばく防止のため濃度監視を行っている。γ線そのものや固定表面、水蒸気だけはこの定義の放射性微粒子ではない。
- 出典: https://www.jaea.go.jp/02/press2022/p22051902/
- verified: true

### ACC-09-Q005
- 問題文: 核燃料が付着した物体の切断・解体作業で、空気汚染管理上特に注意すべき現象はどれか。
- 選択肢: ["切断により放射性微粒子が発生し、空気中へ飛散する", "切断すると放射性物質が必ず非放射性化する", "切断すると空気中の微粒子が完全に消失する", "切断中は表面汚染だけが問題で、吸入経路は存在しない"]
- 正答選択肢: A
- 正答: 切断により放射性微粒子が発生し、空気中へ飛散する
- 解説: JAEAは、燃料デブリや核燃料物質が付着した機器の切断で微粒子状の放射性エアロゾルが飛散し得るため、閉じ込めと空気中濃度の監視が必要としている。切断で放射能が消えるわけではなく、吸入経路も無視できない。
- 出典: https://www.jaea.go.jp/02/press2022/p22051902/
- verified: true

### ACC-09-Q006
- 問題文: 放射性エアロゾル発生作業で、発生源近傍の空気モニタリングが排気系末端だけの監視より有利な理由として最も適切なものはどれか。
- 選択肢: ["排気系では放射性物質を一切測定できないから", "異常な濃度上昇をより早く把握し、作業員の吸入リスク低減に結び付けやすいから", "発生源近傍では放射線検出器が不要になるから", "空気モニタリングを行えば閉じ込め設備が不要になるから"]
- 正答選択肢: B
- 正答: 異常な濃度上昇をより早く把握し、作業員の吸入リスク低減に結び付けやすいから
- 解説: JAEAは、排気系での測定では発生箇所から検出まで時間差が生じる可能性があり、現場近傍でリアルタイム監視できれば内部被ばくの未然防止に有効としている。排気系でも測定は可能であり、監視は閉じ込め設備の代替ではない。
- 出典: https://www.jaea.go.jp/02/press2022/p22051902/
- verified: true

### ACC-09-Q007
- 問題文: スミヤ法の目的として最も適切なものはどれか。
- 選択肢: ["作業員の肺に取り込まれた核種を直接測定する", "排気筒からの放出量だけを連続測定する", "対象物表面をろ紙で拭き取り、表面汚染を採取して評価する", "空間線量率だけを測定する"]
- 正答選択肢: C
- 正答: 対象物表面をろ紙で拭き取り、表面汚染を採取して評価する

- 出典: https://www.jaea.go.jp/02/press2018/p19022202/
- verified: true

### ACC-09-Q008
- 問題文: α線放出核種による表面汚染を調べる際、通常のZnS(Ag)サーベイメータのみでは困難とJAEAが説明している事項はどれか。
- 選択肢: ["α線を一切検出すること", "表面に汚染があるかどうかを計数率で確認すること", "検出器を汚染面へ近づけること", "検出したα線のエネルギー情報から核種を識別し、粒子の位置分布まで特定すること"]

- 正答: 検出したα線のエネルギー情報から核種を識別し、粒子の位置分布まで特定すること
- 解説: JAEAは、市販ZnS(Ag)サーベイメータではα線の計数率は測定できる一方、エネルギー測定や粒子位置分布の特定ができず、天然核種とPu・U等の識別が困難と説明している。
- 出典: https://www.jaea.go.jp/02/press2018/p19022202/
- verified: true

### ACC-09-Q010

### ACC-09-Q011
- 問題文: グリーンハウスで汚染拡大防止のため局所排気装置を使用する際の考え方として正しいものはどれか。
- 選択肢: ["GH内を外周より高圧にして汚染空気を外へ押し出す", "空気の流れを設けず完全静止させる", "GH内を外周より低圧にし、清浄側から汚染側へ向かう空気流を形成する", "局所排気装置を使うとダストモニタは測定不能になる"]
- 正答選択肢: C
- 正答: GH内を外周より低圧にし、清浄側から汚染側へ向かう空気流を形成する
- 解説: JAEAは局所排気によりGH内を外周より低圧に保ち、出口側から入口側へ空気を流すことでGH外への汚染拡大を防止するとしている。正圧化して押し出す方法や無風化は逆であり、局所排気とダストモニタは併用される。
- 出典: https://www.jaea.go.jp/02/press2020/p21012202/
- verified: true

### ACC-09-Q024
