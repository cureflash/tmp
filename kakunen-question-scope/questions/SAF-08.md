## 問題

### SAF-08-Q001
- 問題文: 閉じ込めの考え方でいう「静的閉じ込め」の説明として最も適切なのはどれか。
- 選択肢: ["気密性を持つ容器・機器・壁などの物理的な境界で放射性物質の漏えいを抑える", "室内を外気より高い圧力にして放射性物質を外へ押し出す", "排気中濃度を測定するだけで物理的な境界を設けない", "放射性物質を水で希釈して閉じ込めの代わりとする"]
- 正答選択肢: A
- 正答: 気密性を持つ容器・機器・壁などの物理的な境界で放射性物質の漏えいを抑える
- 解説: JAEAのトリチウムプロセス研究棟では、第1次閉じ込め系を実験装置・貯蔵設備等の気密構造としている。これは物理的境界による静的閉じ込めの典型である。正圧化、監視だけ、希釈は物理的境界による閉じ込めではない。
- 出典: https://www.jaea.go.jp/04/ntokai/hot/hot_07.html
- verified: true

### SAF-08-Q002
- 問題文: 閉じ込めの考え方でいう「動的閉じ込め」の説明として最も適切なのはどれか。
- 選択肢: ["容器の肉厚だけで漏えいを防ぐこと", "負圧や所定の風向を維持し、漏えい時の空気の流れを管理すること", "放射線を鉛で遮蔽することだけ", "核燃料物質の質量を臨界未満に制限すること"]
- 正答選択肢: B
- 正答: 負圧や所定の風向を維持し、漏えい時の空気の流れを管理すること
- 解説: JAEAのトリチウムプロセス研究棟では、第2次閉じ込め系のグローブボックス・フードと第3次閉じ込め系の実験室で負圧維持・風向維持を行っている。これは換気による動的閉じ込めに相当する。肉厚は静的境界、遮蔽は外部被ばく低減、質量制限は臨界安全であり別機能である。
- 出典: https://www.jaea.go.jp/04/ntokai/hot/hot_07.html
- verified: true

### SAF-08-Q003
- 問題文: 加工施設の技術基準に関する規則に照らし、プルトニウム等を取り扱うグローブボックスに要求される構造として正しいものはどれか。
- 選択肢: ["内部を常時正圧に維持し、給気口だけを開放する", "内部圧力は室圧と同じにし、全面を開放可能とする", "内部を常時負圧状態に維持でき、給気口・排気口を除き密閉できる", "圧力管理をせず、排気口も設けない"]
- 正答選択肢: C
- 正答: 内部を常時負圧状態に維持でき、給気口・排気口を除き密閉できる
- 解説: 現行の加工施設の技術基準に関する規則第10条は、プルトニウム等を取り扱うグローブボックスについて、内部を常時負圧状態に維持でき、給気口・排気口を除き密閉できる構造を要求している。正圧、室圧同等、圧力管理なしはいずれも要求と反する。
- 出典: https://laws.e-gov.go.jp/law/502M60080000006
- verified: true

### SAF-08-Q004
- 問題文: 液体状のプルトニウム等を取り扱うグローブボックスについて、技術基準上の要求として正しいものはどれか。
- 選択肢: ["液体を床へ排出できる開口を常時設ける", "漏えいしても室内で回収できればグローブボックス外への漏えいを許容する", "液体の漏えい防止より換気量を優先し、底部は開放する", "液体状のプルトニウム等がグローブボックス外に漏えいするおそれがない構造とする"]
- 正答選択肢: D
- 正答: 液体状のプルトニウム等がグローブボックス外に漏えいするおそれがない構造とする
- 解説: 加工施設の技術基準に関する規則第10条は、液体状のプルトニウム等を取り扱うグローブボックスを、当該物質がグローブボックス外に漏えいするおそれがない構造とすることを求める。外部への漏えいを許容する設計や底部開放は要求に反する。
- 出典: https://laws.e-gov.go.jp/law/502M60080000006
- verified: true

### SAF-08-Q005
- 問題文: 密封されていない核燃料物質等をフードで取り扱う場合、技術基準上の要点はどれか。
- 選択肢: ["フード開口部の風速を適切に維持できること", "フード内部を常に大気圧より高くすること", "開口部の風速をゼロにすること", "フードを局所排気に接続しないこと"]
- 正答選択肢: A
- 正答: フード開口部の風速を適切に維持できること
- 解説: 加工施設の技術基準に関する規則第10条は、密封されていない核燃料物質等を取り扱うフードについて開口部の風速を適切に維持できることを求める。JAEAもフードを、非密封放射性物質を扱う際に作業者・環境の汚染防止に用いる局所排気装置としている。
- 出典: https://laws.e-gov.go.jp/law/502M60080000006 ; https://www.jaea.go.jp/04/o-arai/PFRF/glossary.html
- verified: true

### SAF-08-Q006
- 問題文: プルトニウム等を取り扱う室（保管廃棄する室を除く。）や、核燃料物質等による汚染発生のおそれがある室の圧力管理として適切なのはどれか。
- 選択肢: ["外気より正圧に維持する", "内部を負圧状態に維持できるようにする", "圧力差を持たせないことを必須とする", "作業中だけ正圧、停止中だけ負圧とする"]
- 正答選択肢: B
- 正答: 内部を負圧状態に維持できるようにする
- 解説: 加工施設の技術基準に関する規則第10条は、該当する室を負圧状態に維持し得るものとすることを要求する。正圧や圧力差なしは、漏えい時に汚染空気を限定区域内へ留める方向と逆である。
- 出典: https://laws.e-gov.go.jp/law/502M60080000006
- verified: true

### SAF-08-Q007
- 問題文: 核燃料物質等により汚染された空気による放射線障害を防止する必要がある場所の換気設備について、技術基準に適合するのはどれか。
- 選択肢: ["通常換気に必要な最小限の能力だけあれば、放射線防護は考慮しなくてよい", "排気経路を持たず室内循環だけとする", "放射線障害を防止するために必要な換気能力を有する", "換気設備は汚染空気を意図的に隣室へ送る"]
- 正答選択肢: C
- 正答: 放射線障害を防止するために必要な換気能力を有する
- 解説: 加工施設の技術基準に関する規則の換気要求は、汚染空気による放射線障害を防止するために必要な換気能力を要求している。放射線防護を無視する換気、排気経路を持たない前提、汚染空気の隣室送気は趣旨に反する。
- 出典: https://laws.e-gov.go.jp/law/502M60080000006
- verified: true

### SAF-08-Q009

### SAF-08-Q010
- 問題文: 核燃料施設の換気系におけるHEPAフィルタの役割として最も適切なのはどれか。
- 選択肢: ["中性子を減速して臨界を防止する", "排気中の微粒子を高効率で除去し、放射性エアロゾルの施設外放出を抑える", "排気中の酸素をすべて除去する", "室圧を測定する検出器として用いる"]
- 正答選択肢: B
- 正答: 排気中の微粒子を高効率で除去し、放射性エアロゾルの施設外放出を抑える
- 解説: JAEAは、HEPAフィルタをガス中の微粒子を高効率で除去する設備とし、排気筒上流に位置して換気系の最終的な閉じ込め設備を担うと説明している。臨界防止材、酸素除去装置、圧力計ではない。
- 出典: https://rdreview.jaea.go.jp/review_jp/2023/j2023_11_5.html
- verified: true

### SAF-08-Q011
- 問題文: グローブボックス火災で生じる煤煙がHEPAフィルタに大量に到達した場合に留意すべき現象として適切なのはどれか。
- 選択肢: ["HEPAの捕集性能があるため圧力損失は必ずゼロになる", "煤煙量が増えるほどフィルタ差圧は必ず低下する", "煤煙負荷による目詰まりでフィルタ差圧が上昇し、換気・閉じ込め性能に影響し得る", "HEPAは気体流路にないため火災影響を受けない"]
- 正答選択肢: C
- 正答: 煤煙負荷による目詰まりでフィルタ差圧が上昇し、換気・閉じ込め性能に影響し得る
- 解説: JAEAはグローブボックス材料火災時のHEPAフィルタ目詰まり特性を評価し、煤煙負荷とHEPA差圧の関係を示している。HEPAは排気筒上流の換気系にあり、煤煙による目詰まりは無関係ではない。
- 出典: https://rdreview.jaea.go.jp/review_jp/2023/j2023_11_5.html

### SAF-08-Q012
- 問題文: JAEAのトリチウムプロセス研究棟に示される多重閉じ込めの組合せとして正しいものはどれか。

### SAF-08-Q013
- 問題文: 施設を複数の閉じ込め境界や区画で構成する主な安全上の狙いとして最も適切なのはどれか。
- 選択肢: ["一つの境界で漏えいが起きても、次の境界・区画で拡大を抑える", "全ての区画を常時同一圧力にして境界を無意味にする", "区画間の扉を常時開放して空気を自由に混合する", "換気系を介さず汚染空気を直接屋外へ放出する"]
- 正答選択肢: A
- 正答: 一つの境界で漏えいが起きても、次の境界・区画で拡大を抑える
- 解説: NRAのMOX燃料加工施設の設計整理では、一次バウンダリを漏えい防止、二次バウンダリを漏えいの拡大防止として整理している。JAEAの3重閉じ込めも同様に多層化している。境界の無効化、扉常時開放、直接放出はこの考え方に反する。
- 出典: https://www2.nra.go.jp/data/000464142.pdf ; https://www.jaea.go.jp/04/ntokai/hot/hot_07.html

### SAF-08-Q014

### SAF-08-Q015

### SAF-08-Q016

### SAF-08-Q017
- 問題文: JAEAの放射線管理施設で、空気モニタと排気モニタの役割の組合せとして正しいものはどれか。
- 選択肢: ["空気モニタは管理区域内の空気中放射能濃度、排気モニタは排気筒から放出される放射性物質濃度を評価する", "空気モニタは個人線量、排気モニタは臨界度を測定する", "空気モニタは排水pH、排気モニタは室温を測定する", "両者とも表面汚染だけを測定する"]
- 正答選択肢: A
- 正答: 空気モニタは管理区域内の空気中放射能濃度、排気モニタは排気筒から放出される放射性物質濃度を評価する
