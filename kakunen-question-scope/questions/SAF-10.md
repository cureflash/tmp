## 出題根拠

対象論点は、可燃物、有機溶媒、水素、粉末、着火源、防火区画、検知、消火、換気。NRA掲載の「加工施設の技術基準に関する規則」第11条引用部で、消火・自動検知警報、不燃・難燃材料、防火壁、水素設備の接地、可燃性ガスを滞留させない構造、加熱設備の熱的制限値、水素等を用いる焼結設備の爆発防止措置を確認した。NRA安全研究資料でMOX燃料加工施設のグローブボックス火災が放射性物質漏えいの観点から重要な事故シナリオであることを確認した。JAEAの2026年公表資料で放射線分解による水素発生と換気停止時の蓄積を、JAEA ATOMICAで再処理施設の有機溶媒・電気火災等の事故教訓を確認した。粉じん・水素の一般的な爆発特性は労働安全衛生総合研究所の公的技術資料で照合した。NRA公式の過去問公開ページで直近第58回（2026年）～第56回の問題公開を確認し、過去問本文は転載せず独立した4択問題を作成した。

## 問題

### SAF-10-Q001
- 問題文: 加工施設の火災防護について、NRAの基準が要求する基本的な考え方として最も適切なのはどれか。
- 選択肢: ["火災・爆発の発生防止、早期感知、消火、影響軽減を組み合わせる", "火災の発生防止だけを行い、発生後の対策は考えない", "消火設備だけを設ければ早期感知設備は不要である", "火災発生後は安全機能の維持を考慮しなくてよい"]
- 正答選択肢: A
- 正答: 火災・爆発の発生防止、早期感知、消火、影響軽減を組み合わせる
- 解説: NRAの加工施設基準では、火災又は爆発で安全性が損なわれないよう、発生防止、早期感知、消火、影響軽減を組み合わせる考え方を示している。いずれか一つだけで足りるとはしていないため、他の3肢は不適切である。
- 出典: https://www.nra.go.jp/data/000405021.pdf
- verified: true

### SAF-10-Q002
- 問題文: 加工施設の技術基準規則第11条でいう警報設備の説明として正しいものはどれか。
- 選択肢: ["作業員が目視した後に手動で連絡する設備だけをいう", "火災の発生を自動的に検知し、警報を発する設備を含む", "消火剤を放出する設備だけをいう", "放射線量だけを測定する設備をいう"]
- 正答選択肢: B
- 正答: 火災の発生を自動的に検知し、警報を発する設備を含む
- 解説: 第11条は、警報設備について自動火災報知設備、漏電火災警報器その他の火災発生を自動的に検知して警報を発するものと明示している。手動連絡のみ、消火設備のみ、放射線測定のみは定義に合わない。
- 出典: https://www2.nra.go.jp/data/000460082.pdf
- verified: true

### SAF-10-Q003
- 問題文: 火災用の消火設備・警報設備自体の故障等について、加工施設の技術基準規則が求める事項はどれか。
- 選択肢: ["故障時には必ず全施設を停止できることだけを求める", "設備の故障は火災時だけ考慮し、平常時は考慮しない", "故障、損壊又は異常な作動により安全上重要な施設の安全機能に著しい支障を及ぼさないこと", "消火設備の誤作動による影響は安全設計の対象外とする"]
- 正答選択肢: C
- 正答: 故障、損壊又は異常な作動により安全上重要な施設の安全機能に著しい支障を及ぼさないこと
- 解説: 第11条第2項は、消火設備及び警報設備の故障、損壊又は異常な作動が安全上重要な施設の安全機能に著しい支障を及ぼさないことを要求している。設備自体が新たな共通原因や機能喪失を生まないことが要点である。
- 出典: https://www2.nra.go.jp/data/000460082.pdf

### SAF-10-Q004
- 問題文: 火災又は爆発で損傷を受けるおそれがある安全機能を有する施設の材料・防護について、技術基準規則に適合するものはどれか。
- 選択肢: ["可燃性の高い材料を優先し、防火壁は設けない", "材料の燃焼性は問わず、消火器だけに依存する", "すべて木質材料とし、延焼後に復旧する", "可能な限り不燃性又は難燃性の材料を使用し、必要に応じて防火壁等の防護措置を講じる"]
- 正答選択肢: D
- 正答: 可能な限り不燃性又は難燃性の材料を使用し、必要に応じて防火壁等の防護措置を講じる
- 解説: 第11条第3項は、不燃性又は難燃性材料の使用と、必要に応じた防火壁その他の適切な防護措置を要求している。可燃材料を優先することや消火だけに依存する考え方ではない。
- 出典: https://www2.nra.go.jp/data/000460082.pdf

### SAF-10-Q005
- 問題文: 防火壁や防火区画を設ける主目的として最も適切なのはどれか。
- 選択肢: ["火災の延焼・影響の拡大を抑え、安全機能への影響を軽減する", "室内の可燃物量を増やす", "火災感知器を不要にする", "可燃性ガスを意図的に一か所へ集める"]
- 正答選択肢: A
- 正答: 火災の延焼・影響の拡大を抑え、安全機能への影響を軽減する
- 解説: NRAの加工施設資料は、防火壁・防火区画等を火災の拡大防止・影響軽減の措置として位置付けている。防火区画は感知や消火を不要にするものでも、可燃物や可燃性ガスを集積するためのものでもない。
- 出典: https://www.nra.go.jp/data/000405021.pdf

### SAF-10-Q006
- 問題文: NRA公開の加工施設適合性説明書に示される火災発生時の設備構成として適切なのはどれか。
- 選択肢: ["火災感知設備だけを設け、消火設備は設けない", "自動火災報知設備と、粉末消火器・消火栓等の消火設備を組み合わせる", "消火設備だけを設け、火災の早期感知は人の嗅覚だけに頼る", "放射線モニタを火災感知器の代替として用いるだけでよい"]
- 正答選択肢: B
- 正答: 自動火災報知設備と、粉末消火器・消火栓等の消火設備を組み合わせる
- 解説: NRA掲載の適合性説明書では、火災を早期に感知・報知する自動火災報知設備と、粉末消火器、屋内・屋外消火栓等の消火設備を組み合わせる設計が示されている。感知か消火の一方だけに依存するものではない。
- 出典: https://www.nra.go.jp/data/000405021.pdf

### SAF-10-Q007
- 問題文: 爆発の危険性がある水素を取り扱う設備について、加工施設の技術基準規則が明示している措置はどれか。
- 選択肢: ["水素設備は必ず木製架台に載せる", "水素設備では静電気対策を行わない", "適切に接地する", "水素濃度を高く保つため換気を停止する"]
- 正答選択肢: C
- 正答: 適切に接地する
- 解説: 第11条第4項は、爆発の危険性がある水素を取り扱う設備を適切に接地することを要求している。接地は着火源となり得る静電気への対策であり、他の選択肢は規則の方向と逆である。
- 出典: https://www2.nra.go.jp/data/000460082.pdf
- verified: true

### SAF-10-Q008

### SAF-10-Q010

### SAF-10-Q013
- 問題文: 再処理施設の高レベル放射性廃液で水素が発生する主な機構として正しいものはどれか。
- 選択肢: ["廃液中の水が放射線によって分解され、水素が生成する", "窒素が核分裂して水素だけになる", "換気装置が水素を化学合成する", "鉛遮蔽体が常温で水素を放出する"]
- 正答選択肢: A
- 正答: 廃液中の水が放射線によって分解され、水素が生成する
- 解説: JAEAは、高レベル放射性廃液に含まれる放射性核種からの放射線によって水が分解され、水素が継続的に生成されることを実廃液研究の背景として示している。他の3機構は同資料に基づく水素発生機構ではない。
- 出典: https://www.jaea.go.jp/02/press2026/p26052202/
- verified: true

### SAF-10-Q014
- 問題文: 高レベル放射性廃液の保管エリアで換気を行う水素安全上の目的として最も適切なのはどれか。
- 選択肢: ["廃液の放射能を換気だけでゼロにする", "廃液から出た水素が危険な濃度に達しないようにする", "水素を室内に均一に蓄積させる", "廃液の崩壊熱を発生させる"]
- 正答選択肢: B
- 正答: 廃液から出た水素が危険な濃度に達しないようにする
- 解説: JAEAは、保管エリアでは廃液から出た水素が危険な濃度に達しないよう換気を行うと説明している。換気は放射能を消滅させる設備でも、水素を蓄積させるための設備でもない。
- 出典: https://www.jaea.go.jp/02/press2026/p26052202/
- verified: true

### SAF-10-Q015
- 問題文: 高レベル放射性廃液の保管施設で停電等により換気が停止した場合に想定すべき現象はどれか。
- 選択肢: ["水素生成が瞬時に永久停止する", "換気停止だけで廃液中の放射性核種が消滅する", "廃液から発生する水素が保管場所に蓄積する可能性がある", "水素は換気停止と同時に全量が液中へ固定される"]
- 正答選択肢: C
- 正答: 廃液から発生する水素が保管場所に蓄積する可能性がある
- 解説: JAEAは、停電や設備故障で換気が停止すると、放射線分解で継続的に生成される水素が保管場所に滞留する可能性を想定する必要があるとしている。換気停止は放射線分解や放射能そのものを止めない。
- 出典: https://www.jaea.go.jp/02/press2026/p26052202/
- verified: true

### SAF-10-Q016
- 問題文: 水素と空気の混合気について、労働安全衛生総合研究所が示す着火可能な濃度範囲として正しいものはどれか。
- 選択肢: ["0.01～0.1 vol%", "1～2 vol%", "90～100 vol%", "4～75 vol%"]
- 正答選択肢: D
- 正答: 4～75 vol%
- 解説: 労働安全衛生総合研究所は、水素と空気の混合気が4～75 vol%という広い範囲で着火することを示している。したがって、水素漏えい時には濃度上昇を防ぐ換気・滞留防止が重要である。他の数値範囲は同資料の値ではない。
- 出典: https://www.jniosh.johas.go.jp/publication/mail_mag/2016/95-column-1.html
- verified: true

### SAF-10-Q017

- 選択肢: ["約0.02 mJ", "約2 J", "約200 J", "約20 kJ"]
