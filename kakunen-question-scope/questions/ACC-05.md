## 出題根拠

対象論点は、放射線分解等による水素発生、濃度管理、換気・掃気、着火源、爆発限界、事故影響及び発生・拡大防止策である。

JAEAは2026年5月、実高レベル放射性廃液を用いた測定結果を公表した。高レベル放射性廃液ではα線・β線・γ線による水の放射線分解で水素が継続的に生成され、停電等で換気と冷却が失われると水素蓄積と温度上昇が同時進行し得る。実測では吸収線量の増加に伴い水素総発生量が直線的に増加した。30℃では撹拌により水素の気相移行が促進され、静置時より気相への水素放出量が増えた。一方、撹拌条件下では30℃から沸騰温度まで明確な温度依存性は認められず、温度上昇自体が水素発生量を増加させるとの結果ではなかった。

NRA公開の六ヶ所再処理施設審査資料では、放射線分解で水素が生じる貯槽・濃縮缶を通常時に圧縮空気で掃気し、水素掃気機能喪失時には水素濃度の上昇を想定する。資料ではドライ換算4 vol%を可燃限界濃度とし、4～8 vol%では部分燃焼、8～12 vol%では爆燃、12 vol%超では条件により爆轟への遷移があり得るとしている。重大事故対策では未然防止濃度8 vol%に至る前に代替掃気を開始し、可燃限界濃度未満を維持する考え方が示されている。

現行の「再処理施設の位置、構造及び設備の基準に関する規則」第三十六条は、放射線分解により発生する水素による爆発について、発生防止、再発防止、換気系統の隔離・過圧時漏えい防止及び放射性物質放出影響の緩和に必要な設備を要求している。規則解釈は発生防止設備の例として、設計基準設備とは異なる圧縮空気供給、溶液回収・移送、水素掃気配管への窒素供給、水素燃焼設備等を示す。

DOE Hydrogen Programの公的資料では、水素の空気中可燃範囲を4～75 vol%、空気中の最小着火エネルギーを0.017 mJとする資料があり、水素は広い可燃範囲と低い着火エネルギーを持つため、十分な換気、漏えい検知、着火源管理、不活性ガスによるパージが重要とされている。

NRAの過去問公開ページで直近の第58回・第57回・第56回「核燃料物質の取扱いに関する技術」を確認し、公開検索で取得できた第58回・第56回の本文情報も出題形式の確認に用いた。過去問本文は転載せず、水素爆発・再処理施設安全の論点を独立した4択問題に再構成した。

## 問題

### ACC-05-Q001
- 問題文: 再処理施設の高レベル放射性廃液で、水素が継続的に生成される主な機構はどれか。
- 選択肢: ["放射線による廃液中の水の分解", "窒素ガスの自然分解", "TBPの燃焼だけによる生成", "冷却水ポンプの機械的摩擦による生成"]
- 正答選択肢: A
- 正答: 放射線による廃液中の水の分解
- 解説: JAEAは、高レベル放射性廃液中の放射性核種から出る放射線によって水が分解され、水素が常に生成されると説明している。窒素の自然分解、TBP燃焼だけ、ポンプ摩擦はいずれも同資料が示す高レベル放射性廃液の継続的な水素生成機構ではない。
- 出典: https://www.jaea.go.jp/02/press2026/p26052202/
- verified: true

### ACC-05-Q002
- 問題文: JAEAが高レベル放射性廃液中の水の放射線分解に関して示す放射線の組合せはどれか。
- 選択肢: ["α線だけ", "α線・β線・γ線", "中性子線だけ", "可視光だけ"]
- 正答選択肢: B
- 正答: α線・β線・γ線
- 解説: JAEAは、高レベル放射性廃液にα線・β線・γ線を放出する多様な放射性核種が溶けており、それらの放射線によって水が分解されると説明している。α線だけ、中性子線だけ、可視光だけとする選択肢はこの説明と一致しない。
- 出典: https://www.jaea.go.jp/02/press2026/p26052202/
- verified: true

### ACC-05-Q003
- 問題文: 高レベル放射性廃液を保管している間の水素生成について、JAEAの説明と一致するものはどれか。
- 選択肢: ["廃液が沸騰した瞬間だけ水素が生成される", "換気設備を運転した時だけ水素が生成される", "放射線の水分解により水素が継続的に生成される", "着火源が存在する時だけ水素が生成される"]
- 正答選択肢: C
- 正答: 放射線の水分解により水素が継続的に生成される
- 解説: JAEAは水素が放射線の水分解により継続的に生成・放出されるとしている。沸騰、換気運転、着火源の存在を水素生成開始の条件とはしておらず、他の3選択肢は誤りである。
- 出典: https://www.jaea.go.jp/02/press2026/p26052202/
- verified: true

### ACC-05-Q004
- 問題文: 高レベル放射性廃液保管施設で停電等により換気と冷却が同時に失われた場合、JAEAが想定すべきとしている状態はどれか。
- 選択肢: ["水素濃度と廃液温度が必ず同時に低下する", "水素生成が直ちに停止し、冷却だけが不要になる", "換気停止によって水素が必ず消滅する", "廃液温度の上昇と水素の蓄積が同時進行し得る"]
- 正答選択肢: D
- 正答: 廃液温度の上昇と水素の蓄積が同時進行し得る
- 解説: JAEAは、停電や設備故障で換気と冷却が同時に失われると、崩壊熱等による温度上昇と、水素の滞留・蓄積を同時に想定する必要があるとしている。温度低下、水素生成停止、水素消滅はいずれも同資料の説明と逆である。
- 出典: https://www.jaea.go.jp/02/press2026/p26052202/
- verified: true

### ACC-05-Q005
- 問題文: JAEAが実高レベル放射性廃液で測定した、吸収した放射線量と水素総発生量の関係として正しいものはどれか。
- 選択肢: ["吸収線量の増加に伴い水素総発生量は直線的に増加した", "吸収線量が増えるほど水素総発生量は必ずゼロに近づいた", "吸収線量と水素総発生量に関係は全くなかった", "一定線量を超えると水素総発生量は必ず負の値になった"]
- 正答選択肢: A
- 正答: 吸収線量の増加に伴い水素総発生量は直線的に増加した
- 解説: JAEAの実測では、温度等の条件が異なっていても、廃液が吸収した放射線量の増加に伴い水素の総発生量は直線的に増加した。減少、無関係、負値化とする他の選択肢はいずれも測定結果と一致しない。
- 出典: https://www.jaea.go.jp/02/press2026/p26052202/

### ACC-05-Q006
- 問題文: 30℃の実高レベル放射性廃液について、撹拌ありと静置を比較したJAEAの結果として正しいものはどれか。
- 選択肢: ["撹拌すると水素の気相移行が完全に止まった", "撹拌により水素が気相へ移行しやすくなり、気相への水素放出量が増えた", "静置時だけ放射線が存在した", "撹拌の有無で水素挙動は完全に同一だった"]
- 正答選択肢: B
- 正答: 撹拌により水素が気相へ移行しやすくなり、気相への水素放出量が増えた
- 解説: JAEAは、撹拌により液中に留まっていた水素が気相へ移行しやすくなり、測定される水素発生量が増加したとしている。気相移行停止、静置時のみ放射線存在、挙動完全同一はいずれも実測結果と矛盾する。
- 出典: https://www.jaea.go.jp/02/press2026/p26052202/
- verified: true

### ACC-05-Q007
- 問題文: JAEAの実測で、30℃の静置条件における水素発生量が撹拌条件より低くなった主な説明はどれか。

- 正答: 水素の一部が溶液中で消費され、気相へ出る量が抑えられるから
- 解説: JAEAは、静置条件では水素の一部が溶液中で消費され、気相への放出量が低く抑えられると説明している。放射性核種の全消滅、水の全蒸発、水素の窒素への核変換はいずれも同資料にない誤った説明である。
- 出典: https://www.jaea.go.jp/02/press2026/p26052202/
- verified: true

### ACC-05-Q008
- 問題文: 実高レベル放射性廃液を30℃から沸騰温度まで調べたJAEAの結果について、正しいものはどれか。
- 選択肢: ["温度上昇だけで水素発生量が必ず指数関数的に増加した", "沸騰すると放射線分解が完全に停止した", "温度を上げるほど水素発生量が必ず一定割合で増加した", "撹拌条件下では明確な温度依存性は認められず、温度上昇自体による増加は確認されなかった"]
- 正答選択肢: D
- 正答: 撹拌条件下では明確な温度依存性は認められず、温度上昇自体による増加は確認されなかった
- 解説: JAEAは、撹拌条件下で30℃から沸騰温度まで測定しても、水素発生量に明確な温度依存性は認められず、温度上昇自体が発生量を増やす結果ではなかったとしている。指数増加、完全停止、一定割合増加はいずれも実測結果と異なる。
- 出典: https://www.jaea.go.jp/02/press2026/p26052202/
- verified: true

### ACC-05-Q009
- 問題文: DOEの2023年Hydrogen Safety Reviewが示す、水素の空気中の可燃範囲として正しいものはどれか。
- 選択肢: ["4～75 vol%", "0.4～4 vol%", "5～15 vol%", "16～27 vol%"]
- 正答選択肢: A
- 正答: 4～75 vol%
- 解説: DOE資料の比較表では水素の空気中可燃範囲は4～75%である。同表で5～15%は天然ガス、16～27%はアンモニアであり、0.4～4%は水素の可燃範囲として示されていない。したがって正解は一意に4～75 vol%である。
- 出典: https://www.hydrogen.energy.gov/docs/hydrogenprogramlibraries/pdfs/review23/fe019_bayham_2023_p-pdf.pdf
- verified: true

### ACC-05-Q015

### ACC-05-Q024
- 問題文: 現行の再処理施設基準規則第三十六条に照らし、水素爆発発生後の放射性物質放出拡大を抑える考え方として正しいものはどれか。
