# RADL-07 外部被ばく管理

- status: complete
- verified_at: 2026-09-13
- question_count: 24
- authority: 作問時点で現行のe-Gov「電離放射線障害防止規則」（令和8年4月1日施行）を法令数値のauthorityとし、厚生労働省・JAEAの公的資料を外部被ばく管理実務の根拠とする

## 出題根拠

対象は `07_放射線防護・法定数値.md` の RADL-07（時間、距離、遮蔽、線量率、作業計画、サーベイ）。既存の RADL-01 で扱われた単純な時間比例、点線源の逆二乗則、時間・距離・遮蔽の一般論との重複を避け、作業前・作業中のサーベイ、作業環境モニタリング、作業計画、据付型エリアモニタと携帯型サーベイメータの役割、現行電離則第53・54条、線源除去、事前準備、直読式線量計、複数区間の線量予測を中心に新規作問した。

2026-09-13時点で、e-Govの電離放射線障害防止規則は令和8年4月1日施行版が現在施行であることを確認した。同規則第53・54条について、外部放射線の作業環境測定対象、原則一月以内ごとに1回の定期測定、一定条件で六月以内ごとに1回となる例外、記録の5年間保存、測定困難時の計算、結果の周知を確認した。

NRAの過去の資格試験問題公開ページで、第58回（2026年）、第57回（2025年）、第56回（2024年）の「放射線の測定及び放射線障害の防止に関する技術」を確認した。第58回では外部被ばく用個人線量計に関する論点が出題されているため、本topicでは同じ文章を転載せず、作業環境モニタリングと個人モニタリングの使い分け・作業管理への利用として新規問題化した。

## 問題

### RADL-07-Q001
- 問題文: 放射線作業を開始する前の外部被ばく管理として最も適切なものはどれか。
- 選択肢: ["作業場所の放射線場をサーベイし、線量率分布を把握して被ばく線量を予測する", "作業後にだけ線量率を測定し、事前の被ばく予測は行わない", "個人線量計を装着すれば作業環境の線量率測定は不要とする", "線量率を確認せず、作業時間だけを一律に決める"]
- 正答選択肢: A
- 正答: 作業場所の放射線場をサーベイし、線量率分布を把握して被ばく線量を予測する
- 解説: JAEAは、外部被ばく管理では作業者が立ち入る前に放射線場を把握するため作業環境モニタリングを行い、作業開始時の被ばく予測に用いるとしている。Bは事前把握を欠き、Cは環境モニタリングと個人モニタリングを混同し、Dは線量率を無視するため不適切である。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-04-03.html

### RADL-07-Q002
- 問題文: 外部放射線モニタリングの目的として正しいものはどれか。
- 選択肢: ["作業者の血液検査だけを行うこと", "作業環境の放射線レベルの異常確認、作業者線量の推定、作業計画上の防護方法・手順の検討に用いること", "放射性物質の化学組成だけを決定すること", "個人線量計の装着位置だけを決めること"]
- 正答選択肢: B
- 正答: 作業環境の放射線レベルの異常確認、作業者線量の推定、作業計画上の防護方法・手順の検討に用いること
- 解説: JAEAは外部放射線モニタリングの目的として、作業環境の異常確認、作業者線量の推定、放射線作業計画での防護手段・作業手順の検討、個人モニタリング用資料の収集を挙げている。A・C・Dはいずれも目的を不当に限定している。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-06-02.html
- verified: true

### RADL-07-Q003
- 問題文: 据付型エリアモニタと携帯型サーベイメータの使い分けとして正しいものはどれか。
- 選択肢: ["両者とも個人の積算線量だけを測るために用いる", "サーベイメータは固定点の連続監視にしか使用できない", "エリアモニタは特定位置の放射線レベルを連続監視し、サーベイメータは区域内外の詳細な線量率分布の確認に用いる", "エリアモニタがあれば局所的な線量率分布をサーベイする必要はない"]
- 正答選択肢: C
- 正答: エリアモニタは特定位置の放射線レベルを連続監視し、サーベイメータは区域内外の詳細な線量率分布の確認に用いる
- 解説: JAEAは、据付型エリアモニタを特定箇所の放射線レベル変動の連続監視、携帯型サーベイメータを管理区域内外の詳細な線量率モニタリングに用いるとしている。A・B・Dは両者の機能を取り違えている。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-06-02.html

### RADL-07-Q005
- 問題文: 現行の電離放射線障害防止規則第53条で、外部放射線の作業環境測定の対象として掲げられるものはどれか。
- 選択肢: ["放射線業務を行う作業場のうち管理区域に該当する部分", "事業場内のすべての事務室", "管理区域外のすべての休憩室", "放射線業務と無関係な屋外通路すべて"]
- 正答選択肢: A
- 正答: 放射線業務を行う作業場のうち管理区域に該当する部分
- 解説: 現行の電離則第53条第1号は「放射線業務を行う作業場のうち管理区域に該当する部分」を作業環境測定対象としている。B・C・Dのように放射線業務・管理区域との関係なく事業場全域を対象とする規定ではない。
- 出典: https://laws.e-gov.go.jp/law/347M50002000041
- verified: true

### RADL-07-Q006
- 問題文: 現行の電離放射線障害防止規則第54条により、同規則第53条第1号の管理区域で外部放射線による線量当量率又は線量当量を定期測定する原則的な頻度はどれか。
- 選択肢: ["一週間以内ごとに1回", "一月以内ごとに1回", "六月以内ごとに1回", "一年以内ごとに1回"]
- 正答選択肢: B
- 正答: 一月以内ごとに1回
- 解説: 現行の電離則第54条第1項は原則として一月以内ごとに1回の定期測定を求める。一定条件では六月以内ごとに1回とする例外があるが、Cを一般原則とするのは誤りで、A・Dも規定された原則頻度ではない。
- 出典: https://laws.e-gov.go.jp/law/347M50002000041
- verified: true

### RADL-07-Q007
- 問題文: 現行の電離放射線障害防止規則第54条で、外部放射線の定期測定を「六月以内ごとに1回」とできる条件の一つとして正しいものはどれか。

- 正答選択肢: C
- 正答: 放射線装置を固定して使用し、使用方法及び遮蔽物の位置が一定していること
- 解説: 現行の電離則第54条第1項は、放射線装置を固定使用し、使用方法及び遮蔽物の位置が一定の場合などに六月以内ごとに1回とする例外を定めている。A・B・Dは同項の例外条件ではない。
- 出典: https://laws.e-gov.go.jp/law/347M50002000041

### RADL-07-Q016
- 問題文: 作業中のサーベイで、事前予測より明らかに高い線量率上昇を確認した。外部被ばく管理として最も適切な対応はどれか。
- 選択肢: ["予測値を優先し、測定値を無視して作業を続ける", "線量率上昇を記録せず、作業終了後まで知らせない", "作業者を線源へ近づけて原因を確認させることを最優先する", "放射線場の変化を異常情報として扱い、退避・距離確保を含め作業条件と防護措置を再評価する"]
- 正答選択肢: D
- 正答: 放射線場の変化を異常情報として扱い、退避・距離確保を含め作業条件と防護措置を再評価する
- 解説: JAEAは作業環境モニタリングを被ばく予測だけでなく放射線に係る異常発見にも有効とし、作業中も環境の放射線レベル変化と個人モニタ情報を監視して安全上の助言を行うとしている。A・Bは異常情報を無視し、Cは不要な接近を招く。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-04-03.html ; https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-06-01.html

### RADL-07-Q023
- 問題文: 作業者が、線量率0.30 mSv/hの場所で20分、続いて0.06 mSv/hの場所で40分作業した。各区間で線量率が一定とすると、外部被ばく線量の概算として正しいものはどれか。
- 選択肢: ["0.06 mSv", "0.10 mSv", "0.14 mSv", "0.36 mSv"]
- 正答選択肢: C
- 正答: 0.14 mSv
- 解説: 線量は各区間の「線量率×時間」を足し合わせる。0.30 mSv/h×(20/60) h=0.10 mSv、0.06 mSv/h×(40/60) h=0.04 mSv、合計0.14 mSvである。A・Bは一部区間又は計算不足、Dは時間換算を誤った値である。JAEAは放射線場の把握と作業線量予測を外部被ばく管理に用いるとしている。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_09-04-04-03.html

### RADL-07-Q024
- 問題文: 同じ作業を行う2つの経路を比較する。経路Aは平均線量率0.20 mSv/hで15分、経路Bは平均線量率0.08 mSv/hで45分かかる。線量率が各経路で一定とすると、被ばく線量が小さい経路の判断として正しいものはどれか。
- 選択肢: ["経路B。線量率が低いので時間を考えなくても必ず小さい", "両経路とも0.20 mSvで同じ", "経路B。推定線量は0.12 mSvである", "経路A。推定線量は0.05 mSvで、経路Bの0.06 mSvより小さい"]
- 正答選択肢: D
- 正答: 経路A。推定線量は0.05 mSvで、経路Bの0.06 mSvより小さい
