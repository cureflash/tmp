## 出題根拠

対象は `03_燃料・材料.md` の MAT-08（定義、単位、燃焼度上昇による同位体組成・FP・物性変化、高燃焼度化の課題）。燃焼度の定義と単位換算、燃焼に伴う U-235 の減少と Pu-239 の生成、回収ウラン中の U-232/U-236/U-234、FP蓄積と燃料・被覆管への影響、高燃焼度化の目的・設計変更・安全上の課題を分けて作問した。NRAが公開している直近3回（第58回・第57回・第56回）の試験問題の公開状況を確認し、過去問本文は転載していない。数値を用いる問題は、問題文で資料又は条件を固定し、JAEA/ATOMICA又はNRAの該当資料の値に限定した。

## 問題

### MAT-08-Q001
- 問題文: 核燃料の燃焼度の定義として正しいものはどれか。
- 選択肢: ["燃料の単位重量当たりに、それまでの核分裂で発生した累積エネルギー量を表す指標", "燃料の単位体積当たりの瞬時熱出力を表す指標", "新燃料中のU-235の質量百分率を表す指標", "被覆管が受けた高速中性子の積算フルエンスだけを表す指標"]
- 正答選択肢: A
- 正答: 燃料の単位重量当たりに、それまでの核分裂で発生した累積エネルギー量を表す指標
- 解説: JAEA ATOMICAは燃焼度を「単位重量当たりの発生エネルギー量」と定義している。瞬時熱出力、U-235濃縮度、中性子フルエンスはいずれも別の物理量であり、燃焼度そのものではない。
- 出典: https://atomica.jaea.go.jp/dic/detail/dic_detail_963.html
- verified: true

### MAT-08-Q002
- 問題文: 燃焼度の単位について、1 GWd/t と等しいものはどれか。
- 選択肢: ["0.001 MWd/kg", "1 MWd/kg", "1000 MWd/kg", "1 MW/kg"]
- 正答選択肢: B
- 正答: 1 MWd/kg
- 解説: 1 GWd=1000 MWd、1 t=1000 kgなので、1 GWd/t=(1000 MWd)/(1000 kg)=1 MWd/kgとなる。Dは時間を積分したエネルギー量ではなく出力の単位である。
- 出典: https://atomica.jaea.go.jp/dic/detail/dic_detail_963.html
- verified: true

### MAT-08-Q003
- 問題文: 45,000 MWd/tU を GWd/tU に換算した値として正しいものはどれか。

- 解説: 1000 MW=1 GWなので、45,000 MWd/tU ÷1000=45 GWd/tUである。JAEA資料も45,000 MWd/tUの燃焼度を使用済燃料組成の例として用いている。

### MAT-08-Q004
- 問題文: 燃焼度55 GWd/tUまで照射されたウラン1 tについて、燃焼度の定義から対応する累積発生エネルギー量として正しいものはどれか。
- 選択肢: ["55 GWの瞬時熱出力", "55 MWdの累積エネルギー", "55,000 GWdの累積エネルギー", "55 GWdの累積エネルギー"]
- 正答選択肢: D
- 正答: 55 GWdの累積エネルギー

### MAT-08-Q006
- 問題文: JAEA ATOMICA「高燃焼度燃料」が示す軽水炉燃料の燃焼度向上の歴史的な順序として正しいものはどれか。

### MAT-08-Q007
- 問題文: 軽水炉燃料を高燃焼度化する主な狙いとして、JAEAの説明に合うものはどれか。
- 選択肢: ["運転サイクルを短くし、燃料交換回数を増やすこと", "燃料集合体1体当たりの発生エネルギーを減らし、使用済燃料を増やすこと", "運転サイクルの長期化や使用済燃料発生量の低減を通じ、経済性を向上させること", "U-235を全く含まない燃料へ移行すること"]
- 正答選択肢: C
- 正答: 運転サイクルの長期化や使用済燃料発生量の低減を通じ、経済性を向上させること
- 解説: JAEAは、濃縮度を高めて燃焼度を高くすることで運転サイクルを長期化でき、集合体1体当たりの発生エネルギーが増えることで使用済燃料発生量や燃料・再処理コストの低減が期待できるとしている。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_08-01-03-07.html ; https://atomica.jaea.go.jp/dic/detail/dic_detail_963.html
- verified: true

### MAT-08-Q008
- 問題文: NRA「事故耐性燃料等の事故時挙動研究」が注記する「高燃焼度まで使用した燃料」の説明として正しいものはどれか。
- 選択肢: ["原子炉での使用期間が短く、核燃料物質の消費割合が低い燃料", "未照射の新燃料のうち濃縮度だけが高い燃料", "被覆管を使用せず、燃料物質を直接冷却材に接触させた燃料", "原子炉での使用期間が長く、核燃料物質の消費割合が高い燃料"]

- 正答: 原子炉での使用期間が長く、核燃料物質の消費割合が高い燃料
- 解説: NRAは高燃焼度まで使用した燃料を、原子炉での使用期間が長く、核燃料物質の消費割合が高い燃料と説明している。単に初期濃縮度が高いだけでは、この注記の定義にはならない。

### MAT-08-Q009
- 問題文: 軽水炉でウラン燃料を燃焼させたときのU-235の変化として正しいものはどれか。
- 選択肢: ["核分裂によりU-235は減少する", "核分裂のたびにU-235は増加する", "U-235量は燃焼前後で必ず同一である", "U-235は全てU-238へ変換されるためにだけ減少する"]
- 正答選択肢: A
- 正答: 核分裂によりU-235は減少する
- 解説: JAEA原子力基本用語集は、原子炉運転により核分裂するU-235が減少するため、一定期間ごとに燃料を取り替えると説明している。U-235が増加又は不変という説明は誤りである。
- 出典: https://www.jaea.go.jp/glossary/%E4%BD%BF%E7%94%A8%E6%B8%88%E7%87%83%E6%96%99
- verified: true

### MAT-08-Q010
- 問題文: ウラン燃料の照射中にPu-239が生成する代表的な反応系列として正しいものはどれか。
- 選択肢: ["U-235がα壊変して直接Pu-239になる", "U-238が中性子を吸収してU-239となり、β壊変でNp-239を経てPu-239になる", "U-234が陽子を放出してPu-239になる", "FPのXe-135が中性子を吸収してPu-239になる"]
- 正答選択肢: B
- 正答: U-238が中性子を吸収してU-239となり、β壊変でNp-239を経てPu-239になる
- 解説: JAEAは U-238+n→U-239→Np-239→Pu-239 の系列を示している。したがってU-235のα壊変、U-234の陽子放出、Xe-135からの生成という他の選択肢は誤りである。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_04-09-01-01.html
- verified: true

### MAT-08-Q011
- 問題文: 軽水炉燃料を燃焼させ、再処理で回収したウランの同位体組成について正しいものはどれか。

- 正答: 燃焼によりU-232、U-236等が生成し、U-234含有量も増加する

### MAT-08-Q012
- 問題文: 回収ウランに含まれるU-236の炉心特性への影響として正しいものはどれか。
- 選択肢: ["中性子をほとんど吸収しないため反応度を必ず増加させる", "U-236が存在するとU-235の核分裂断面積がゼロになる", "U-236は核燃料の熱伝導率だけを決め、核特性には影響しない", "中性子吸収断面積が大きいため、回収ウラン燃料を装荷すると反応度を低下させる方向に働く"]

### MAT-08-Q019
- 問題文: JAEA ATOMICA「軽水型原子炉のための高燃焼度燃料」が例示するBWR高燃焼度燃料のウラン濃縮度と集合体最高燃焼度の組合せとして正しいものはどれか。
- 選択肢: ["約4.8％、48 GWd/t", "約3.0％、29 GWd/t", "約3.8％、55 GWd/t", "約20％、200 GWd/t"]
- 正答選択肢: C
- 正答: 約3.8％、55 GWd/t
- 解説: 同資料は、従来BWR燃料の約3.4％・50 GWd/tに対し、高燃焼度燃料では濃縮度約3.8％、集合体最高燃焼度55 GWd/tと記載している。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_04-06-03-05.html

### MAT-08-Q020
- 問題文: JAEA ATOMICAが説明するBWR高燃焼度9×9型燃料の設計変更の理由として正しいものはどれか。
- 選択肢: ["高燃焼度化すると水が不要になるため、ウォータロッドを全て除去するため", "濃縮度上昇に伴いボイド反応度係数の影響がなくなるため、非沸騰水量を減らすため", "燃料棒を太径化して本数を減らし、集合体内の水対燃料比を必ずゼロにするため", "濃縮度上昇に伴うボイド反応度特性を考慮し、ウォータロッド等を変更して非沸騰水量・水対燃料比を適切にするため"]
- 正答選択肢: D
- 正答: 濃縮度上昇に伴うボイド反応度特性を考慮し、ウォータロッド等を変更して非沸騰水量・水対燃料比を適切にするため
- 解説: JAEAはBWR高燃焼度化で濃縮度が上がるとボイド反応度係数の特性が変化するため、ウォータロッドの寸法・形状・本数等を見直して非沸騰水量を増やし、9×9型へ構造変更したと説明している。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_04-06-03-05.html ; https://atomica.jaea.go.jp/data/detail/dat_detail_04-06-03-06.html

### MAT-08-Q021

### MAT-08-Q022
- 問題文: 軽水炉燃料の高燃焼度化と初期U-235濃縮度の関係について、JAEAの説明に合うものはどれか。
- 選択肢: ["燃焼度を高めるには初期U-235濃縮度を必ず0％にする", "初期U-235濃縮度を高めることは、高燃焼度化と運転サイクル長期化のために用いられる", "濃縮度は燃焼度と無関係で、どの高燃焼度燃料でも天然ウランだけを用いる", "初期濃縮度を高めるほど、集合体1体当たりに取り出せるエネルギーは必ず減少する"]
- 正答選択肢: B
- 正答: 初期U-235濃縮度を高めることは、高燃焼度化と運転サイクル長期化のために用いられる
- 解説: JAEAは、核燃料の濃縮度を高めて燃焼度を高くすることにより運転サイクルを長期化できると説明している。PWR・BWRの高燃焼度燃料の実用例でも、従来燃料より濃縮度を高めている。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_08-01-03-07.html ; https://atomica.jaea.go.jp/data/detail/dat_detail_04-06-03-05.html

### MAT-08-Q023
- 問題文: NRAが令和6年度～令和10年度の研究で事故時挙動の対象としている高燃焼度燃料に関する組合せとして正しいものはどれか。
- 選択肢: ["高燃焼度燃料は対象外で、天然ウラン鉱石の採鉱だけを研究する", "高燃焼度燃料は廃棄物処分だけを研究し、炉内事故は対象外とする", "高燃焼度まで使用した従来型燃料について、LOCA時とRIA時に生じうる燃料損傷を実験・解析する", "高燃焼度燃料では事故時の燃料損傷を考慮する必要がないとして試験を行わない"]
- 正答選択肢: C
- 正答: 高燃焼度まで使用した従来型燃料について、LOCA時とRIA時に生じうる燃料損傷を実験・解析する
- 解説: NRAの現行研究はATFだけでなく、高燃焼度まで使用された従来型燃料も対象とし、LOCA及びRIAで生じうる燃料損傷を実験・解析している。したがって採鉱・廃棄物処分だけを対象とする説明や、事故試験不要とする説明は誤りである。
- 出典: https://www.nra.go.jp/activity/anzen/bunya/kakunenryou_jikojikyodou.html

### MAT-08-Q024
- 問題文: NRA「事故耐性燃料等の事故時挙動研究（令和6年度～令和10年度）」が示す事故模擬試験の条件の組合せとして正しいものはどれか。
- 選択肢: ["LOCA模擬では室温のまま保持し、RIA模擬では数か月かけて加熱する", "LOCA模擬では燃料を100℃未満に限定し、RIA模擬では100時間以上かけて加熱する", "LOCA模擬とRIA模擬のいずれも温度・時間条件を変えず、同一の静的試験だけを行う", "LOCA模擬では短尺燃料棒を約1200℃まで加熱し、RIA模擬ではNSRRで1秒以下の時間に急速加熱する"]
- 正答選択肢: D
- 正答: LOCA模擬では短尺燃料棒を約1200℃まで加熱し、RIA模擬ではNSRRで1秒以下の時間に急速加熱する
- 解説: NRAはLOCA模擬試験で短尺燃料棒を1200℃程度まで加熱し、RIA模擬試験ではNSRRを用いて1秒以下で急速加熱するとしている。数値は同研究ページの条件に固定している。
- 出典: https://www.nra.go.jp/activity/anzen/bunya/kakunenryou_jikojikyodou.html
- verified: true
