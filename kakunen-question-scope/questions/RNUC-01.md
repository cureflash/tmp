## 出題根拠

対象論点は、α、β−、β＋、γ、X線、中性子、陽子・重粒子についての電荷、質量、透過力、電離作用である。RNUC-01の範囲に収め、壊変後の核種変化やLETの定量論など後続topicの主論点は避けた。

## 問題

### RNUC-01-Q001
- 問題文: α線の実体として正しいものはどれか。
- 選択肢: ["陽子2個と中性子2個からなるヘリウム原子核", "高速の電子", "電荷を持たない中性子", "原子核外で生じた電磁波"]
- 正答選択肢: A
- 正答: 陽子2個と中性子2個からなるヘリウム原子核
- 解説: 環境省資料はα線を、陽子2個と中性子2個からなるヘリウム原子核が高速で飛び出したものとしている。Bはβ−線、Cは中性子線、Dは代表的なX線の説明である。
- 出典: https://www.env.go.jp/chemi/rhm/current/01-03-01.html
- verified: true

### RNUC-01-Q002
- 問題文: β−線を構成する粒子として正しいものはどれか。
- 選択肢: ["陽電子", "電子", "ヘリウム原子核", "中性子"]
- 正答選択肢: B
- 正答: 電子
- 解説: QST SIRABEはβ線について、β−線では電子、β＋線では陽電子が放出されると説明している。したがってβ−線の粒子は電子である。
- 出典: https://sirabe.nirs.qst.go.jp/sirabe/%E3%83%99%E3%83%BC%E3%82%BF%E7%B7%9A.html
- verified: true

### RNUC-01-Q003
- 問題文: β＋線を構成する粒子として正しいものはどれか。
- 選択肢: ["中性子", "電子", "陽電子", "α粒子"]
- 正答選択肢: C
- 正答: 陽電子
- 解説: JAEA ATOMICAは陽電子を電子と同一質量で正の素電荷を持つ粒子とし、不安定な原子核のβ＋壊変で放出されるとしている。したがってβ＋線は陽電子の流れである。
- 出典: https://atomica.jaea.go.jp/dic/detail/dic_detail_691.html
- verified: true

### RNUC-01-Q004
- 問題文: γ線とX線の共通点として正しいものはどれか。
- 選択肢: ["どちらもヘリウム原子核である", "どちらも電子の流れである", "どちらも中性子の流れである", "どちらも電磁波である"]
- 正答選択肢: D
- 正答: どちらも電磁波である
- 解説: 環境省資料はγ線とX線をともに電磁波の仲間としている。α線、β線、中性子線は粒子線である。
- 出典: https://www.env.go.jp/chemi/rhm/current/01-03-03.html
- verified: true

### RNUC-01-Q005
- 問題文: 中性子線を構成する粒子の電荷について正しいものはどれか。
- 選択肢: ["電気的に中性である", "負の素電荷を持つ", "正の素電荷を持つ", "常に＋2の電荷を持つ"]
- 正答選択肢: A
- 正答: 電気的に中性である
- 解説: QSTは中性子線を構成する中性子を「電気的に中性の粒子」と説明している。電子は負、陽子は正、α粒子は陽子2個を含むため正に帯電する。
- 出典: https://www.qst.go.jp/site/taka/2337.html
- verified: true

### RNUC-01-Q006
- 問題文: 陽子の電荷について正しいものはどれか。

- 正答: 正の電荷を持つ
- 解説: 環境省資料は原子核を、プラスの電荷を持つ陽子と電荷を持たない中性子で構成されると説明している。陽子線は粒子線の一種である。

### RNUC-01-Q007

### RNUC-01-Q008
- 問題文: 物質を直接電離する放射線の組合せとして正しいものはどれか。

- 正答: α線とβ線
- 解説: 環境省資料は、α線・β線など電荷を持つ粒子線が物質を直接電離するとしている。γ線・X線は二次電子を介して間接的に電離する。

- 正答選択肢: D
- 正答: 炭素粒子は陽子より約12倍重い
- 解説: QST病院は重粒子線治療で、陽子より12倍重い炭素粒子を用いると説明している。したがってA～Cは同資料と一致しない。
