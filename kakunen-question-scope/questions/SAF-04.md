## 問題

### SAF-04-Q001
- 問題文: 臨界安全管理でいう「核的制限値」の説明として最も適切なのはどれか。
- 選択肢: ["臨界管理を行う体系の未臨界を確保するために設定する、実際の設計・運転で管理可能な制限値", "臨界に達した後に警報を発するためだけの線量率設定値", "放射性物質の年間放出量だけを制限する環境管理値", "設備の機械強度だけから決める許容応力値"]
- 正答選択肢: A
- 正答: 臨界管理を行う体系の未臨界を確保するために設定する、実際の設計・運転で管理可能な制限値
- 解説: NRA公開資料では、核的制限値を臨界管理を行う体系の未臨界確保のために設定する計量可能な値として扱っている。IAEA SSG-27 (Rev.1) 2.8～2.12も、keff又は質量・濃度・形状・相互作用等の管理パラメータに未臨界限度と安全余裕を設定し、運転上監視・制御できる限度へ落とし込む考え方を示す。ほかの3肢は臨界安全の核的制限値ではない。
- 出典: https://www.nra.go.jp/data/000069200.pdf ; https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1995_web.pdf

### SAF-04-Q002
- 問題文: 単独ではそれぞれ未臨界である核燃料物質収納容器を複数配置する場合、臨界安全評価で追加して考慮すべき事項はどれか。
- 選択肢: ["容器の塗装色だけをそろえること", "容器相互の中性子相互作用による体系全体のkeff変化", "各容器の製造年月だけを比較すること", "作業員の人数だけを一定にすること"]
- 正答選択肢: B
- 正答: 容器相互の中性子相互作用による体系全体のkeff変化
- 解説: SSG-27 (Rev.1) 3.27は、核分裂性物質を含むユニット又は設備間の中性子相互作用が体系のkeffに影響するため考慮すべきとしている。SSR-4 6.144(h)も、関係し得るすべての施設ユニット間の中性子相互作用を考慮するよう要求する。個々が未臨界でも複数体系としての評価が必要である。
- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1995_web.pdf ; https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1791_web.pdf

### SAF-04-Q003
- 問題文: 複数ユニットの臨界安全を距離で管理する方法として、IAEA SSG-27 (Rev.1) に沿うものはどれか。
- 選択肢: ["ユニット間距離は臨界安全とは無関係なので管理しない", "距離は作業動線だけで決め、核計算には用いない", "個別に未臨界な体系同士について、評価済みの最小分離距離を管理パラメータとして設定する", "隣接ユニットの質量が増えても距離条件は再評価しない"]
- 正答選択肢: C
- 正答: 個別に未臨界な体系同士について、評価済みの最小分離距離を管理パラメータとして設定する
- 解説: SSG-27 (Rev.1) 3.18(i)は、個別に未臨界な別体系間の最小分離距離を臨界安全の管理パラメータとして明示している。距離変更は中性子相互作用を変えるため、評価済み条件から外すことはできない。
- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1995_web.pdf
- verified: true

### SAF-04-Q004
- 問題文: 複数の核燃料容器の安全な間隔を維持する方法として、IAEA SSG-27 (Rev.1) が実例として挙げるものはどれか。
- 選択肢: ["床に目印を描くだけで、容器の移動は自由にする", "作業者の記憶だけで所定間隔を維持する", "容器間隔を毎回口頭で決める", "固定式の貯蔵ラックなど、工学的手段で分離距離を維持する"]
- 正答選択肢: D
- 正答: 固定式の貯蔵ラックなど、工学的手段で分離距離を維持する

- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1995_web.pdf

### SAF-04-Q005
- 問題文: IAEA SSG-27 (Rev.1) による未臨界限度の設定根拠として正しいものはどれか。
- 選択肢: ["対象体系のkeffが1未満となる値、又はkeffが1未満に対応する一つ以上の巨視的管理パラメータの値", "keffが必ず1.00となる値だけ", "放射線管理区域境界の線量率だけ", "設備の運転時間だけ"]
- 正答選択肢: A
- 正答: 対象体系のkeffが1未満となる値、又はkeffが1未満に対応する一つ以上の巨視的管理パラメータの値
- 解説: SSG-27 (Rev.1) 2.8は、未臨界限度を対象体系の未臨界なkeff又はkeff<1に対応する質量、濃度、減速、幾何形状、反射、相互作用等の管理パラメータから導くとしている。他の3肢は未臨界限度の定義に当たらない。
- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1995_web.pdf

### SAF-04-Q006
- 問題文: 臨界安全限度を決める際の安全余裕の扱いとして正しいものはどれか。
- 選択肢: ["計算値が1未満なら安全余裕は不要である", "未臨界限度から臨界安全限度を定める際に安全余裕を適用し、計算の不確かさ等も考慮する", "安全余裕は事故後の被ばく評価にだけ使う", "安全余裕は設備完成後に削除する"]
- 正答選択肢: B
- 正答: 未臨界限度から臨界安全限度を定める際に安全余裕を適用し、計算の不確かさ等も考慮する
- 解説: SSG-27 (Rev.1) 2.9～2.10は、臨界安全限度を定めるため安全余裕を適用し、keff計算のバイアス、バイアス不確かさ、感度などを考慮するよう求める。単に中心値が1未満というだけでは十分でない。
- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1995_web.pdf
- verified: true

### SAF-04-Q007
- 問題文: 施設で実際に用いる運転上の臨界管理限度と、評価で定めた臨界安全限度との関係として適切なのはどれか。
- 選択肢: ["運転上の限度は臨界安全限度より常に大きくする", "両者は無関係に設定する", "運転上の限度・条件は臨界安全限度以下とし、監視・制御可能なものとする", "運転上の限度は異常時だけ設定する"]
- 正答選択肢: C
- 正答: 運転上の限度・条件は臨界安全限度以下とし、監視・制御可能なものとする
- 解説: SSG-27 (Rev.1) 2.12は、施設又は活動の運転上の限度・条件を臨界安全限度以下とし、監視及び制御に適した形で設定するよう示している。臨界安全限度を超える運転限度は安全余裕を失わせる。
- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1995_web.pdf
- verified: true

### SAF-04-Q008

### SAF-04-Q009

### SAF-04-Q010
- 問題文: 核的制限値に安全余裕を設定するときに考慮する事項として、IAEA SSG-27 (Rev.1) 3.19に沿う組合せはどれか。

### SAF-04-Q011
- 問題文: 核燃料物質を含むユニット周囲の反射条件を保守的に評価する一般的な方法として、IAEA SSG-27 (Rev.1) が示すものはどれか。
- 選択肢: ["真空境界だけを仮定する", "周囲物質をすべて無視する", "最大keffとなるのに十分な厚さの全密度軽水反射体、いわゆる完全軽水反射を検討する", "反射体は必ずkeffを下げると仮定する"]
- 正答選択肢: C
- 正答: 最大keffとなるのに十分な厚さの全密度軽水反射体、いわゆる完全軽水反射を検討する
- 解説: SSG-27 (Rev.1) 3.22は、通常の臨界安全評価では最大keffを与えるのに十分な厚さの全密度軽水反射を考慮するとしている。反射材は中性子漏えいを減らしkeffを増加させ得るため、無視や真空境界だけの評価は一般に保守的とは限らない。
- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1995_web.pdf
- verified: true

### SAF-04-Q012
- 問題文: 全密度軽水反射を評価済みであっても、周囲にコンクリートや鋼など別の材料が存在し得る場合の扱いとして正しいものはどれか。
- 選択肢: ["軽水を評価したので他材料は必ず無視できる", "コンクリートや鋼は中性子と相互作用しないので評価不要である", "複数材料が存在する場合は必ずkeffが低下するとみなす", "他の反射材又はその組合せがより大きくkeffを増加させ得るなら、その条件も評価する"]

- 正答: 他の反射材又はその組合せがより大きくkeffを増加させ得るなら、その条件も評価する

### SAF-04-Q013
- 問題文: 複数ユニットの間や周囲に水、蒸気、ポリエチレン、コンクリートなどが存在する場合の評価として正しいものはどれか。
- 選択肢: ["材料の種類と密度により、反射・減速・吸収作用を通じてkeffを増減させ得るため評価する", "ユニット間物質はkeffに影響しない", "水以外の物質はすべて真空と同じとして扱う", "低密度の蒸気や泡は常に影響ゼロとみなす"]
- 正答選択肢: A
- 正答: 材料の種類と密度により、反射・減速・吸収作用を通じてkeffを増減させ得るため評価する
- 解説: SSG-27 (Rev.1) 3.26は、核燃料物質の間又は周囲の材料が反射体、減速材、吸収材として働き、種類と密度によってkeffを増加又は減少させ得るとする。水素含有物質や低密度の蒸気・泡でも大きな変化を生じ得るため、影響ゼロとはできない。

### SAF-04-Q015
- 問題文: 複数ユニット間の距離管理について、IAEA SSG-27 (Rev.1) 3.27の説明として正しいものはどれか。

### SAF-04-Q017
- 問題文: 複数ユニットを含む施設の最不利条件評価で、核分裂性物質の物理的・化学的形態をどう扱うべきか。
- 選択肢: ["運転状態又は事故条件で存在し得る中から、最も反応度が高くなる放射性・化学的形態を決定して評価する", "最も扱いやすい形態だけを使う", "公称形態だけを使い、沈殿や状態変化は除外する", "形態はkeffに影響しないので評価しない"]

### SAF-04-Q024
- 問題文: 固定ラック内の各容器は単独では未臨界である。事故時に近傍へ別の核燃料容器が移動し、周囲に水が入り、近くのコンクリート壁による反射も変化し得る。複数ユニットとして最も適切な臨界安全評価はどれか。
