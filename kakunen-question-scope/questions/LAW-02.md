## 問題

### LAW-02-Q01
- 問題: 製錬、加工、使用済燃料貯蔵、再処理、廃棄、核燃料物質の使用について、事業・使用開始時の主要な行政処分を「指定」または「許可」に分類せよ。
- 正答: 製錬＝指定、加工＝許可、使用済燃料貯蔵＝許可、再処理＝指定、廃棄＝許可、核燃料物質の使用＝許可（法定の適用除外を除く）。
- 解説: 原子炉等規制法は事業類型ごとに入口の行政処分を分けている。製錬と再処理は「指定」、加工・使用済燃料貯蔵・廃棄・核燃料物質の使用は「許可」が基本である。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q02
- 問題: 製錬の事業を始めるために原子力規制委員会から受ける必要がある行政処分は何か。
- 正答: 指定。
- 解説: 原子炉等規制法第3条は、製錬事業を行おうとする者に原子力規制委員会の指定を要求している。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q03
- 問題: 加工の事業を始めるために原子力規制委員会から受ける必要がある行政処分は何か。
- 正答: 許可。
- 解説: 原子炉等規制法第13条は、加工事業を許可制としている。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q04
- 問題: 使用済燃料貯蔵の事業を始める場合、基本となる行政処分は何か。
- 正答: 許可。
- 解説: 原子炉等規制法第43条の4第1項の許可が入口となる。施行令第22条は、この許可を事業所ごとに受けることを定めている。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166 ; https://laws.e-gov.go.jp/law/332CO0000000324
- verified: true

### LAW-02-Q05
- 問題: 再処理の事業を始めるために原子力規制委員会から受ける必要がある行政処分は何か。
- 正答: 指定。
- 解説: 原子炉等規制法第44条は、再処理事業を指定制としている。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q06
- 問題: 原子炉等規制法上、廃棄の事業を行う場合の基本的な行政処分は何か。
- 正答: 許可。
- 解説: 法第51条の2は、廃棄の事業について、その種類に応じ原子力規制委員会の許可を要求している。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q07
- 問題: 核燃料物質を使用しようとする者が原則として受ける必要がある行政処分は何か。
- 正答: 許可。
- 解説: 法第52条第1項は核燃料物質の使用を原則として許可制としている。ただし同項各号には適用除外がある。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q08
- 問題: 製錬事業者が製錬施設の位置・構造・設備や製錬方法など、法第6条第1項の対象となる重要事項を変更しようとするとき、事前に必要な手続は何か。
- 正答: 変更の許可。
- 解説: 製錬事業そのものは「指定」だが、指定後の一定の重要事項の変更は原子力規制委員会の「許可」を受ける構造になっている。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q09
- 問題: 製錬事業者が氏名・名称・住所など法第3条第2項第1号の事項を変更した場合、原則として何日以内に何をする必要があるか。
- 正答: 変更の日から30日以内に原子力規制委員会へ届け出る。
- 解説: 法第6条第2項は、相続の場合を除き、同号等の変更について30日以内の届出を求めている。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q10
- 問題: 製錬事業者が事業を開始、休止または再開した場合、何日以内にどの手続をするか。
- 正答: それぞれの日から15日以内に原子力規制委員会へ届け出る。
- 解説: 法第7条の「事業開始等の届出」による。事前許可ではなく事後の届出である点が重要である。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q11
- 問題: 加工事業者が加工施設の位置・構造・設備や加工方法など法第16条第1項の対象となる重要事項を変更しようとするとき、必要な手続は何か。
- 正答: 変更の許可。
- 解説: 加工事業では事業開始時も許可であり、一定の重要事項の変更にも変更許可が必要となる。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q12
- 問題: 加工事業者が、変更許可の対象ではない法定の届出事項を変更した場合、原則として何日以内に届け出るか。
- 正答: 変更の日から30日以内。
- 解説: 法第16条第2項は、氏名・名称・住所等や所定の事項の変更について30日以内の届出を定めている。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q13
- 問題: 使用済燃料貯蔵事業者が、貯蔵施設の位置・構造・設備など法第43条の7第1項の対象となる事項を変更しようとするとき、必要な手続は何か。
- 正答: 変更の許可。
- 解説: 法第43条の7第1項は、所定の重要事項を変更する場合に原子力規制委員会の許可を要求している。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q14
- 問題: 使用済燃料貯蔵事業者が「事業所の名称だけ」を変更する場合、変更許可は必要か。また、その後の手続は何か。
- 正答: 変更許可は不要。変更の日から30日以内に原子力規制委員会へ届け出る。
- 解説: 法第43条の7は、事業所の名称のみの変更を第1項の許可対象から外し、第2項で30日以内の届出対象としている。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q15
- 問題: 再処理事業者が、再処理能力、施設の位置・構造・設備、再処理方法など法第44条の4第1項の対象となる事項を変更しようとするとき、必要な手続は何か。
- 正答: 変更の許可。
- 解説: 再処理事業そのものは「指定」であるが、指定後の一定の重要事項の変更は「許可」である。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q16
- 問題: 再処理事業者が工場または事業所の名称だけを変更する場合、変更許可は必要か。また、その後の手続は何か。
- 正答: 変更許可は不要。変更の日から30日以内に原子力規制委員会へ届け出る。
- 解説: 法第44条の4は名称のみの変更を許可対象から除外し、30日以内の届出対象としている。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q17
- 問題: 核燃料物質の使用者が、使用目的、核燃料物質の種類・数量、使用施設等に関する法第55条第1項の対象事項を変更しようとするとき、必要な手続は何か。
- 正答: 変更の許可。
- 解説: 法第55条第1項は、第52条第2項の所定事項の変更について原子力規制委員会の許可を要求している。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q18
- 問題: 核燃料物質の使用者が氏名・名称・住所など法第52条第2項第1号の事項を変更した場合、原則として何日以内に何をする必要があるか。
- 正答: 変更の日から30日以内に原子力規制委員会へ届け出る。
- 解説: 法第55条第2項の届出であり、相続による承継の場合は別条の手続となる。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q19
- 問題: 製錬事業者が製錬事業のために核燃料物質を使用する場合、法第52条第1項による「使用の許可」を別途受ける必要があるか。
- 正答: 原則として不要。
- 解説: 法第52条第1項は、製錬事業者が製錬事業の用に供する場合などを使用許可の適用除外としている。同様に加工、原子炉、再処理の事業に伴う所定の使用にも適用除外がある。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q20
- 問題: 政令で定める種類・数量以下の核燃料物質の使用について、法第52条第1項の使用許可は必ず必要か。
- 正答: 必ずしも必要ではない。政令で定める種類・数量に該当する場合は使用許可の適用除外となる。
- 解説: 法第52条第1項の適用除外を受け、具体的な種類・数量は施行令第39条で定められている。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166 ; https://laws.e-gov.go.jp/law/332CO0000000324
- verified: true

### LAW-02-Q21
- 問題: 製錬事業者である法人が、法定の合併または事業全部を承継させる分割によって製錬事業者の地位を承継させるには、原子力規制委員会の何が必要か。
- 正答: 認可。
- 解説: 法第8条は、所定の合併・分割について認可を受けた場合に、存続法人等が製錬事業者の地位を承継すると定める。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q22
- 問題: 製錬事業者について相続があった場合、相続人は事業者の地位を承継するために改めて指定を受け直す必要があるか。また、必要な事後手続は何か。
- 正答: 指定を受け直す必要はなく地位を承継する。相続の日から30日以内に、事実を証する書面を添えて原子力規制委員会へ届け出る。
- 解説: 法第9条による地位承継と届出である。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q23
- 問題: 使用済燃料貯蔵事業者である法人の所定の合併・分割によって事業者の地位を承継する場合、原子力規制委員会の何が必要か。
- 正答: 認可。
- 解説: 法第43条の14は、所定の合併・分割について原子力規制委員会の認可を受けた場合に事業者の地位を承継させる制度を定めている。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q24
- 問題: 使用済燃料貯蔵事業者について相続があった場合、相続人が行うべき手続と期限は何か。
- 正答: 事業者の地位を承継し、相続の日から30日以内に、事実を証する書面を添えて原子力規制委員会へ届け出る。
- 解説: 法第43条の15による。相続では新規許可ではなく、法定承継と届出の組合せになる。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q25
- 問題: 核燃料物質の使用者である法人が分割によって使用者の地位を承継させる場合、どのような条件と行政処分が必要か。
- 正答: 当該許可に係る全ての使用施設等、核燃料物質および汚染された物を一体として承継させる分割であり、原子力規制委員会の認可を受ける必要がある。
- 解説: 法第55条の3は、分割による承継について対象一式の承継と認可を要件としている。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q26
- 問題: 核燃料物質の使用者について相続があった場合、相続人が行うべき手続と期限は何か。
- 正答: 使用者の地位を承継し、相続の日から30日以内に、事実を証する書面を添えて原子力規制委員会へ届け出る。
- 解説: 法第55条の4による。新規の使用許可を取り直す手続ではない。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q27
- 問題: 製錬事業者が正当な理由なく、規則で定める期間内に事業を開始しない、または引き続き1年以上事業を休止した場合、原子力規制委員会はどのような処分を行うことができるか。
- 正答: 製錬事業の指定を取り消すことができる。
- 解説: 法第10条第1項の指定取消事由である。「指定」を受ける事業なので、取消対象も指定である。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q28
- 問題: 使用済燃料貯蔵事業者が、変更許可を受けるべき事項を無許可で変更した場合、原子力規制委員会が取り得る主要な行政処分は何か。
- 正答: 許可の取消し、または1年以内の期間を定めた事業停止命令。
- 解説: 法第43条の16は、法第43条の7第1項に違反した場合を取消し等の事由に含める。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true

### LAW-02-Q29
- 問題: 使用済燃料貯蔵事業を廃止する場面で、法第43条の27第2項に基づく廃止措置計画について必要となる行政処分は何か。
- 正答: 原子力規制委員会の認可。
- 解説: 使用済燃料貯蔵事業規則は、同条項に基づく廃止措置計画の認可申請を定めている。単なる任意の廃業届だけで処理する制度ではない。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166 ; https://laws.e-gov.go.jp/law/412M50000400112
- verified: true

### LAW-02-Q30
- 問題: 核燃料物質の使用を廃止する場面で、法第57条の5第2項に基づく廃止措置計画について必要となる行政処分は何か。
- 正答: 原子力規制委員会の認可。
- 解説: 法は使用の廃止に伴う措置を定め、関係規則は廃止措置計画の認可申請手続を置いている。
- 出典: https://laws.e-gov.go.jp/law/332AC0000000166
- verified: true
