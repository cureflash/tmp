## 問題

### CYC-03-Q001
- 問題文: 遠心分離法によるウラン濃縮で、遠心分離機へ供給する原料の化学形・状態として正しいものはどれか。
- 選択肢: ["気体状態の六フッ化ウラン（UF6）", "固体の二酸化ウラン（UO2）ペレット", "液体の金属ウラン", "硝酸ウラニル水溶液"]
- 正答選択肢: A
- 正答: 気体状態の六フッ化ウラン（UF6）
- 解説: JAEA/ATOMICAは遠心分離法の原料として気体状態のUF6を用いると説明し、日本原燃も天然UF6を固体から気体にして遠心分離機へ供給するとしている。UO2ペレット、金属ウラン、硝酸ウラニル水溶液をそのまま遠心分離機へ供給する工程ではない。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_04-05-01-04.html ; https://www.jnfl.co.jp/ja/business/about/uran/summary/process.html
- verified: true

### CYC-03-Q002
- 問題文: ガス遠心分離機の回転胴内におけるUF6の同位体分布として正しいものはどれか。
- 選択肢: ["235Uを含むUF6が外周側、238Uを含むUF6が軸側に多くなる", "238Uを含むUF6が外周側、235Uを含むUF6が軸側に多くなる", "235Uを含むUF6と238Uを含むUF6はいずれも外周側だけに集まる", "235Uを含むUF6と238Uを含むUF6はいずれも軸上だけに集まる"]
- 正答選択肢: B
- 正答: 238Uを含むUF6が外周側、235Uを含むUF6が軸側に多くなる
- 解説: 高速回転による遠心力で、重い238Uを含むUF6は回転胴の外周側へ、軽い235Uを含むUF6は軸側へ偏る。逆向き、両者が同じ側だけに集まるという説明はいずれも公的資料の記述と一致しない。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_04-05-01-04.html ; https://www.nrc.gov/materials/fuel-cycle-fac/ur-enrichment
- verified: true

### CYC-03-Q003
- 問題文: 遠心分離法が235Uと238Uを分ける際に直接利用する性質として最も適切なものはどれか。
- 選択肢: ["235Uと238Uの化学反応性の大差", "235Uだけが常温で気体になる性質", "235Uと238Uを含むUF6分子のわずかな質量差", "235Uだけが電荷を持つ性質"]
- 正答選択肢: C
- 正答: 235Uと238Uを含むUF6分子のわずかな質量差
- 解説: 遠心分離法はUF6分子の質量差を利用する物理的分離法である。両同位体の化学反応性が大きく異なること、235Uだけが気体になること、235Uだけが帯電することを利用する方法ではない。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_04-05-01-04.html ; https://www.energy.gov/ne/nuclear-fuel-cycle
- verified: true

### CYC-03-Q004
- 問題文: 日本原燃が説明するガス遠心分離機で、235U割合の高いUF6を得る位置として正しいものはどれか。
- 選択肢: ["回転胴の外壁だけから抜き取る", "回転胴の外側と中心部を混合してから抜き取る", "回転を止めて底部に沈殿させてから抜き取る", "回転胴の中心部から抜き取る"]
- 正答選択肢: D
- 正答: 回転胴の中心部から抜き取る
- 解説: 日本原燃は、軽い235Uの割合が高いUF6が中心部に集まり、中心部からUF6ガスを抜き取ることで濃縮ウランを得ると説明している。外壁側は238U割合が高くなるため、他の選択肢は工程説明と一致しない。
- 出典: https://www.jnfl.co.jp/ja/business/about/uran/summary/centrifuge-cascade.html
- verified: true

### CYC-03-Q005
- 問題文: ガス遠心分離機内部の軸方向の対向流（countercurrent flow）が果たす役割として適切なものはどれか。
- 選択肢: ["半径方向の分離に加えて軸方向の分離を強め、濃縮側と劣化側を反対側の端で取り出しやすくする", "UF6を化学分解してUF4とF2に変える", "回転胴を停止させたまま同位体を重力沈降させる", "235Uだけをイオン化して電極に捕集する"]
- 正答選択肢: A
- 正答: 半径方向の分離に加えて軸方向の分離を強め、濃縮側と劣化側を反対側の端で取り出しやすくする
- 解説: ATSDRの公的毒性プロファイルは、回転胴長手方向の対向循環流が同位体の鉛直方向の分離も生じさせ、別々の端から取り出せると説明している。化学分解、停止状態での重力沈降、選択的イオン化を行う流れではない。
- 出典: https://www.ncbi.nlm.nih.gov/books/NBK158806/
- verified: true

### CYC-03-Q006
- 問題文: ガス遠心分離機の「スクープ」の役割として正しいものはどれか。
- 選択肢: ["回転胴そのものを高速回転させる電動機である", "回転胴内からUF6ガスを抜き出すための管である", "UF6をUO2へ再転換する反応器である", "カスケード全体の濃縮度を測る質量分析計そのものである"]
- 正答選択肢: B
- 正答: 回転胴内からUF6ガスを抜き出すための管である
- 解説: JAEA/ATOMICAはスクープ方式を回転胴内に抜き出しパイプを取り付けてガスを取り出す方式と説明し、JAEA掲載のIAEA追加議定書附属書IIも抜出管をUF6ガス抽出用として規定している。電動機、再転換反応器、質量分析計ではない。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_04-05-01-04.html ; https://www.jaea.go.jp/04/iscn/archive/infcirc255a/infcirc255aii.html
- verified: true

### CYC-03-Q007
- 問題文: 遠心分離濃縮で多数の遠心分離機をカスケード化する主な理由として正しいものはどれか。
- 選択肢: ["1台ではUF6を気体にできないため", "1台では235Uと238Uの質量差が消えるため", "1台あたりの濃縮度の上昇は小さく、所要濃縮度まで処理を繰り返す必要があるため", "1台だけではUF6が必ずUO2へ戻るため"]
- 正答選択肢: C
- 正答: 1台あたりの濃縮度の上昇は小さく、所要濃縮度まで処理を繰り返す必要があるため
- 解説: 日本原燃は、1台の遠心分離機による濃縮度上昇は一般にごくわずかで、必要な濃縮度を得るには何回も処理する必要があるため複数機を連結したカスケードを用いるとしている。UF6の気化、質量差消失、UO2への逆変換が理由ではない。
- 出典: https://www.jnfl.co.jp/ja/business/about/uran/summary/centrifuge-cascade.html
- verified: true

### CYC-03-Q008
- 問題文: 日本原燃が示す遠心分離カスケードの基本的な接続構成として正しいものはどれか。
- 選択肢: ["全遠心分離機を1台ずつ独立させ、相互に接続しない", "すべての遠心分離機を直列だけに接続し、各段に1台しか置かない", "すべての遠心分離機を並列だけに接続し、段を設けない", "複数の段を直列に構成し、各段では処理流量に応じた台数を並列に接続する"]
- 正答選択肢: D
- 正答: 複数の段を直列に構成し、各段では処理流量に応じた台数を並列に接続する
- 解説: 日本原燃は、カスケードを直列に接続された複数の段で構成し、各段には処理流量に応じた台数の遠心分離機を並列接続すると説明している。独立運転、直列のみ、並列のみでは所定のカスケード構成にならない。
- 出典: https://www.jnfl.co.jp/ja/business/about/uran/summary/centrifuge-cascade.html ; https://www.nrc.gov/materials/fuel-cycle-fac/ur-enrichment
- verified: true

### CYC-03-Q009
- 問題文: カスケードの同一段内で遠心分離機を複数台並列に接続する主な目的として、日本原燃の説明に合うものはどれか。
- 選択肢: ["その段で必要な処理流量に対応するため", "各遠心分離機の回転方向を交互に変えるため", "UF6を液体状態で保持するため", "235Uを化学反応で生成するため"]
- 正答選択肢: A
- 正答: その段で必要な処理流量に対応するため
- 解説: 日本原燃は、各段には処理する流量に応じた台数の遠心分離機を並列接続するとしている。並列化の目的は回転方向変更、UF6の液体保持、235U生成ではない。
- 出典: https://www.jnfl.co.jp/ja/business/about/uran/summary/centrifuge-cascade.html
- verified: true

### CYC-03-Q010
- 問題文: カスケード内で、ある段から出た235U割合が増加したUF6ガスの基本的な送り先はどれか。
- 選択肢: ["同じ段の廃品回収槽へ直ちに送る", "さらに濃縮するため次の上位段へ送る", "必ず原料シリンダへ戻す", "再転換工程へ直接送る"]
- 正答選択肢: B
- 正答: さらに濃縮するため次の上位段へ送る
- 解説: 日本原燃は、ある段で235U割合が増加したガスを、さらに濃縮するため次の上位段へ供給すると説明している。廃品回収、原料シリンダへの強制返送、再転換への直接送出ではない。
- 出典: https://www.jnfl.co.jp/ja/business/about/uran/summary/centrifuge-cascade.html ; https://www.nrc.gov/materials/fuel-cycle-fac/ur-enrichment
- verified: true

### CYC-03-Q011
- 問題文: カスケード内で、ある段から出た235U割合が減少したUF6ガスの基本的な扱いとして正しいものはどれか。
- 選択肢: ["上位段だけへ送り続ける", "その場でUO2へ転換してカスケードに戻す", "さらに無駄なく利用するため次の下位段へ送る", "必ず大気へ放出する"]
- 正答選択肢: C
- 正答: さらに無駄なく利用するため次の下位段へ送る
- 解説: 日本原燃は235U割合が減少したUF6ガスを下位段に再び供給するとしており、NRCもdepleted streamを次のlower stageへ戻すと説明している。上位段のみ、UO2への変換、大気放出ではない。
- 出典: https://www.jnfl.co.jp/ja/business/about/uran/summary/centrifuge-cascade.html ; https://www.nrc.gov/materials/fuel-cycle-fac/ur-enrichment
- verified: true

### CYC-03-Q012
- 問題文: カスケード各段の遠心分離機の特性や台数を設定する際、日本原燃が重要としている考え方はどれか。
- 選択肢: ["各段で必ず同じ濃縮度のガスを捨てること", "すべての段で遠心分離機の台数を必ず同一にすること", "上位段と下位段のガスを混合しないよう完全に別系統にすること", "異なる濃度の流れを合流させる際の混合による無駄をなるべく小さくすること"]
- 正答選択肢: D
- 正答: 異なる濃度の流れを合流させる際の混合による無駄をなるべく小さくすること
- 解説: 日本原燃は、各段の供給では下位段からの濃縮側流れと上位段からの劣化側流れが合流するため、異なる濃度の混合による無駄を抑えるよう機械特性や台数を設定することが重要としている。他の選択肢は同資料の説明と一致しない。
- 出典: https://www.jnfl.co.jp/ja/business/about/uran/summary/centrifuge-cascade.html
- verified: true

### CYC-03-Q013
- 問題文: JAEA/ATOMICAが示すガス遠心分離機の理論的な分離係数の依存性について、同位体の質量差との関係として正しいものはどれか。
- 選択肢: ["質量差の2乗に比例するとされる", "質量差に反比例するとされる", "質量差の平方根に比例するとされる", "質量差には依存しないとされる"]
- 正答選択肢: A
- 正答: 質量差の2乗に比例するとされる
- 解説: JAEA/ATOMICAは、遠心分離機の分離係数が理論的には質量差の2乗、周速の4乗に比例し、回転胴の長さにも比例すると説明している。反比例、平方根比例、非依存ではない。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_04-05-01-04.html
- verified: true

### CYC-03-Q016
- 問題文: JAEA/ATOMICAの説明から、より高い分離性能を狙う遠心分離機の方向性として適切なものはどれか。
- 選択肢: ["低周速で短い回転胴にする", "高周速で短い回転胴にする", "低周速で長い回転胴にする", "高周速で長い回転胴にする"]
- 正答選択肢: D
- 正答: 高周速で長い回転胴にする
- 解説: JAEA/ATOMICAは、分離係数が周速の4乗と回転胴長さに比例するため、周速が速く、かつ長い回転胴を有する遠心機が効率的と説明している。他の3組合せはいずれか一方または双方がこの方向と逆である。
- 出典: https://atomica.jaea.go.jp/data/detail/dat_detail_04-05-01-04.html

### CYC-03-Q017
- 問題文: 米国DOEが示すガス遠心分離機1台とガス拡散法1段の比較として正しいものはどれか。
- 選択肢: ["遠心分離機1台の処理容量は小さいが、分離能力はガス拡散法1段より大きい", "遠心分離機1台の処理容量も分離能力も必ずガス拡散法1段より大きい", "遠心分離機1台の処理容量は大きいが、分離能力はガス拡散法1段より小さい", "両者の処理容量と分離能力は常に同一である"]
- 正答選択肢: A
- 正答: 遠心分離機1台の処理容量は小さいが、分離能力はガス拡散法1段より大きい
- 解説: DOEは、単一遠心分離機のcapacityは単一ガス拡散段より小さい一方、separative capabilityはかなり大きいと説明している。大小関係を逆にした選択肢や同一とする選択肢は誤りである。
- 出典: https://www.energy.gov/ne/nuclear-fuel-cycle
- verified: true

### CYC-03-Q018
- 問題文: 遠心分離法とガス拡散法の分離原理の組合せとして正しいものはどれか。
- 選択肢: ["遠心分離法は多孔質隔膜、ガス拡散法は遠心力を利用する", "遠心分離法は高速回転による遠心力、ガス拡散法は多孔質隔膜を通る分子運動の差を利用する", "両者とも235Uだけをレーザー励起する", "両者ともUO2ペレットの沈降速度差を利用する"]
- 正答選択肢: B
- 正答: 遠心分離法は高速回転による遠心力、ガス拡散法は多孔質隔膜を通る分子運動の差を利用する
