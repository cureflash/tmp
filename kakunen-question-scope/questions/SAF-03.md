## 問題

### SAF-03-Q001
- 問題文: IAEA SSG-27 (Rev.1) が臨界安全の管理パラメータとして明示している組合せはどれか。
- 選択肢: ["質量、濃度、形状・寸法、減速、反射、吸収材、ユニット間隔など", "作業者の年齢、勤続年数、所属人数、勤務時間", "照度、騒音、室温、帳票枚数", "購入価格、設備年式、建屋外装色、点検会社数"]
- 正答選択肢: A
- 正答: 質量、濃度、形状・寸法、減速、反射、吸収材、ユニット間隔など
- 解説: SSG-27 (Rev.1) 3.17～3.18は、未臨界性を維持するための制御パラメータとして質量、濃度、幾何形状、減速、反射、中性子吸収材、ユニット間隔等を挙げる。残る3選択肢は臨界管理パラメータではない。
- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1995_web.pdf
- verified: true

### SAF-03-Q002
- 問題文: 臨界安全対策の選択順位として、IAEA SSG-27 (Rev.1) の考え方に最も合うものはどれか。
- 選択肢: ["行政的管理を最優先し、設備的対策は使わない", "本質安全又は受動的な設備対策を、可能な限り行政的管理より優先する", "警報後の運転員判断だけに依存する", "すべての管理を口頭指示だけで行う"]
- 正答選択肢: B
- 正答: 本質安全又は受動的な設備対策を、可能な限り行政的管理より優先する
- 解説: SSG-27 (Rev.1) 3.13～3.16は、本質安全、受動的設備、能動的設備、行政的管理という防護階層を示し、可能な場合には本質安全・受動的対策を優先する。ほかの選択肢はこの階層化に反する。
- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1995_web.pdf
- verified: true

### SAF-03-Q003
- 問題文: 核分裂性物質をグローブボックスへ入れる前に、運転員が容器を秤量して質量上限を確認する方法は、IAEA SSG-27 (Rev.1) の分類では何に当たるか。
- 選択肢: ["本質安全", "受動的設備対策", "行政的安全対策", "中性子反射対策"]
- 正答選択肢: C
- 正答: 行政的安全対策
- 解説: SSG-27 (Rev.1) は、運転員が容器を秤量し、グローブボックスへ導入する前に質量制限を確認する例を行政的安全対策として挙げる。人の操作・確認に依存するため本質安全や受動的設備ではない。
- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1995_web.pdf
- verified: true

### SAF-03-Q004
- 問題文: 質量制限を臨界管理に使うときの設定方法として適切なのはどれか。
- 選択肢: ["最小臨界質量そのものを管理上限にする", "臨界質量を超えても平均値が低ければよい", "秤量誤差や異常投入を考慮しない", "安全係数を用いて最小臨界質量より低い管理限度を設定し、十分な未臨界余裕を持たせる"]
- 正答選択肢: D
- 正答: 安全係数を用いて最小臨界質量より低い管理限度を設定し、十分な未臨界余裕を持たせる
- 解説: SSG-27 (Rev.1) 3.18(b)は、質量限度を最小臨界質量より低く安全係数を用いて設定する方法を示し、過剰投入が起きても直ちに臨界とならない余裕を持たせ得るとしている。
- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1995_web.pdf
- verified: true

### SAF-03-Q005
- 問題文: 質量管理の安全評価で、通常の1バッチだけでなく追加投入の可能性を考慮する主な理由はどれか。

### SAF-03-Q006
- 問題文: 均一な核分裂性物質溶液を濃度で管理する場合の基本的な考え方として適切なのはどれか。
- 選択肢: ["濃度上限は設けず液量だけを見る", "評価済みの未臨界濃度以下に制限し、適用条件を維持する", "最低濃度だけを管理する", "濃度測定をせず公称値だけを使う"]
- 正答選択肢: B
- 正答: 評価済みの未臨界濃度以下に制限し、適用条件を維持する
- 解説: SSG-27 (Rev.1) 3.18(c)は、均一な水素含有混合物や固体について核分裂性物質濃度の制限を安全対策として示す。限度は評価条件の下で未臨界性を確保する必要がある。
- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1995_web.pdf
- verified: true

### SAF-03-Q007
- 問題文: 溶液の濃度管理だけに依存する場合、特に管理すべき変化はどれか。
- 選択肢: ["壁面塗装の退色", "作業服の色", "沈殿・析出・蒸発などによる局所的又は全体的な濃縮", "建屋の窓数"]
- 正答選択肢: C
- 正答: 沈殿・析出・蒸発などによる局所的又は全体的な濃縮

- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/P061_scr.pdf

### SAF-03-Q008
- 問題文: 形状・寸法による臨界管理の説明として正しいものはどれか。
- 選択肢: ["容器材質に関係なく外観だけで決める", "どの形状でも同じ容積なら同じ安全性とみなす", "質量が同じなら寸法管理は不要とする", "配管や容器の寸法・形状を、評価済みの有利な幾何形状から外れないよう制限する"]
- 正答選択肢: D
- 正答: 配管や容器の寸法・形状を、評価済みの有利な幾何形状から外れないよう制限する
- 解説: SSG-27 (Rev.1) 3.18(a)は、設備の寸法と形状を制限する有利形状を臨界管理方法として明示する。幾何形状そのものが中性子漏えいと相互作用に影響するため、単純な質量・容積だけでは代替できない。
- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1995_web.pdf
- verified: true

### SAF-03-Q009
- 問題文: 均一溶液で容積上限を臨界管理に利用する場合の考え方として最も適切なのはどれか。
- 選択肢: ["最大濃度や容器形状などの評価条件と組み合わせ、容積上限が核分裂性物質量を制限するよう設定する", "容積だけ同じなら濃度や形状は自由に変えてよい", "容積を大きくするほど必ず安全になる", "容積管理では核分裂性物質量を考えなくてよい"]
- 正答選択肢: A
- 正答: 最大濃度や容器形状などの評価条件と組み合わせ、容積上限が核分裂性物質量を制限するよう設定する
- 解説: IAEA資料は臨界性が質量、濃度、形状、容積等の組合せで変化することを示している。均一溶液では核分裂性物質量は濃度と容積に依存するため、容積制限は評価済み濃度・形状等の前提と一体で用いる必要がある。
- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/P061_scr.pdf ; https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1995_web.pdf
- verified: true

### SAF-03-Q010
- 問題文: 有利形状設備を臨界管理に使う場合、長期運転や異常時に確認すべき事項はどれか。
- 選択肢: ["設備の購入価格の変化", "腐食・侵食・変形・膨らみ等で評価済み寸法から外れないこと", "作業者の平均年齢", "帳票のページ数"]
- 正答選択肢: B
- 正答: 腐食・侵食・変形・膨らみ等で評価済み寸法から外れないこと
- 解説: IAEAの転換・濃縮施設安全資料は、幾何形状を安全対策とする設備について、腐食、侵食、変形、膨らみ等による寸法変化を考慮するよう求める。形状が変われば臨界安全評価の前提が失われ得る。
- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/PUB2038_web.pdf
- verified: true

### SAF-03-Q011
- 問題文: 減速材を臨界管理パラメータとして用いる場合の方法として正しいものはどれか。
- 選択肢: ["減速材の種類だけを決め、量は無制限とする", "水だけを対象とし他の水素含有物質は無視する", "減速材の種類と量を、評価済み範囲内に制限する", "減速材が増えるほど常に未臨界になると仮定する"]
- 正答選択肢: C
- 正答: 減速材の種類と量を、評価済み範囲内に制限する
- 解説: SSG-27 (Rev.1) 3.18(d)は、体系中の減速材の種類と量に制限を設けることを臨界管理方法として示す。水以外にも油、ポリエチレン等の水素含有物質が減速材となり得る。
- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1995_web.pdf
- verified: true

### SAF-03-Q012
- 問題文: ウラン粉末の漏えい・こぼれが臨界上重要な施設で、減速条件悪化を防ぐ設計として適切なのはどれか。

### SAF-03-Q013
- 問題文: 中性子吸収材を臨界管理に使用するとき、SSG-27 (Rev.1) が管理対象として明示している組合せはどれか。

### SAF-03-Q014
- 問題文: 熱中性子吸収材の効果を評価するときに注意すべき現象はどれか。

### SAF-03-Q015
- 問題文: 固定式の中性子吸収材を安全機能として用いる場合の管理として正しいものはどれか。
- 選択肢: ["据付後は存在確認をしない", "メーカー仕様書があれば初期確認は不要", "使用開始前に吸収核種の存在・分布等を確認し、使用中も有効性が維持されていることを確認する", "吸収材の厚さや組成は臨界評価から除外する"]

- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1995_web.pdf

### SAF-03-Q016
- 問題文: 均一に混合した中性子吸収材を長期使用する場合、臨界安全上考慮すべき変化はどれか。

- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1995_web.pdf

### SAF-03-Q017
- 問題文: 個々には未臨界な複数ユニットの相互作用を抑える基本的な配列管理はどれか。

### SAF-03-Q018

### SAF-03-Q019
- 問題文: ユニット間隔管理について、SSG-27 (Rev.1) が示す例外的な考え方として正しいものはどれか。
- 選択肢: ["距離は臨界安全に影響しない", "常に無限大の離隔だけを要求する", "ユニット間物質による減速の影響を制限するため、場合によっては最大離隔距離を管理することもある", "最小離隔距離と最大離隔距離を同時にゼロにする"]
- 正答選択肢: C
- 正答: ユニット間物質による減速の影響を制限するため、場合によっては最大離隔距離を管理することもある
- 解説: SSG-27 (Rev.1) は通常の最小分離距離に加え、ユニット間に入る減速材の量を制限する目的で、場合によって最大距離が管理パラメータとなり得ることを示している。
- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1995_web.pdf
- verified: true

### SAF-03-Q020
- 問題文: 配列・間隔管理で、ユニット間に存在する物質を評価する必要がある理由はどれか。
- 選択肢: ["物質の色で容器番号が変わるため", "作業動線が短くなるため", "温度計の表示が変わるため", "反射・減速・吸収の作用によりkeffを上げる場合も下げる場合もあるため"]
- 正答選択肢: D
- 正答: 反射・減速・吸収の作用によりkeffを上げる場合も下げる場合もあるため
- 解説: SSG-27 (Rev.1) は、周囲及びユニット間の物質が反射材、減速材又は吸収材として作用し、材質・密度等によってkeffを増減させ得るため、モデルへの包含又は除外を正当化する必要があるとする。
- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1995_web.pdf

### SAF-03-Q022

### SAF-03-Q023
- 問題文: 有利形状設備や固定式中性子吸収材を継続的な臨界管理に用いる場合、適切な保全はどれか。

- 正答: 寸法・形状や吸収材の存在・健全性・有効性を定期的に点検する

### SAF-03-Q024
- 問題文: 臨界管理限度の設定方法として、IAEA SSG-27 (Rev.1) に整合するものはどれか。
- 選択肢: ["臨界点そのものを管理限度とし余裕を設けない", "経験値だけで決め計算や不確かさを考慮しない", "平均運転値が安全なら上限値を設けない", "臨界パラメータへ安全係数を適用するか、十分な未臨界余裕が得られる値を解析で定め、不確かさと保守性を考慮する"]
- 正答選択肢: D
- 正答: 臨界パラメータへ安全係数を適用するか、十分な未臨界余裕が得られる値を解析で定め、不確かさと保守性を考慮する
- 解説: SSG-27 (Rev.1) 3.19は、臨界パラメータに安全係数を適用する方法又は十分な未臨界余裕を与える値を計算で決める方法を示し、パラメータ変動・計算不確かさ・結果の保守性を考慮するよう求める。
- 出典: https://www-pub.iaea.org/MTCD/Publications/PDF/PUB1995_web.pdf
